## Checked distribution routes

- [Show HN](https://news.ycombinator.com/showhn.html): runnable personally built product, not just a landing page, fundraiser, newsletter or signup page. Make trying easy; no requests for upvotes or comments. Reserve different product days and skip the submission if the stated product gate isn't met.
- [DEV code of conduct](https://dev.to/code-of-conduct): respectful original work, cite sources, disclose AI assistance under the linked AI guidance. Publish a technical lesson that stands without the product link, not a synthetic testimonial.
- [Peerlist Launchpad](https://peerlist.io/launchpad): real destination, but public rendering showed a historical week. Inspect actual current availability/rules; no reserved slot is implied.
- [Product Hunt launch guide](https://www.producthunt.com/launch): maker account, no solicited votes, inspect existing listing before repeat launch. No paid placement.
- [AlternativeTo FAQ](https://alternativeto.net/faq/): verify email, use Suggest new application with real platform/license/tags; normal review backlog may be indefinite. Paid priority is outside budget. **Forecast zero month-one traffic until accepted.** No advertising through a user profile.
- [Raycast pricing](https://www.raycast.com/pricing): free core and extension ecosystem; paid Pro displayed at$10/month or$96/year. Do not label an unrelated launcher a direct usage-meter competitor without a verified applicable extension. Free manual provider usage pages and a local text handoff are often the true alternatives.

## Scheduling and estimation

Proposed individual-builder launch windows: FuelBar Day10, Relay Day18 only after distribution/signing gates pass, SnipText Day24 after its own audit. These are preferred relative windows, not booked dates. A coordinator should translate them to actual dates and avoid duplicate organization pitches. Later desktop utilities should use a different professional niche or a later week rather than blanket the same feed.

No observed launch analytics were supplied. Conservative planning ranges: an original small-account developer post100–500impressions and0–5qualified visits; one usable Show HN20–300visits, possibly zero; Peerlist20–150visits, possibly zero. These are guesses, not measured industry averages. A front-page hit is upside, not a necessary input to an honest target model. Zero-budget means free submissions only, no sponsored newsletter, paid download purchase by the kit writer or paid review.

Keep actual install failures distinct from untested installation. A stale source count is not a live usage signal; a path printed in a brief grants no tool filesystem access. Never capture API keys, payment receipts, auth cookies, private session logs or users' local documents in public demos.
