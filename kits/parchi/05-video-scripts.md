# Parchi — Phone-demo scripts

Use a fictional clothing seller, synthetic order and invented non-personal delivery fields. Record your screen and voice. No real customer name, address, phone, GST data or private invoice. Leave the human review visible.

## A. Correct before sending — 65 seconds

0–3 s: synthetic Hinglish order. **“Which blue item did the customer mean?”**

3–17 s: actual owned sample product list and permitted draft entry. “The saved products supply the rate. The message supplies the requested details.”

17–32 s: actual generated draft if verified; inspect item, size and quantity. “A plausible match still needs the seller's check.” Leave one real correction uncut.

32–47 s: delivery charge and total review, then actual PDF if supported. “Compare every line with the original before sending.” Do not send to a real customer during recording.

47–55 s: challenge/sample disclaimer versus real workflow. “The public game sends nothing. This test uses fictional data.”

55–65 s: actual quota/price and URL. “Thirty-day passes, no auto-renewal. Check your plan before paying. parchi.site.”

## B. Quantity hook — 20 seconds, Status

0–3 s: synthetic order with a corrected count. **“Two, not three.”**

3–12 s: actual draft correction and arithmetic. “The useful step is catching the mismatch before it becomes the bill.”

12–20 s: reviewed sample label and URL. “Parchi drafts. The seller checks.” No invented returns reduction.

## C. Sample hook — 25 seconds, LinkedIn

0–3 s: public challenge notice. **“This bill is not an invoice.”**

3–15 s: sample game and its nothing-sent disclosure. “It demonstrates the idea. No customer is billed, and no payment is collected by playing.”

15–25 s: real entry/pricing boundary. “Inspect the actual seller workflow and quotas before using real orders.”

Capture current headline/CTA, sample challenge label, actual saved-product mapping, real correction, exact totals, PDF and 30-day plan. If the authenticated pipeline is unavailable, do not splice challenge output into a claimed real invoice. Label waiting-time cuts and untested functions.
