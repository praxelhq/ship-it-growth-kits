# Kindred — 30-day calendar

Daily: 15 minutes for product replies and aggregate issues. Keep the journal itself out of feedback requests.

| Day | Main job | Time |
| --- | --- | --- |
| 1 | Test actual offer, signup, first entry, reopen and delete; baseline. | 3h |
| 2 | Publish the true price/free allowance and a fictional sample. | 3h |
| 3 | Explain privacy/storage and keep reflection boundaries visible. | 2h |
| 4 | Record demo A and hook B after the flow works. | 2h |
| 5 | Invite five willing adult journalers (#1). | 1h |
| 6 | Observe onboarding only, not their private writing. | 2h |
| 7 | Checkpoint: accounts, first saved entries and confusion. | 1h |
| 8 | First Reel B / #3 at 19:30 IST. | 1h |
| 9 | Ask two existing group admins for permission. | 30m |
| 10 | Invite five more journalers. | 1h |
| 11 | First LinkedIn #4 at 12:30 IST. | 2h |
| 12 | Share #2 in first approved group. | 1h |
| 13 | Second Reel C / #3. | 1h |
| 14 | Checkpoint: offer understood and first entry actually saved. | 1h |
| 15 | Repair the biggest saving/reopening issue. | 3h |
| 16 | Share #2 in second approved group. | 1h |
| 17 | Send #5 to one willing journaling-club organizer. | 30m |
| 18 | Run accepted voluntary demo, or support existing testers. | 2h |
| 19 | Record privacy explainer D using fictional data. | 1h |
| 20 | Third Reel D / #3. | 1h |
| 21 | Checkpoint: unprompted return versus one-time curiosity. | 1h |
| 22 | Optional Peerlist maker feedback #6, current rules checked. | 1h |
| 23 | Fix one actual first-entry issue from feedback. | 2h |
| 24 | Second LinkedIn #4 with a real design lesson. | 2h |
| 25 | Record another fictional prompt interpretation. | 1h |
| 26 | Fourth Reel / #3. | 1h |
| 27 | One follow-up only to willing testers/organizer. | 30m |
| 28 | Checkpoint: return, deletion controls and offer clarity. | 1h |
| 29 | Support the channel producing voluntary repeat journalers. | 2h |
| 30 | Report accounts, first entries, returns and target gap. | 2h |

Never use a fear-based notification or a supposedly accurate prediction to manufacture retention. If you cannot explain the current paid/free offer, fix it before traffic.
