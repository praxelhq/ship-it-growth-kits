# Kindred — Measurement

**B2C target: 1,000 signups in 30 days.** Count confirmed real accounts once. Report **first reflection saved and reopened** plus **voluntary seven-day return** beside it. Viewing a symbolic card is not proof journaling became useful.

No private records were accessed; the public screen did not expose pricing. Record actual baseline and offer before posting.

| Baseline | Source |
| --- | --- |
| Accounts, total and last 7 days | Authentication records, no tests |
| First entries saved/reopened | Aggregate status events, no entry text |
| Returning journalers | Aggregate account activity |
| Save/delete failures | Issue codes, not diary contents |
| Current price/free allowance and real payments | Product/checkout configuration, not a guess |
| Traffic and course baseline | Existing consented analytics and [profile](https://shipped.money/p/kindred), metric/time recorded |

Check whether [Clarity](https://clarity.microsoft.com/) already exists. Mask or exclude journal, mood, birth details, account and payment screens. Track `account_confirmed`, `prompt_viewed`, `first_entry_saved`, `entry_reopened`, `entry_deleted`, `seven_day_return` as status only. Never collect diary text for conversion analysis.

| Checkpoint | Question | Response |
| --- | --- | --- |
| Day 7 | Do five willing testers understand the offer and save/reopen an entry? | Fix unclear pricing/onboarding or failed saves before promotion. |
| Day 14 | Can users explain that prompts aren't predictions? | If not, change the first screen and example. |
| Day 21 | Do people return without pressure? | Ask about usefulness; don't manufacture fear-based retention. |
| Day 30 | Accounts against 1,000; first entries and return beside it | Report actual gap and useful acquisition route. |

At 30% visitor-to-account, 1,000 needs about 3,334 relevant unique visits. `02`'s scheduled tests may only yield dozens of accounts. Replace forecast rates after three clips, and don't present repeat logins as new signups.

Do not infer therapeutic improvement, accurate astrology or prediction success from app use. Course 24-hour readings overlap and are not cumulative accounts. The useful result is a voluntary, clearly framed journal habit with privacy controls the user understands.
