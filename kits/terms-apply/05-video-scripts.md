# Terms Apply — Video scripts

Use your own ordinary task, readable screen recordings and voice. Hide email, access links and private commitments. Hard cuts and captions are enough.

## A. Promise to report — 60 seconds

**Where:** owned profiles and small-circle opening. **Hook:** “Tomorrow is not a definition of done.”

| Time | Shot / text | Voice |
| --- | --- | --- |
| 0–8s | Vague note, then a specific ordinary task. | “Tomorrow is not a definition of done. I need to say what I will actually finish.” |
| 8–22s | Actual creation screen and chosen deadline/timezone. | “I write one task, what done means and the date. The terms are mine.” |
| 22–35s | Review screen and manageable pledge. | “I check the terms. This is not a financial stake or an enforced punishment.” |
| 35–48s | A real later outcome screen, or clearly labeled example if no later report yet. | “Later I report what happened. Late, missed and unanswered are different.” |
| 48–60s | Original terms beside report; URL/free line. | “Terms Apply keeps the record. Free, with optional email reminders.” |

Do not present an illustrative later screen as a completed real task.

## B. Definition of done — 20 seconds, vertical

**Hook:** “Work on it is not finish it.”

| Time | Shot / text | Voice |
| --- | --- | --- |
| 0–5s | “Work on application” crossed out. | “Work on it is not finish it.” |
| 5–13s | Actual specific task and deadline. | “Choose a result you can recognize. Keep the first one small.” |
| 13–20s | Review screen and URL. | “Write the terms, then report honestly. termsapply.me.” |

## C. Missed is a result — 25 seconds, vertical

**Hook:** “A missed task is not an app failure.”

| Time | Shot / text | Voice |
| --- | --- | --- |
| 0–6s | Actual or clearly labeled missed example. | “A missed task is not an app failure. Hiding it would be.” |
| 6–17s | Original terms and actual report choices. | “I can see what I promised and answer what happened. Silence stays unreported.” |
| 17–25s | URL; “Record, not enforcement.” | “That is the useful record. No forced public confession.” |

## D. Emails are optional — 20 seconds, vertical

**Hook:** “A promise does not need another email list.”

| Time | Shot / text | Voice |
| --- | --- | --- |
| 0–6s | Actual reminder choice. | “A promise does not need another email list.” |
| 6–14s | Select the real preference in a test. | “Email reminders are optional. Check the terms before confirming.” |
| 14–20s | Saved record, only if actually saved. | “The record is the point. You choose the reminder.” |

Bank creation, review, actual later report and reminder-choice clips. Six owned posts are scheduled, each with a different real task/learning rather than a recycled motivational slogan.
