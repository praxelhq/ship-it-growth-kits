# KnockKnock — Video scripts

Native hardware footage first. No private windows, personal Mac names, license keys or claim that the website simulation tested the motion sensor. Use a supported maker-owned machine and harmless sample windows. Keep hardware/model/price visible in final cards.

## A. Demonstration — 55 seconds, landing and optional session

**0–7s:** Wide shot of actual MacBook base plus clean sample windows. “Two knocks to hide personal windows before a shared-screen moment.” Overlay exact test model/version and *native demonstration*.

**7–17s:** Show actual calibration and chosen decoy. “This needs supported hardware and calibration.” Don't compress four knocks into two without explaining the separate setup.

**17–28s:** Knock twice; show what actually happens to windows and audio. “Here is this test's result.” Don't splice in an animated result. If a window stays visible, treat it as a test failure/known limit, not hide it in the edit.

**28–38s:** Perform actual restoration. “Then bring the windows back.” Show state honestly, including audio behavior verified in the test.

**38–46s:** Show separate triple-knock lock option if implemented/tested. “Hiding windows isn't the same as locking the Mac.” No cheating/deception scenario.

**46–55s:** Compatibility/offer card: M2-or-later MacBooks or M1 Pro; not base M1/desktop Macs; $5 once plus tax, three Macs; check refund/privacy/release terms. URL.

## B. Hook — 23 seconds, Day 10

**0–5s:** Hand on base, clean fictional windows. “No shortcut to remember—if your MacBook is supported.”

**5–15s:** Real two-knock hide/restore in one continuous shot. State exact model on screen.

**15–23s:** “Not base M1, not desktop Macs. Check before buying.” Price/URL card. Don't lead people into an incompatible checkout for a higher click rate.

## C. Hook — 25 seconds, Day 16

**0–6s:** Browser laptop simulation clearly labelled. “This click animation isn't a hardware test.”

**6–17s:** Cut to native calibration/gesture. “This is the real sensor path on a supported MacBook.” Use only after actually recording it.

**17–25s:** “Ask for a native demo, not just a pretty landing page.” URL/model/price. The developer's honesty is the hook, not an invented testimonial.

## D. Hook — 25 seconds, Day 24

**0–6s:** Two columns: detection versus licensing. “Local sensor detection doesn't mean no network anywhere.”

**6–17s:** Highlight actual public privacy text without showing keys. “Activation sends license details, a hardware hash and Mac name; later checks validate the license.”

**17–25s:** “Know the boundary before installing.” Link public privacy and actual product. No claim the hardware hash is anonymous or the entire app was independently audited.

Captions and clean sound matter because audio mute is part of the demonstration. Don't overlay music that disguises whether app audio really stopped.
