# KnockKnock — Distribution map

This is a supported-MacBook gesture utility. Coordinate the shared Mac cluster: no organizer receives KnockKnock, SnipText and Swish pitches in the same week. Different audiences: quick window privacy, OCR from images, bilingual writing edits. Actual moderator rules override relative launch windows.

## Ranked routes

1. **Twenty qualified warm MacBook-owner invitations**, five Days 5,12,19,26. Ask the exact model before sending a purchase link. Use 03 #1; show a maker-owned hardware demo before asking for $5. A supported model doesn't eliminate the need to verify app signing and release delivery. One follow-up maximum; no warning bypass.
2. **Six owned posts**, Days 6,10,16,20,24,29. Use the real hardware gesture, calibration, restoration and plain compatibility card. Post manually; [LinkedIn policy](https://www.linkedin.com/help/linkedin/answer/a1341387) disallows unauthorized automation/scraping and inauthentic engagement. Don't target another maker's comment list or imply universal M1 support.
3. **One conditional ten-person supported-MacBook demo**, Day 15. Ask a known Mac-user organizer Day 8 with 03 #4. Proposed cap isn't an approved group/attendance count. Demo the maker's own machine, no purchase pressure, no install required for attendance. If none accepts, individual tests replace it and event forecast is zero.
4. **r/macapps, conditional rule-compliant route**, https://www.reddit.com/r/macapps/comments/1ryaeex/rmacapps_mods_went_too_far_whats_changing_phase_3/. The checked moderator announcement uses trust/transparency tiers for main feed versus App Pile, requires useful Problem/Comparison/Pricing and maker disclosure, and limits promotion to once per developer per 30 days, including removed posts. Read current pins/sidebar and history Day 18. One appropriate submission Day 23 only if eligible; no promise of main-feed access, no crosspost/alternate account to evade limits. Use 03 #6.
5. **Peerlist**, https://peerlist.io/launchpad. Check current eligibility/slot/existing listing; optional Day 25 submission if allowed. No votes requested and no guaranteed reach from a historical launch page.
6. **Product Hunt**, https://www.producthunt.com/launch. Optional after a working release and actual launch/iteration check; don't duplicate an unchanged product. Real maker disclosure, no paid hunter/upvote asks. Zero forecast until published.
7. **AlternativeTo**, https://alternativeto.net/faq/. Optional factual platform/license entry after verified email. Free backlog can be indefinite; paid priority outside budget. Zero month-one traffic until accepted.

## Honest forecast

Planning guesses, not benchmarks: twenty qualified invitations × 40–60% visit = 8–12 visits; × 10–25% purchase/compatible activation = about 1–3. Six posts × 100–500 impressions = 600–3,000 impressions; × 1% visit = 6–30; × 5–15% purchase/activation = about 0–5. Accepted ten-person demo × 60–80% attendance = 6–8; × 10–25% later purchase/activation = about 1–2. Remove warm/demo/post overlap.

Base roughly 1–8 activated buyers without the session, 2–10 with it before deduplication. These are not market conversion estimates and may be zero if trust/release readiness fails. Reddit and launches aren't guaranteed and contribute zero to the base. The 1,000 target remains far above this reachable input volume. A larger accepted Mac utility partner can be tested after reliability and purchase clarity, but it isn't imaginary traffic in this month's model.
