# Sue Your Friend — Landing page fixes

Observed 29 October 2026: homepage **“Friendship Court.”**, “File a case” → **“File your complaint.”** The actual form states fictional scope, complete preview free and $4.99 USD one-time sharing/downloads. No case was generated or purchased.

1. **Make fictional scope the first readable sentence.** Current “Your friend has committed crimes” is comic framing but can be detached from context. Replacement **“Fictional court cases for harmless friend-group jokes.”** Support **“Stolen fries, late arrivals, unread jokes. No real accusations or legal authority.”** CTA **“Create a fictional case”** → existing create path.
2. **Preserve the actual useful price split.** Repeat beside hero CTA **“Full case preview free. Sharing and downloads: $4.99 USD one-time.”** Keep tax/currency explanation before purchase; no free-sharing claim. Test that free preview really shows the whole case and paid entitlements deliver only after actual confirmation. This kit did not test either.
3. **Prompt safe fictional input before a name.** Add **“Use a made-up nickname. Leave out private details, health, money or serious disputes.”** Keep the existing harmless-use confirmation. Do not imply that collecting a real name is necessary to try the product. Reject/redirect serious allegations rather than making a legal-looking output from them.
4. **Keep the disclaimer on the output and previews.** Suggested label **“Fictional joke case — no legal effect.”** Keep it on shared links, images/PDF and appeal pages, not only the input form. Test metadata so a preview cannot present a real person as accused without context. Never use official court insignia or imply real legal service.
5. **Explain private versus shared state.** The form says free preview is visible in this browser. State actual storage, processing providers, retention and whether it can be recovered. Do not promise permanent privacy or deletion without implementation evidence. Before sharing: **“Check the complete case and ask whether the intended recipient would welcome it.”** Do not auto-post or auto-message.
6. **Mobile and failure.** Title **“Friendship Court — harmless fictional cases for friends”**. Preview uses a fictional nickname/fries example. Test text length, disabled Build button explanation, generation failure and mobile readability. Error **“The case didn't finish. Nothing has been shared.”** only if that second sentence is actually true. No fake generated-case counter or popularity proof.
