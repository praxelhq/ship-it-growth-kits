# Shipit Studio — Video scripts

Film your authorized test workspace with synthetic class content, not a real student's messages or assignments. No paid editor.

**A. One group, one task, 45 seconds; eligible pilot/owned profile.** Hook: “Another account isn't the same as a useful class workspace.” Show the actual MU-only signup notice. Show the tested confirmation boundary without email/credentials. Record one real implemented task in a synthetic workspace, then a second authorized member finding it. Say, “The test is whether the right classmate can find the agreed item.” End: “Quad, currently MU students only.” If the workflow doesn't work, show the blocker as a build update instead of a fake task board.

**B. Only this audience today, 20 seconds; LinkedIn.** Hook: “A signup restriction should be visible before the form.” Show the actual MU email label and eligibility text. Say, “Quad isn't open to every institution yet. I need to explain who can join, not send ineligible visitors to a dead end.” End on verified URL.

**C. Confirmation isn't instant entry, 20 seconds; accepted campus bulletin.** Hook: “Three fields, then what?” Show the current form and an accurate tested confirmation explanation. Say, “Read the email step and recovery before starting.” Don't display a real inbox or invent a sent-email confirmation.

**D. Right people, 20 seconds; owned post.** Hook: “The right workspace matters more than a busy screen.” Show synthetic membership/visibility only after actual tests. Say, “Class content should reach the people permitted to see it. We test access before adding real work.” No security certification or claim the kit audited implementation.
