# Biaah — Video scripts

Use a wholly fictional household, generic roles and invented expenses. No real names, contacts, guest diet/travel/room data, wedding dates, payment records or photos. Real app footage requires actual access; label any proposed paper exercise as proposed, not shipped UI.

## A. Main demonstration — 55 seconds, after access verified

**0–7s:** Fictional function plan. “Start with one function, not the whole wedding.” Sample label stays visible.

**7–19s:** Open actual authorized sample workspace. “Who owns this plan, and who can see it?” Show only actual verified access controls, no security-certification claim.

**19–31s:** Enter a few fictional planned costs using the real interface. “Planned isn't paid. Keep status clear.” Don't imply a ledger entry transfers money.

**31–42s:** Assign/update an actual supported responsibility and show shared view if genuinely tested. “What does the next helper do?” No fake real-time update or invented WhatsApp notification.

**42–49s:** Actual export/access terms. “Keep a backup and understand how long this workspace stays available.” Don't animate an unimplemented export.

**49–55s:** ₹51 one-time current launch offer, actual delivery/refund terms, URL. If access/entitlement isn't verified, use B repair update rather than a purchase CTA.

## B. Hook — 24 seconds, Day 9

**0–6s:** Public checkout button, no transaction details. “A checkout isn't a workspace.”

**6–16s:** Actual verified access path if ready, otherwise transparent not-yet-verified status. “Show how someone gets in and keeps access before asking them to pay.”

**16–24s:** Fictional first-function test and URL. No claim payment succeeded from a redirect string.

## C. Hook — 25 seconds, Day 14

**0–6s:** Sample cost labels planned/committed/paid. “Three numbers that shouldn't become one.”

**6–17s:** Real sample ledger workflow or explicitly labelled paper exercise. “A clear status helps a family ask the next question.”

**17–25s:** “Tracking money isn't transferring it.” URL. No current vendor quote, bank receipt or price benchmark invented.

## D. Hook — 25 seconds, Day 24

**0–6s:** Static sample dashboard with sample label. “A beautiful sample isn't a customer's wedding.”

**6–17s:** Highlight invented guest count/rating/household labels. “These examples show the idea. Actual vendor verification and private access need their own evidence.”

**17–25s:** “Try one safe shared plan first.” Actual evaluation link/terms if ready. No testimonial or “zero chaos guaranteed.”

Four assets plus two honest text/process posts support the six-post calendar. Avoid cinematic wedding imagery that distracts from missing access, undefined retention or untested shared data.
