# PBC Tracker — Phone-demo scripts

Use a fictional audit engagement, invented request IDs and wholly synthetic supports. Record your screen/voice. No client names, financial evidence, inbox contents, private links or real credentials. Do not connect a real mailbox or send a client upload as a marketing action.

## A. Received is not accepted — 65 seconds

0–3 s: synthetic support beside two request IDs. **“Which request does this belong to?”**

3–17 s: actual sample Excel/CSV import with column mapping. “Start with the list the practice already uses.”

17–32 s: actual saved-email/sample upload route, labelled internal. “A file arriving is only the first step.” Leave one supported interaction uncut.

32–47 s: actual uncertain match and auditor correction/acceptance. “Inspect the reason. The auditor makes the decision.” If unavailable, show the public claim and label the missing test rather than fake success.

47–55 s: actual outstanding view/export if verified. “Check the output against the request list.”

55–65 s: Free limits and URL. “One engagement on Free. Paid periods do not auto-renew. pbctracker.tech.”

## B. Wrong period hook — 20 seconds, Short

0–3 s: synthetic file with the wrong year. **“Same title. Wrong period.”**

3–12 s: actual review/correction or a labelled checklist. “A good match needs more than a familiar file name.”

12–20 s: received/accepted state distinction and URL. “Keep uncertainty visible before acceptance.” No audit-quality guarantee.

## C. Permission hook — 25 seconds, LinkedIn

0–3 s: public read-only claim and sample email. **“Read-only is still access.”**

3–15 s: verified provider-scope/domain review, or public explanation labelled untested. “Check what the connection reads and who authorized it.”

15–25 s: synthetic saved-email route and URL. “Use a harmless sample before a real client inbox.”

Capture exact headline, import/mapping, uncertain match, human decision, actual trail/export, private-link scope and prepaid limits. Label wait cuts. A static landing mockup cannot be presented as a successful engagement or a source of customer numbers.
