# Proof of Work Wall — Landing page fixes

Browser checked 29 October 2026: **“Show your work. Find your next opportunity.”**, “Submit a brick” → `#/auth`; **“The wall is waiting for its first brick.”** Actual pricing: core free; optional $8/month or $48/year billed upfront and auto-renewing. No account, publication or payment was submitted.

1. **Replace the employment shortcut with a concrete first outcome.** Current “Get hired” implies a stronger immediate result than an empty wall supports. Replacement **“Publish one case study someone can inspect.”** Support **“Show the brief, your contribution, real evidence and what you learned.”** CTA **“Create my first brick”** → existing auth with return to the intended submission. Test return routing before claiming it works.
2. **Keep the empty state honest and useful.** Current “No pretend work” is good. Add a clearly labelled original example with an actual permission-safe class experiment or synthetic demonstration. Copy **“Example structure, not a real customer or hiring result.”** Never seed fake marketer profiles to make the marketplace appear busy.
3. **Explain the verification boundary beside evidence.** Footer “Self-posted work, not independently verified” should sit near claims, not only at the bottom. Copy **“Peer feedback is an opinion on the submitted work. Confirmation covers only what the reviewer actually checked.”** Manager-confirmation invitations require consent and a tested implementation; no fake badges or blanket verification claim.
4. **Put permissions and visibility before publish.** Copy **“Publish only material you own or may share. Remove private client, colleague and student information.”** Open-to-work choice **“Signed-in recruiters can see the contact details you choose to provide.”** Show a preview and explicit setting, then test actual access with authorized accounts. Do not imply every note/contact field is private.
5. **Separate core value from Pro.** The pricing page is clear: free core, Pro $8/month or one $48 annual charge, auto-renewal and possible taxes. Repeat near upgrades **“Core posting is free. Pro is optional and renews until cancelled.”** A $48 annual payment is not a $4 monthly cancellable plan. No checkout/entitlement verification is claimed.
6. **Mobile and preview.** Title **“Proof-of-Work Wall — marketing cases with inspectable evidence”**. Description **“Publish a brief, your contribution and what actually happened. Core posting is free.”** Test long case text, number/source fields, errors and publish preview on a phone. Session replay must exclude private drafts and contacts; no performance benchmark or security audit was done here.
