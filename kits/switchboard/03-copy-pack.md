## 3. LinkedIn teaching post

> “The job asks for stakeholder alignment” isn't evidence that you've done it.
>
> Before adding a keyword to a résumé, ask: what did I actually do, with whom, and can I explain it in an interview?
>
> If the evidence is there, make it clearer. If it isn't, leave the skill out. A closer match on paper isn't worth a false claim.
>
> I built SwitchBoard around visible additions/removals and a decision on every change before export. You can inspect the idea here: https://switchboardapp.studio/.
>
> Which résumé edit would you most want an explanation for?

## 4. Useful comment, no product link

> A helpful test for that bullet is whether you could explain your personal contribution in the interview. If the rewrite adds responsibility or impact you can't support, reject it even if it matches the job description better.

Use only in a relevant discussion and adapt to the actual question. Don't diagnose a stranger's entire career from one post.

## 7. Product Hunt maker comment, after readiness

> I wanted résumé tailoring to feel inspectable rather than like a mystery rewrite. The useful test is whether a person can explain every accepted change as true. Suggestions can be wrong, so review is the product, not an obstacle to skip. This doesn't guarantee ATS success, interviews or a job. Please start with an example you can safely share with an AI service.
