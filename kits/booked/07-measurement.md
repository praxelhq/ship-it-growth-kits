# booked — Measurement

**Target: 10 real creator businesses.** Activation beside it: **businesses independently maintaining a permitted real paid-work record with deliverable/revision/payment status**. Account creation alone isn't activation. The actual private feature set still needs controlled verification.

## Day 0

Query actual businesses, real job records, successful status updates, error rates and independent returns from your own records. The sign-in page establishes none of those counts. Check existing [Clarity](https://clarity.microsoft.com/) collection or configure it if absent, masking private work/client information. Record actual [course profile](https://shipped.money/p/booked) rank, saved reading and timestamp. Unknown isn't zero. No public price/live billing was verified; don't report imagined subscription revenue.

Only instrument functions that exist: `account_created`, `real_job_saved`, `deliverable_updated`, `revision_recorded`, `payment_status_confirmed` and `creator_returned` are proposed event names, not claims all current controls were tested. A recorded “paid” status isn't independent payment verification. Exclude synthetic jobs and your own accounts.

## Four tests

The [policy](../../TARGET-POLICY.md) requires a real trading creator business, its own permitted actual work onboarded, independent use in the final seven days without your prompt, and a responsible person's name/callable number held privately. Paying isn't required. One creator with ten jobs is one business. If the current app can't support the actual job, the ten-customer target is gated; don't count a research conversation as adoption.

## Forecast and checkpoints

40 first approaches × hypothetical 25% response × 60% permitted trial × 50% independent reuse ≈ 3 businesses. Ten warm requests may add 0–2. **Base 3–5 is below ten**, and the unverified private workflow can reduce that to zero. These are planning assumptions, not creator-CRM benchmarks. Replace them after 20 approaches using actual successful jobs and return use.
