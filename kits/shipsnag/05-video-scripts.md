# ShipSnag — Video scripts

Use a disposable repo and deliberately fake fixtures that cannot be used as credentials. Inspect scripts before running and don't install anything on a viewer's behalf. Record actual command output; label time cuts and seeded test cases. No private source, invoice, dashboard token or full secret.

## A · Did the checks run? · 60 seconds · own feed / launch

| Time | Shot / text | Say |
| --- | --- | --- |
| 0–2s | Toy task and terminal. **“Show the checks.”** | “Before done, I want the actual output.” |
| 2–14s | Free-skill page/requirements and inspected files. | “This is the free Prove It Works skill on a disposable repo.” |
| 14–30s | Actual supported first run, time cuts labelled. | “Here is the command, its result and what did not run.” |
| 30–44s | Compare real test/build output with report. | “A missing tool must stay unverified. It isn't a quiet pass.” |
| 44–53s | Real task coverage or a remaining gap. | “Passing these checks doesn't prove every production system is safe.” |
| 53–60s | Free URL and data boundary. | “Inspect the free skill at shipsnag dot com. Your agent still has its own data terms.” |

Don't invent a failed check to dramatize the clip. Use a labelled deliberately seeded case or the actual observed result.

## B · Missing is a result · 20 seconds · short technical clip

Hook: **“No test run is not a passing test.”** 0–8s, show a genuine missing-dependency/NOT VERIFIED state on your toy repo. 8–15s: “The useful report names the missing check instead of guessing.” 15–20s: “Fix the setup, then rerun.” No claim that a single clean run certifies security.

## C · A diff needs your decision · 25 seconds · paid-skill explanation

Hook: **“Read the change before applying it.”** 0–8s, show an actual proposed diff on synthetic code. 8–18s: “The skill describes the evidence and fix. I review what changes before approving it.” 18–25s: “Then I check the result again.” If only the free read-only tool is installed, use a clearly labelled explanation slide; don't pretend to have tested the paid skill.

## D · Scripts aren't the whole data path · 20 seconds · trust help

Hook: **“Offline script doesn't mean offline agent.”** 0–8s, show a simple script/agent/model diagram. 8–15s: “ShipSnag describes local no-network scripts, but the agent may send code to its model. Claude.ai handles uploaded files differently.” 15–20s: “Read both boundaries before choosing a repo.” No guarantee of confidentiality or actual model-provider configuration.
