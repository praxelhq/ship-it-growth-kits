## Your sentence

> Before your coding agent calls a change done, run the actual project checks and show what passed, failed or could not run.

Bio: **A checkable report before “done.” Start with the free skill.**

The first job is one real small change on a toy repo: inspect the skill/scripts, install in the correct supported location, request proof, then compare the command/output with the project's actual checks. Include a missing-dependency or deliberately failing test case. A report saying NOT VERIFIED is a useful boundary, not an error to conceal.

## Real alternatives

Your project's existing test/build/lint commands cost no additional checking-tool licence, though model use and infrastructure may cost money. An ordinary coding agent can run them too; demonstrate what your explicit verdict/coverage review adds. [Gitleaks](https://github.com/gitleaks/gitleaks) is a free MIT-licensed secret-detection alternative for the Key Leaked branch. Its current repository says feature-complete/security-patch focus and points to Betterleaks. Don't claim it is useless or repeat ShipSnag's planted-test comparison as independent universal accuracy.

The site's benchmark results are operator-reported planted cases, not a guarantee on arbitrary projects. The scripts are described as standard-library Python and offline/no telemetry; the coding agent still processes code under its own provider/mode. Claude.ai runs on uploaded files, unlike a local agent. Don't turn “scripts make no network calls” into “your code can never leave your computer.”

## What you cannot promise

The tool cannot see hosting dashboards, live databases, traffic or invoices that weren't provided. A “safe to ship” result is bounded by checks and evidence, not a security certification or guaranteed cost cap. Fixes are described as diffs requiring approval; inspect actual behaviour before demonstrating it. Never test real exposed credentials in a growth demo or paste a full secret into a public report.

Keep **1,000 consumer signups**, counted here as **distinct successful individual skill installs/first runs** because the free workflow needs no product account. Activation beside it is **one meaningful proof report reviewed against actual command output**. ZIP downloads, paid purchases and a newsletter email are separate.
