# ShipSnag — Landing-page fixes

Homepage, free-skill page and install guide read 29 October 2026. Free ZIP/guide and paid provider destinations are linked; no download was executed, repo scanned or payment made. Public examples/benchmarks are operator claims.

## 1. Replace the permanent-fix guarantee

**Current headline:** “AI built it. Something broke, leaked or cost you.” Supporting line: “Fix it in minutes, then make sure it never happens again.”

**Write:** **“Find evidence for the problem, review a fix and check it again.”** Supporting helper: **“Skills for specific deploy, secret and bill problems. Coverage depends on your code, inputs and environment.”** Keep the recognizable incident language, but don't promise universal speed or permanent prevention. A static check cannot establish every future production outcome.

## 2. Put the free proof path next to the first decision

**Current actions:** “See the skills,” “Find your error”; free “Download Prove It Works free” sits inside the skill list.

**Write first action:** **“Try the free proof skill”** → actual free-skill page. Secondary **“Find my specific error.”** Helper: **“Inspect the files, use a disposable repo, then compare the real checks.”** Test the ZIP, checksum, supported agent discovery and first run on a clean supported setup. If that fails, repair before a directory launch; a download link alone isn't installation proof.

## 3. Make verdicts evidence-bounded

**Current:** Ship Check says “safe to ship,” while the free skill documents PROVEN, CHECKS PASS, NOT VERIFIED and NOT DONE with distinct coverage.

**Write next to the verdict:** **“This result covers the checks and evidence listed below. Unrun or unseen systems remain unverified.”** Keep actual command/output/time and task coverage accessible. Don't let a green summary hide missing tests, a timeout or a dashboard the tool cannot inspect. Verify exact verdict semantics in the current release before filming.

## 4. Separate offline scripts from agent processing

**Current badges:** “No installs,” “No accounts,” “Works offline”; installation requires a skill folder, supported agent and Python 3.8+.

**Write:** **“No extra Python packages or ShipSnag account. Install the skill in a supported agent. Local scripts make no network calls; your agent/model may.”** Explain Claude.ai's uploaded-file environment separately from local agents. These are operator boundaries until tested, not an independent privacy audit. Do not claim code stays local merely because the scanner script is offline.

## 5. Make annual access distinct from one-time purchases

**Current:** single skills $7–$9 once, bundle $19 once, All access $29/year, alongside broad “Pay once, keep it.” A dated launch discount is advertised through 5 November.

**Write plan helpers:** **“Single/bundle: one-time purchase”** and **“All access: $29/year; review renewal terms before checkout.”** Show final charge/tax, licence/update scope and actual seven-day refund terms. Keep any discount deadline dated and remove it when expired; no invented countdown or guessed discounted tax total.

## 6. Put the benchmark's scope with the numbers

**Current:** planted-bug/secret/bill comparisons with plain Claude and Gitleaks.

**Write:** **“Operator-run planted-case evaluation. Results depend on test corpus, tool versions and configuration; not a universal accuracy guarantee.”** Provide reproducible methodology before stronger superiority claims. Keep full secrets out of all sample reports and never test whether a credential is live for marketing. A found code pattern isn't proof a real bill was avoided.

**Current:** homepage says start a new session, while the detailed current guide says Claude Code watches skills and may need reload if the folder was absent initially.

Use one maintained agent/version-specific guide and remove stale duplicate instructions. Proposed preview: **“ShipSnag — evidence before your coding agent says done.”** Test phone readability of code/evidence and desktop access to ZIP/guide. No measured 30-second install or page-speed result was established. Make requirements and actual no-network limits visible before someone downloads.
