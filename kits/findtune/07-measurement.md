# findtune — Measurement

**B2C target: 1,000 signups in 30 days.** For the intended no-account listener flow use the policy's session definition: **unique first working song-search sessions**, with **checked candidates and voluntarily confirmed correct matches** alongside. If the restored build requires accounts, record those separately and state the definition before the month begins. Never count visits to the current empty deployment as product use.

Check existing[Clarity](https://clarity.microsoft.com/) before adding another script. Mask every text/audio input and don't log recordings, lyrical snippets, contact details or private search content. Minimal measurable events may include `search_started`,`query_submitted`,`candidate_shown`,`no_match`,`candidate_opened`,`match_confirmed`,`return_search`. A candidate result isn't a correct identification unless the listener actually confirms it.

## Arithmetic

At an assumed 30% visitor-to-working-search rate, 1,000 first sessions needs about 3,334 qualified visits. If 60% inspect a candidate, that's 600 activation actions, not 600 verified correct songs. These are hypotheses, not recognition benchmarks. Twenty warm invitations,eight posts,one conditional session and directory discovery plausibly form 15–40 first working sessions. They don't establish thousands of visitors.

Don't publish accuracy from ten selected examples. Keep test inputs, supported modes and failures clear; no famous-song success montage can stand in for a representative evaluation. Artist-promotion enquiries or paid exposures, if later launched, remain separate from consumer discovery use.

## Weekly decisions

|Day|Decision|
|---|---|
|7|Can three fresh-phone users reach a genuine result/no-match state? Missing bundle, input permission or unusable output: fix before more invitations.|
|14|Fewer than five of ten willing testers inspect a useful candidate: observe where the loop fails and narrow the advertised input.|
|21|Who returned for a different discovery need? No repeat value: ask whether the input niche differs enough from free alternatives.|
|30|Report first sessions, checked candidates, voluntary correct matches, failures, repeat use, recovered scope,hours and target gap.|

These are experiment decisions, not music-recognition standards. A clear no-match is better than a fabricated answer. Never use copyrighted lyrics or private recordings as public growth evidence without the needed rights and permission.
