# BuskAlong — 30-day calendar

Start after a supported chart opens and the permission/fallback experience works. Every day: 15 minutes replying and 10 minutes recording practice starts, useful sessions and errors. Times IST; no paid software required.

| Day | Main action | Time |
| --- | --- | --- |
| 1 | Baseline `07`; test one complete chart on two available devices. | 2h |
| 2 | Ship the focused hero and ready-made-song CTA (`04` 1–2). | 2h |
| 3 | Clarify imported-title labels and mic explanation (`04` 3–4). | 2h |
| 4 | Ask the music-society organizer for one five-player test (#1/#6). | 1h |
| 5 | Record demo A and the pause-test Short B. | 2h |
| 6 | Invite five players after permission; run the accepted test at 18:00. | 2h |
| 7 | Checkpoint: count uninterrupted useful practices, not compliments. | 1h |
| 8 | Publish Short B on your own YouTube channel. | 1h |
| 9 | Fix the most common chart-following or readability failure. | 2h |
| 10 | Send two musician/teacher notes #4 using existing relationships. | 1h |
| 11 | Record original-song Short C; keep rights labels visible. | 1h |
| 12 | Publish Short C and answer practical questions. | 1h |
| 13 | Prepare Peerlist #3 and check the current launch slot. | 1h |
| 14 | Checkpoint: ask the first testers whether they practised again alone. | 1h |
| 15 | Publish the usable project on the next eligible Peerlist slot or Scroll. | 2h |
| 16 | Fix feedback on mic denial, line recovery or private import. | 2h |
| 17 | Publish a fresh pause/repeat Short with the fixed behavior. | 1h |
| 18 | Send the remaining three teacher/musician notes #4. | 1h |
| 19 | Record demo A again if the product materially changed. | 2h |
| 20 | Publish the complete demo and Short D. | 1h |
| 21 | Checkpoint: compare starts→useful sessions→week-two returns. | 1h |
| 22 | Read r/learnGuitar rules; ask moderators before considering #5. | 1h |
| 23 | Publish one new original rehearsal Short, based on the most asked question. | 1h |
| 24 | Test an authorized private import on a fresh device; document limits. | 2h |
| 25 | Send #7 only to testers who agreed to follow-up. | 1h |
| 26 | Publish the sixth Short, showing a real practice improvement. | 1h |
| 27 | Optional Product Hunt preparation; skip if music tests are still failing. | 1h |
| 28 | Watch three people begin without instructions; repair the first obstacle. | 2h |
| 29 | Ask which song or practice situation would make people return. | 1h |
| 30 | Report the actual funnel, device failures, returners and gap to target. | 2h |

If following fails for multiple testers, pause invitations and fix it. If a clip spreads, answer musician questions and make a second honest demonstration; do not add a song library you have no rights to distribute.
