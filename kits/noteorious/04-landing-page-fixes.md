# Noteorious — Landing page fixes

Home/privacy read 29 October 2026. Purchase, installation and actual recording were not tested. The page is live; the conversion gate is a real compatible-Mac first note.

## 1. Put setup/compatibility next to payment

Current headline: “You talk. It writes.” CTA: “Pay & Download for Mac.” The page states $5 once, macOS 14.4+, Apple silicon M1+; privacy adds about 3.9 GB initial models.

Supporting copy:

> **One agreed call. Checked decisions and next actions.**
>
> Apple-silicon Mac, macOS 14.4 or later. $5 once for up to 2 Macs. First setup downloads about 3.9 GB of models before local processing is ready.
>
> **See the real setup and test result**

Keep payment visible, but let someone assess compatibility/setup before buying. Do not advertise Intel support or an unverified free trial.

## 2. Explain recording openly

“No bot joins” can be misread as invisible recording. Add:

> Tell participants and obtain the appropriate agreement before recording. No bot guest does not remove that responsibility. Use a non-sensitive test conversation for the first run.

This is practical product guidance, not a statement of every jurisdiction's recording law. Never make covert recording the acquisition hook.

## 3. Replace the perfect sample with a checked real result

The hero shows sample decisions/actions. Add an actual consented test with the original short conversation and corrections. Use your own script/participants, not a private customer meeting.

Labels:

> What was said → what the app drafted → what we corrected.

Owners/dates should be “when mentioned,” as the page already says. Do not invent a date to make the checklist look complete or call a speaker name verified from a screenshot.

## 4. Clarify manual versus automatic start

The page says “Press Start Recording” and also advertises automatic meeting detection/start. Show the current release's actual mode, permissions and visible recording indicator. Test each supported app before claiming “works with every call app.”

Copy:

> Check that recording is active and permitted in this mode. Confirm what audio is captured before relying on the notes.

Do not present a single Zoom test as proof of all apps/languages.

## 5. Make local/network boundaries exact

Privacy says meeting processing/transcripts stay local, but model download, license activation and anonymous install/daily counts use the internet. Preserve that nuance:

> Meeting content is processed locally under the stated release design. Setup, license and anonymous usage counts use the network. See exactly what is sent before you decide.

Do not say zero telemetry or never internet. Test deletion and the actual local-record location before promising controls. No recording was made in this review.

## 6. Observe three real first runs

Use compatible willing adults/your own test materials. Test download, install, model-ready state, permissions, consented recording/import, checked output and copy/export. Network loss, denied permissions and interrupted model download need clear recovery. If essential steps fail, pause promotion and repair them.

Do not tell users to disable macOS security to make installation work. Make support and refund terms visible before payment; do not invent a signing/notarization claim.

## 7. Mobile/share reality

Mobile visitors can watch a demo, but cannot complete a native-Mac install there. Show desktop requirements immediately. Mask license/email fields on the after-purchase page and keep real transcripts out of web replay.

Suggested title: “Noteorious—your Mac call into checked next actions.” Description: “Apple silicon, macOS 14.4+. $5 once. Local meeting processing with setup/network details explained.” Preview privately with a test conversation only.
