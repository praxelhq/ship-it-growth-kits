# Postifyy — Video scripts

Record your own voice and browser. Use a project you actually built. Caption the important words, enlarge the text and hide personal profiles. No paid editor or rendered commercial is needed. Never fake a successful publication or recruiter response.

## A. The honest project demo — 60 seconds, horizontal

**Use:** student clinic opening, LinkedIn native video, the campaign page. **First two seconds:** “You can explain your project. Start there.”

| Time | Shot / on-screen text | Spoken line |
| --- | --- | --- |
| 0–8s | Your empty LinkedIn compose box, then your project on screen. Text: “A real project. No post yet.” | “I can explain this project to a friend. Writing the first public sentence is the hard part.” |
| 8–20s | Postifyy voice input; record the actual short explanation. Text: “What I tried / what broke / what changed.” | “I tell it what I made, one problem I hit, and the choice I made. I leave out private team information.” |
| 20–35s | Show generated choices at readable zoom. Highlight a sentence you correct. | “Now I check the claims. This line is too strong, so I rewrite it. A better hook is not worth an invented result.” |
| 35–48s | The approved draft beside its original transcript. Text: “My facts. My edit.” | “I keep the version that sounds like me. I can copy it or approve this exact wording before scheduling.” |
| 48–60s | Only show a real completed export or approved action. End card: `postifyy.in` / “Three posts free in total.” | “That is one project post, not a promise of a job. Try the public demo first if you want to see the flow.” |

Record the authenticated steps for real before using this script. If you cannot complete them, stop filming and fix the flow; do not substitute an animated mockup and call it a demo.

## B. The first-post hook — 20 seconds, vertical

**Use:** LinkedIn short video, Reels and Shorts if those accounts already exist. **First two seconds:** “Don't start with ‘thrilled to announce’.”

| Time | Shot / text | Voice |
| --- | --- | --- |
| 0–4s | Type the phrase, then delete it. | “Don't start with ‘thrilled to announce’.” |
| 4–10s | Show a project decision written as one sentence. | “Start with the choice you made and why. That gives someone a reason to keep reading.” |
| 10–16s | Original voice note beside corrected draft. | “Say it aloud first. Then edit the draft until every claim is yours.” |
| 16–20s | URL and public-demo button. | “That is the first Postifyy exercise. Three posts free.” |

Write the actual decision before recording. Do not use a made-up “cut costs by 40%” example as though it happened.

## C. The fact-check hook — 30 seconds, vertical

**Use:** a useful standalone LinkedIn post before the clinic. **First two seconds:** “AI wrote that you led the team. Did you?”

| Time | Shot / text | Voice |
| --- | --- | --- |
| 0–6s | A clearly labeled demonstration draft: “I led the team.” Red underline. | “AI wrote that you led the team. Did you?” |
| 6–16s | Change it to the true contribution in your own project. Text: “Role / number / result.” | “Check your role, every number and every result. If you did one part, say the part. That is still useful work.” |
| 16–25s | Show the approve control without activating it. | “Postifyy helps with the wording. It cannot give you permission to invent the facts. Read the exact words before approving.” |
| 25–30s | Checklist fills the frame; URL small at bottom. | “A short true post beats a polished false one.” |

This example is a teaching draft, not a claim that Postifyy generated that sentence. Label it accordingly.

## D. One free scheduled post — 25 seconds, vertical

**Use:** answer a real user question about the free plan. **First two seconds:** “Three free posts means three in total.”

| Time | Shot / text | Voice |
| --- | --- | --- |
| 0–6s | Free plan card at readable zoom. | “Three free posts means three in total, not three every month.” |
| 6–15s | Show approval, chosen time and the one-post allowance. | “One scheduled post is included so you can try the whole workflow. Check the words and the time before you confirm.” |
| 15–21s | Edit one word in a test draft and show the actual reapproval state. | “If the words change, they need approval again.” |
| 21–25s | Public demo link. | “Try the web app. The extension is still coming soon.” |

Only keep the reapproval shot if the current test demonstrates that behaviour. Otherwise film the limit explanation and file the discrepancy as a fix.

## Bank once, reuse carefully

Capture five clips: original spoken explanation, draft choices, the factual edit, exact-word approval, and completed export. Keep one clean uncropped master. A readable correction is your signature shot. Do not publish a student's voice or draft without permission, and never show sign-in emails or access links.
