# F1 StratSim — Video scripts

Use authorized game capture and original diagrams, not broadcast race footage. No betting, prize promises, real-driver endorsement or invented game result. Get permission before any class name/score appears publicly.

## A. Decision-to-explanation demo — 60 seconds

0–2s: **“What am I giving up if I box now?”**

2–12s: show one real accessible scenario after entry/visibility tested. “This is a simplified rules-based model, not live race data.”

12–27s: point to actual tyre, gap and pit-loss values. “These are the conditions for this run.” Don't use an unrelated real race's data.

27–42s: make one genuine call and show modelled laps, cuts labelled. “Let's see what the model does.”

42–54s: inspect actual explanation and one limitation. “A result should tell me which assumption mattered.”

54–60s: URL and **Model/game score · check access/leaderboard visibility**. If entry or simulation fails, fix it before filming a successful outcome.

## B. Tradeoff hook — 18 seconds

0–2s: **“A cheap stop can still cost track position.”**

2–12s: own fictional diagram labelled as an explanation, or verified actual game conditions. “Compare what you gain with what you give up.” Don't invent a source-confirmed racing rule or output.

12–18s: scenario/URL. “Try explaining the call.”

## C. Score hook — 20 seconds

0–2s: **“The badge isn't the lesson.”**

2–12s: actual result explanation after verified play. “Which input changed the outcome? What would you test next?”

12–20s: model-limit label/URL. “Strategy IQ is a game score.” No validated skill claim.

## D. Entry-honesty hook — 20 seconds

0–2s: **“Before entering a name, know where it appears.”**

2–12s: show actual class-name gate with no data entered. “This says shared class leaderboard. Decide with that visibility in mind.”

12–20s: accessible public guide and URL. Don't submit a fake person's identity or film private leaderboard names to fill the clip.
