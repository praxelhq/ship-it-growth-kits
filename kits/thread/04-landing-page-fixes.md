# Thread — Landing page fixes

Based on [threadknits.in](https://threadknits.in/), checked 29 October. No pattern generation, swatch or checkout completion was performed during research.

## 1. Put the test-mode boundary before the purchase

The page shows **“$5 one-time”**, **“Buy the Pattern Pack”**, and a clear test-mode notice. Make the button itself unambiguous: **“Try test checkout — no real charge.”** Keep the thank-you page's current distinction: a redirect is not a verified receipt. Do not claim real sales or production fulfilment until verified.

## 2. Make the first project smaller

Current headline: **“See it. Make it.”** CTA: **“Create My Pattern.”**

Suggested headline: **“Start with a pattern you can actually try.”** Support: **“Add an inspiration photo, your skill level and yarn. Review the instructions and make a small swatch before committing to the full project.”** Primary CTA: **“Draft a beginner pattern free.”**

## 3. Replace visual-only proof with real making evidence

Current section says **“Made with Thread.”** Every image under that label needs a traceable output and a real made object. If it is illustrative, say **“Illustration of a possible project, not a tested output.”** Best replacement: input photo, yarn/tool details, first rows, final object and corrections. Do not hide edits needed to make it work.

## 4. Make uncertainty a usable input

The form already allows **“I don't know.”** Keep that. When gauge/tool size is unknown, say: **“We'll suggest a starting point. Make a gauge swatch and adjust before a fitted project.”** Don't turn an unknown measurement into a precise fit guarantee.

## 5. Explain saved patterns and uploads

Current text says saved patterns stay in this browser. Add: **“Clearing this browser's data may remove saved patterns. Save a copy you can keep.”** For photos, link the actual processing policy; do not imply local-only inference merely because saved outputs are local.

## 6. Check beginner comprehension on a phone

Use a simple project, missing yarn details and a malformed image. On 390px, check photo selection, long instructions, stitch abbreviations, saved-pattern retrieval and failure recovery. A loading spinner must not silently become a fabricated pattern.

Preview title: **“Thread — draft and test a beginner knitting or crochet pattern.”** Show a real swatch with permission or a clearly labelled illustration. The creator's first row is better proof than another glossy hero image.
