# FuelBar — Video scripts

Screen-record on a real supported desktop, narrate with your phone microphone and use large captions. Hide account identities, local file paths, credentials and private code. No rendered video needed. If a reading is synthetic, label it throughout.

## A. Which tool has capacity? —60 seconds

**Where:** landing page, Peerlist and developer session. **Hook:** “Before another long task, check the window.”

| Time | Shot | Spoken line |
| --- | --- | --- |
|0–2 s|A real usage window, source identity blurred|Before another long task, check the window.|
|2–12 s|Windows desktop and FuelBar pill|I use more than one coding tool. This keeps their supported limits here.|
|12–25 s|Open actual ring/details|This is the session window, this is the reset, and this is when it was read. A percentage alone isn't enough.|
|25–38 s|Show a genuine stale/example state, labelled|If the source stops updating, I want to see that, not mistake an old number for live capacity.|
|38–50 s|Show the actual supported tool switch/finish state|I can check the next tool without searching several tabs. This isn't a bill estimate or unlimited usage.|
|50–60 s|Price and OS requirements|FuelBar is₹249/$2.99 once at today's price. Read the source and install details before buying: fuelbar.app.|

Do not run a costly coding session solely for a video. Use an existing normal workflow or a clearly labelled demo state.

## B.84%of what? —20 seconds

**Where:** DEV embed and owned feed. **Hook:** “84%isn't a complete answer.” Show three synthetic cards: five-hour session, weekly pool, monthly requests. Say, “Same percentage, different decision. Label the window and reset.” End on a real FuelBar detail view and URL. No invented provider plan limits or guaranteed refresh rate.

## C. Old is different from empty —25 seconds

**Where:** support preview and Peerlist gallery. **Hook:** “A missing reading isn't zero capacity.” Show a labelled stale state and help instructions. Say, “Open the provider app through its normal sign-in path; the meter should tell you what it last knew.” Show age information. End: “If it can't verify a new reading, it shouldn't pretend.” Don't display sign-in tokens or ask anyone to send them.

## D. Windows first — 30 seconds

**Where:** developer-club invitation and LinkedIn. **Hook:** “This little pill is for my Windows workflow.” Show the actual Windows pill moving to an edge, supported account details and a session-finished indicator. Say, “The Mac has good free options too. I'm showing the Windows path because that's where I want feedback.” End with the one-time price and OS requirements. Never simulate an untested installer or claim a rival has no Windows build without checking its current release.

Bank the pill idle, hover details, freshness label, finish state and static price clips. One real continuous detail interaction establishes more than a montage of percentages.
