# Cutroom — Phone-demo scripts

Use an owned short clip and fictional brief. Record your screen and voice with an editor who agreed to participate. Mask emails, access links and client material. Every successful shared action must be shown on the actual second device, not fabricated by switching screenshots.

## A. The right version — 65 seconds

0–3 s: two sample file names. **“Which cut did you approve?”**

3–15 s: create a real sample project and brief. “Start with one job and the editor you already work with.”

15–30 s: open the actual current cut and add a timestamped note if supported. “This change belongs to this version.” Leave one interaction continuous.

30–45 s: show the editor's actual authorized view. “Check that the other person sees the same file and instruction.” If sharing is not verified, stop at the local preview and label the missing step.

45–55 s: final-version decision in the real workflow. “Approval needs an exact file, not another vague message.” Do not fake an approval control.

55–65 s: allowance and URL. “Three video exports total on Free. Paid checkout is not connected. cutroom.space.”

## B. Review hook — 20 seconds, Short

0–3 s: sample note “change the intro” beside two cuts. **“The note is clear. The version is not.”**

3–12 s: actual version and timestamp in Cutroom. “Tie the change to the cut you mean.”

12–20 s: recipient view only if verified and URL. “Test one real review with your existing editor.” No claim of guaranteed faster delivery.

## C. Allowance hook — 25 seconds, LinkedIn

0–3 s: Free plan card. **“Three total is different from three per month.”**

3–15 s: published export rules. “Free exports do not reset. Re-downloading the same exported version is not a new slot.”

15–25 s: disabled paid button. “Paid checkout is not connected yet. Know the limit before starting the job.” Hold URL.

Capture first project, real file/version, timestamp association, second-device access if verified, exact approval, allowance counter and disabled checkout. Label cuts in upload time. Never invent editor testimonials, client jobs or export success.
