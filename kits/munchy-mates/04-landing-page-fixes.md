The [live page](https://munchymatess.app/) was rendered 29 October and separately returnedHTTP 200; old roster downtime is stale. **Buy for Mac** resolves to a production Dodo checkout link. The kit did not pay, install the binary or test licence delivery.

## 1. Put hardware and paid status beside the emotional promise

Current H 1: **“A tiny friend who lives on your Mac.”** Keep its warmth. Subhead replacement: **“A cat, pup or bunny above your Dock, hungry with your battery and quiet when you need it. Apple silicon · macOS 14+.”**

CTA replacement: **“Try the web demo”**, with secondary **“Buy for Mac — current launch price $5.”** Don't imply a trial download that doesn't exist. Show the actual checkout total/currency before payment, and make licence delivery/support clear.

## 2. Prove the battery reaction in the actual app

Current interactive demo can be dragged and fed files. Add a real 15-second Mac recording labelled **“Actual Mac app”**: low battery, plug in, pet response. Keep **“Website preview”** on the browser toy. A simulated battery toggle is fine for the preview, not proof of hardware behaviour.

## 3. Make file consequences impossible to miss

Current copy says files go to Trash. Put **“Moves this file to your Mac's Trash. Restore it there before emptying Trash.”** at the relevant interaction. For PDF tools use **“Creates a separate result; keeps your original.”** These are different actions and shouldn't share a vague “safe files” badge.

## 4. Explain the online exception consistently

The page says offline operation and later explains one licence activation plus update checks. Replacement: **“Online once for licence activation. Pet and file tools then work offline. When connected, the app checks for updates; choose automatic or ask-first in Settings.”** Verify the current build actually matches before publishing.

## 5. Make the $5 limit real

Current price is $5 against $7 for the first 100 users. Show only genuine remaining allocations if the licence system tracks them. Otherwise use **“Launch price currently $5; your final price is shown before checkout.”** [Extra pets](https://munchymatess.app/pets/) cost $3 each, so clarify the three included pets and optional additions before payment.

## 6. Put quiet and screen-sharing controls in the first scroll

Current page has call/Focus/mute and hide-from-screen-share features lower down. Add the short line **“Your call starts. Your pet goes quiet.”** with an actual settings clip. Test in the real supported apps before claiming every call is detected.

The current phone message says to open on a Mac. Add a copy-link action: **“Save this for your Mac.”** Don't put a phone user into payment before revealing incompatibility. Keep the existing pet visual; title **“Munchy Mates — a battery-reactive pet for Apple silicon Macs”** and description with macOS 14+, paid price and web preview.
