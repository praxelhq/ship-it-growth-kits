# SecretAIry —Measurement

**Target:10 real business/organisation customers**, under [policy](../../TARGET-POLICY.md). Four tests: genuine organisation; its own permitted meeting data onboarded; independent use in the last seven days; privately known responsible decision-maker name/phone. Ten committee members or meetings are not ten organisations. Keep identity/contact checks private.

Signup is an actual organisational workspace, currently unavailable to new users according to the page. Activation is a real organisation reviewing/approving its own record and tracing an agreed action to its source. An assisted sample or walkthrough is design research, not activation. If live access remains unavailable, qualifying live adoption is zero.

Private baselines unknown: existing organisations, permitted workspaces, own records, approvals, actions/source retrieval, independent recent use, actual plan/payment status. Capture rank/reading/period/sync from [profile](https://shipped.money/p/secretairy); unknown isn't zero, and don't sum rolling readings.

Check existing [Clarity](https://clarity.microsoft.com/) before tagging. Exclude transcripts, papers, minutes, action text, names, private links and account screens. Aggregate events only: actual_workspace_created, own_draft_reviewed, exact_version_approved, source_action_opened, independent_return. Analytics must not silently extend actual retention or collect confidential meeting contents. A draft-generation event does not establish correct minutes.
