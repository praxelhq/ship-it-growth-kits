# SecretAIry — Video scripts

Use fictional minutes and your own screen/voice. No real board papers, member identities, private meeting links or organisational decisions. Every walkthrough frame stays labelled sample.

## A. From draft to agreed action —65 seconds · own LinkedIn

0–3 s: fictional action beside draft minutes. **“Was this actually approved?”**

3–18 s: actual walkthrough meeting papers/transcript entry. “Start with authorised source material. This is fictional.”

18–32 s: draft wording and owner review. “A generated draft isn't the committee's decision.”

32–47 s: actual sample approval boundary and source-linked action. “The action should point to the exact reviewed record.” Don't stage a live approval if only demo controls exist.

47–57 s: source decision lookup in the walkthrough. “Later, find why the action exists.”

57–65 s: closed-registration disclosure and URL. “Explore the sample; live signups are currently closed.”

## B. Wording hook —20 seconds · Short

0–3 s: draft versus reviewed sentence. **“A confident sentence isn't an approved minute.”**

3–13 s: fictional correction with its context. “Check the decision and responsibility before approval.”

13–20 s: sample label and URL. No legal-certification promise.

## C. Memory hook —25 seconds · administrator follow-up

0–3 s: action with missing source. **“Which meeting agreed this?”**

3–16 s: actual demo source link/version. “Keep the action tied to the record that created it.”

16–25 s: approved/draft distinction and current-release boundary. “Find the source, not a guessed summary.” No fabricated working customer workspace.
