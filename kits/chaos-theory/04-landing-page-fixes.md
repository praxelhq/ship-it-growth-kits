# Chaos Theory — Landing-page fixes

Rendered interface checked 29 October 2026. No campaign completion, room join, account or payment was submitted. The fetched menu's presence is not a tested multiplayer experience.

1. **Put one mission ahead of all the modes.** Current title/tagline: “CHAOS THEORY” / “Reality is unstable. Your mission isn’t.” Add **“Start Asteroid Run: recover 5 fuel cores, clear the lane, reach extraction.”** Keep **“Start campaign”** as the focal action. De-emphasize hangar/dailies/Plus until a new player has acted once.

2. **Teach controls at the first meaningful moment.** Current “How to play” is a menu item. Add a brief device-appropriate control cue beside the first mission. Write the actual keyboard/touch inputs only after verifying them; none were extracted reliably enough to invent here. Test with three first-time players who receive no coaching.

3. **Explain the private-room route clearly.** Current “Play with friends” promises 2–6 private players. Add **“One person hosts. Share the private code only with invited friends. Wait until the group is ready.”** Match the real process; test a host and guest on separate devices/networks. Show a visible join error and reconnect instruction rather than an infinite spinner.

4. **Make sound opt-in and obvious.** Current “Tap to enable sound” is useful. Keep it visible and preserve a playable muted state. Don't autoplay a loud effect when someone opens an invitation during a class break. Test the browser's actual audio permission behavior.

5. **Explain stars and progress without fake traction.** Current counters include missions 0/10, arena 0/10 and ships 1/4. Add **“Your progress on this device/account”** using whichever storage model is actually implemented. Do not call these personal counters community-player totals or invent cross-device sync.

6. **Clarify Chaos+ before any purchase.** Plus is visible but no current price was established from the page. State the actual features, access and charge beside its action before promotion. Do not label it free, paid or recurring from the menu name alone. Separate demo unlocks from real transactions if they exist.

7. **Make the shared preview actionable.** Title **“Chaos Theory — one arcade mission, then a private room”**; description **“Recover fuel, clear the lane and reach extraction. Invite a small group after the first mission.”** Preview a public homepage link and a private invite separately; never expose active codes in public metadata. On phone test controls, browser bars, pause/resume and readable objective text. No performance benchmark was measured here.
