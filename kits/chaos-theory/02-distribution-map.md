# Chaos Theory — Distribution map

**Your main invitation is a working small private room, backed by a quick solo mission.** Do not recruit 100 disconnected individuals when the experience needs two or three friends at the same time.

|Route|Specific action and boundary|Planning outcome, not benchmark|Copy|
|---|---|---|---|
|Five existing friend-group hosts|Personal notes on Days 4/11, then let interested hosts invite their own willing friends. No unsolicited group additions.|5 × 40% host interest × 3 players = 6 starters; at 60% mission completion,3–4 activations.|#1|
|Your own YouTube channel|Six original clips and one full first-mission demo. Follow [YouTube policies](https://www.youtube.com/howyoutubeworks/policies/community-guidelines/).|6 × assumed 200–800 views × 1% visit = 12–48 visits. Zero possible.|#2,videos|
|[itch.io](https://itch.io/docs/creators/getting-started)|Free project page, original screenshots, external browser link or owned HTML5 build. Explain control/device limits and preview before publication.|0–20 visits; free listing is not guaranteed discovery.|#3|
|Existing campus game organizer|One optional six-person test in Days 10–13, after checking other cohort games' slots. No public room code or surprise filming.|6 invited ×50% attend = one 3-person room; count actual joins, not invitations.|#4|
|[r/WebGames rules](https://www.reddit.com/r/WebGames/about/rules)|Read current rules/ask moderators; extraction did not expose rule text. No promotional link until permitted.|Zero until permission.|#5|
|[Peerlist](https://peerlist.io/launchpad)|Show usable game and a tested room flow; check current slots. No vote trades.|0–10 useful testers, upside only.|#6|

Read the public [CrazyGames catalogue](https://www.crazygames.com/) as an alternative player's menu, not a place you can automatically submit or advertise. Any platform distribution agreement needs its own verified requirements; it is not in this forecast. A campus bulletin can carry #4 with organizer permission. No outside newsletter placement is assumed.

This calendar supports tens of players. At an assumed 50% visit→first-mission-start rate, 1,000 starts need 2,000 qualified visits. At 1% video-view→visit, that needs 200,000 views. A six-clip plan does not prove that reach. Measure whether one completed session leads to a real new host before calling the game viral.
