# Shayari NHE 01 — Video scripts

Use fictional ordinary details, a controlled admitted account and no real chat, access code, passphrase or personal identifier. Show AI identity and actual data limits. Screen recording plus your voice is enough; the persona's human-looking image is not evidence of a human relationship.

## A · What was actually remembered? · 60 seconds · own feed / product demo

| Time | Shot / text | Say |
| --- | --- | --- |
| 0–2s | Synthetic hobby card. **“What did it keep?”** | “I want to check the memory, not just hear a confident reply.” |
| 2–12s | AI identity and access notice. | “This is Shayari, a non-human conversational system, on a controlled test account.” |
| 12–25s | Enter fictional project detail, label Demo. | “The detail is invented and non-sensitive.” |
| 25–38s | Actual Memories view if supported. | “Here is what it stored. A summary may differ from the original.” |
| 38–52s | A later real test, timestamp labelled. | “I returned and asked about it. This is the actual answer, including any mistake.” |
| 52–60s | Privacy/access entry. | “Read the memory and data rules first. Current access is invite or waitlist.” |

If memory isn't visible or recall fails, show that limitation. Don't fabricate a next-day conversation or claim one correct detail proves perfect recall.

## B · Waitlist isn't admission · 20 seconds · entry help

Hook: **“This form has two different outcomes.”** 0–8s, show Create account's actual invite helper, hiding any working code. 8–15s: “A valid member code can open access. Without one, the form says waitlist.” 15–20s: “Check which you are joining before submitting.” Keep price/access terms visible; don't create an account just to film.

## C · Three versions of a detail · 25 seconds · technical short

Hook: **“Said, stored, inferred.”** 0–8s, show a labelled fictional original detail. 8–17s, compare actual memory and later reply if available: “These aren't always identical. I want to see the difference.” 17–25s: “Correction should be a working route, not a hidden promise.” If correction is email-mediated, say so; don't stage an in-app Delete button.

## D · A reply isn't a person · 20 seconds · public introduction

Hook: **“Keep the AI label in the screenshot.”** 0–8s, show public non-human disclosure. 8–15s: “A continuing persona is still software. It can make mistakes, and it isn't professional care.” 15–20s: “Try only what you're comfortable processing under the actual privacy terms.” No therapeutic claim, exclusive-dependence message or distress story.
