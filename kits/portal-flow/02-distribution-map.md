# PortalFlow — Distribution map

Lead with studios that already have a deliverable to review, after the release contract is clear. Do not recruit clients to a portal before verifying invitations and recipient access.

| Route | Execution and permission | Planned input / copy |
| --- | --- | --- |
| Existing independent design studios | Qualify a real client-review job, owner authority and permission to evaluate data handling. Start with an owned sample, not confidential client artwork. | Ten blocks of four studios = 40 approaches; #1/#2. |
| Two studio/designer introductions | Ask a known professional to forward one invitation, not share clients, briefs or private contacts. | Days 20 and 23; #4. Upside only. |
| Own [LinkedIn](https://www.linkedin.com/) | Demonstrate one version/change state and truthful local/shared boundary. | Days 9,18,26 at 09:00 IST; #3. Guess 100–500 impressions and 0–3 relevant visits/post, excluded from base. |
| One owner-controlled review test | Studio and a consenting test recipient inspect a harmless owned deliverable on separate devices only if the release supports it. | Day 22; #5. Existing-trial support. |

Base guesses: 40 approaches × 50% substantive conversations × 70% owned-work setup × 70% independent recent use = 9.8, about 10 studios. At 25% conversation, 4.9. This assumes a real usable workflow and actual permitted business data; unresolved release/persistence gates can reduce qualifying customers to zero. Ten outreach blocks occur Days 4,5,8,10,11,15,17,22,24,27. Posts/intros add zero guaranteed conversions.

Reserve Days 20–23 for shared agency-approval invitations and the owner review, as coordinated in [creator operations](../../shared/a2-creator-operations.md). Earlier individual approaches use a distinct studio list, not the same organizer. Keep graphic/design client-review studios separate from Cutroom's existing video-editor pairs and FirmQuote's fixed-price website scope. Do not send a generic agency organizer three “all your client work” pitches. One primary invitation per organizer/week; use distinct actual contact lists and a single clearly described review task.

No agency newsletter, designer community, Discord or professional-group promotion permission is established. Ask the organizer before posting. No paid directory boosts, automated DMs, scraped portfolios or pretending to commission artwork just to reach a studio owner. One relevant follow-up after seven days; stop after decline.

If the current release only supports a local demo, discovery can continue with that boundary stated, but do not count fictional records or preview recipients as customers. Track owner-only real-data use separately from actual shared review. An unverified shared-workspace heading is not permission to publish a confidential client file.
