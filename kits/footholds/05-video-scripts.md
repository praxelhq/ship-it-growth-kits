# Footholds — Video scripts

Use your own ordinary task and a disposable controlled session. No medication instructions, private habit history or diagnosis. Show the actual hosted artifact, not a staged native app. Screen capture and phone voice are sufficient.

## A · One small foothold · 60 seconds · own feed / launch

| Time | Shot / text | Say |
| --- | --- | --- |
| 0–2s | Five scattered non-sensitive objects. **“Five, not the whole room.”** | “Tonight I can start with these five things.” |
| 2–14s | Actual tiny-task selection. | “This is Footholds, an early Claude-hosted artifact.” |
| 14–27s | Choose actual five-minute timer and start after testing. | “I choose a short session for one clear action.” |
| 27–42s | Your actual action; label elapsed-time cut. | “The action counts, not just watching the timer.” |
| 42–52s | Record the actual supported win state. | “This is what I completed. It isn't the whole room.” |
| 52–60s | Platform/access/no-payment-demo note. | “Try a small ordinary task. Some features need Claude sign-in; Plus is a demo.” |

If start or recording fails, show that issue and repair it; don't animate a fake completed session.

## B · Smaller than the task · 20 seconds · short post

Hook: **“The project isn't a five-minute task.”** 0–8s, cross out “finish project” on your own paper. 8–15s, write “outline one paragraph”: “Make the action specific enough to begin.” 15–20s, show the actual timer: “Then test the start.” Don't claim five minutes guarantees completion of the larger job.

## C · A room needs real people · 25 seconds · access explanation

Hook: **“A focus-room card isn't a live room.”** 0–8s, show the actual unavailable message. 8–17s: “This session doesn't have shared-room access. The app says to open the Claude link while signed in.” 17–25s: “Check the real access state before expecting someone else to be here.” No seeded names or manufactured attendance.

## D · Demo means no charge · 20 seconds · pricing help

Hook: **“This isn't a paid upgrade.”** 0–8s, show $4.99/month card together with the demo notice. 8–15s: “The current action only previews Plus. No money changes hands.” 15–20s: “Judge the working task loop, not a prototype payment label.” Don't click an upgrade or create a transaction merely for the clip.
