# Shelf Test — Phone-demo scripts

Use a fictional consumer-product idea and non-confidential inputs, your screen recorder and voice. No actual buyer contacts, private product costs or staged founder testimonial. If the quiz is unavailable to the current tester, show the auth boundary rather than inventing a result.

## A. One assumption, one next question — 65 seconds

0–3 s: fictional product assumption. **“What would change this decision?”**

3–17 s: actual permitted quiz entry after access verification. “This is the founder's input, not a customer answer.”

17–32 s: actual supported questions/output, labelled fictional demonstration. “The tool structures a first critique.” Leave a real interaction readable and do not invent dimensions hidden behind auth.

32–47 s: inspect one actual recommendation and list what is still unknown. “A verdict is not a purchase order. Which buyer question comes next?” Use a separate labelled note if the app cannot annotate.

47–55 s: actual save/return only when verified. “Keep the uncertainty with the test.”

55–65 s: current access/offer and URL. “Check the assumptions, then get real evidence. shelftest.in.”

## B. Verdict hook — 20 seconds, Short

0–3 s: fictional verdict with its sample label. **“Would a buyer pay?”**

3–12 s: distinguish quiz answers from a real purchase. “The quiz cannot answer for your buyer. It can help choose the next question.”

12–20 s: actual entry and URL. “Use the critique as a start, not certainty.” If no output verified, use a labelled explanatory slide instead of a fake report.

## C. Access hook — 25 seconds, LinkedIn

0–3 s: actual Test my idea/sign-in handoff. **“Can a new founder finish the first test?”**

3–15 s: verified entry/save behavior or explicit boundary. “A working landing page is not the same as a saved usable report.”

15–25 s: truthful pilot/offer note and URL. “Explain access before inviting a group.”

Capture exact headline/CTA, auth development-mode boundary, actual quiz/report only if verified, limitations, saved-test behavior and current allowance. Label shortened waits. No fabricated customer evidence, sales prediction or live-market research.
