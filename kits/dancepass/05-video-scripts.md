# DancePass — Video scripts

Use an owner-approved real class or label every frame as a demonstration. Don't show student faces, private messages or an unclaimed logo as partner proof. Phone voice plus screen recording is enough.

## A · The whole class decision · 55 seconds · instructor walkthrough / own feed

0–2s hook: **“Can a new dancer book this without asking five questions?”** Show the class details, not a brand animation. 2–15s: zoom through style, level, date and venue: “These details come from the instructor.” 15–28s: show price, fees and cancellation rule: “The dancer should know the commitment before tapping Book.” 28–43s: use a controlled test booking and label it: “Now check the actual handoff reaches the responsible instructor.” 43–55s: “Public studio entries are unclaimed until reviewed. I'm testing real classes locally, not calling a directory a partnership.” Hold URL.

If booking isn't ready, end at the actual limitation and repair it; don't fabricate a confirmation screen.

## B · Listed is not partnered · 20 seconds · LinkedIn / X

Hook: **“This studio is listed. That doesn't mean it's our partner.”** 0–8s: enlarge the real Unclaimed disclaimer. 8–15s: “Public information helps discovery. Only the instructor can confirm a current workshop and agree to the booking workflow.” 15–20s: “That's the distinction DancePass needs to keep clear.” No implied endorsement.

## C · Beginner question · 25 seconds · instructor-owned announcement

Hook 0–2s: **“Is this class actually for beginners?”** 2–10s: show the owner's approved level and prerequisites. 10–18s: show who to ask when unsure: “If the description doesn't answer this, ask the instructor before paying.” 18–25s: “A good booking page removes a doubt; it doesn't pressure the wrong dancer into a class.”

Capture one readable event page, real fee/cancellation text and the controlled booking result. For student-facing video, get instructor approval and use the actual event link; don't advertise a hypothetical date.
