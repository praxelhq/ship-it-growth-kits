# Bond — 30-day calendar

Daily: 15 minutes for pilot support and aggregate logging. No contacts imported, no unsolicited additions, no promotion before a real offer exists.

| Day | Main job | Time |
| --- | --- | --- |
| 1 | Establish actual supported city/offer and test entry; baseline. | 3h |
| 2 | Publish price/access/terms and a genuine pilot card. | 3h |
| 3 | Fix account/empty-circle/leave information. | 3h |
| 4 | Record demo A and hook B, with correct pilot status. | 2h |
| 5 | Invite ten willing adult prospects for listening/entry testing (#1). | 1h |
| 6 | Confirm a genuine first circle only if host/time/cost are ready. | 2h |
| 7 | Checkpoint: offer understood and real local willingness. | 1h |
| 8 | First short B / #3 at 19:30 IST. | 1h |
| 9 | Ask two local alumni/colleague-group admins for permission. | 30m |
| 10 | Invite ten more prospects to the confirmed pilot offer. | 1h |
| 11 | First LinkedIn #4 at 12:30 IST. | 2h |
| 12 | Share #2 in first approved local group. | 1h |
| 13 | Support actual pilot logistics; no assumed event attendance. | 2h |
| 14 | Checkpoint: real circle joins and voluntarily confirmed participation. | 1h |
| 15 | Fix the main offer/coordination problem. | 3h |
| 16 | Second short C / #3. | 1h |
| 17 | Share #2 in second approved group, if current capacity exists. | 1h |
| 18 | Send organizer note #5 once to one existing local organizer. | 30m |
| 19 | Support a real plan or explain why none is open yet. | 2h |
| 20 | Ask three willing members about the first-plan clarity. | 1h |
| 21 | Checkpoint: people want a second plan without pressure? | 1h |
| 22 | Optional Peerlist builder feedback #6, zero local-supply assumption. | 1h |
| 23 | Fix a real access/coordination issue. | 3h |
| 24 | Second LinkedIn #4 about the actual pilot lesson. | 2h |
| 25 | Third short D / #3 with real learning. | 1h |
| 26 | One follow-up only to willing prospects who asked for details. | 1h |
| 27 | Improve the existing circle instead of opening another city. | 2h |
| 28 | Checkpoint: unique members, actual participation and return interest. | 1h |
| 29 | Strengthen the route producing genuine local participation. | 2h |
| 30 | Report members, real circle activity, capacity and target gap. | 2h |

The calendar doesn't invent a scheduled event. Actual dates must be confirmed by the operating team before any invitation, and postponed/cancelled plans must be communicated clearly.
