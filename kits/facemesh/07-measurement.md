# FaceMesh — Measurement

**B2C target: 1,000 signups in 30 days.** For the optional-account preview, count **distinct consenting adults' first meaningful preview sessions** as the signup equivalent. Report **completed previews** and **verified paid reports** beside it. Repeated photos/scans are not new people.

No private dashboard or scan was accessed. Record actual baseline before promotion.

| Baseline | Source |
| --- | --- |
| First consented preview sessions / last 7 days | Aggregate status events, deduplication limits stated |
| Preview completions/failures | Error/status counts only |
| Real $1.99 reports, fulfilment failures/refunds | Payment/report records, excluding tests |
| Consent/processing comprehension | Voluntary feedback without photos/results |
| Traffic/referrers | Existing consented analytics / [Clarity](https://clarity.microsoft.com/) |
| Course metric/rank/time | [Profile](https://shipped.money/p/facemesh) |

Check existing Clarity before adding scripts. Exclude face images, camera frames, geometry values, report text, account/payment fields and tokens from replay/analytics. Events: `notice_viewed`, `consent_confirmed`, `preview_started`, `preview_completed`, `report_payment_verified`, `report_delivered`, `deletion_requested` as status only.

| Checkpoint | What matters | Response |
| --- | --- | --- |
| Day 7 | Five willing adults understand consent and complete preview | Fix unclear processing or the first blocked step. |
| Day 14 | Users distinguish measurement from interpretation | Revise labels/demo if a score sounds like objective truth. |
| Day 21 | Paid reports arrive correctly and expectations match | Any paid-but-missing report: repair recovery before promotion. |
| Day 30 | Actual first sessions against 1,000; previews/reports/refunds beside it | Report honest gap and informed-user acquisition. |

At 30% visitor-to-preview-start, 1,000 needs about 3,334 qualified unique visits. The scheduled tests may only yield dozens. Replace rates after three clips; do not inflate counts using repeated scans or mock faces.

No metric establishes beauty, personal worth, medical status or future social success. Policy statements are not an independent implementation/compliance audit. Course 24-hour readings overlap and are not cumulative users. The useful proof is a clear, consented experience with honest limits and reliable fulfilment.
