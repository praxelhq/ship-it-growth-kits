# Linkup — Video scripts

Use fictional profiles and a non-sensitive work blocker. Real people appear only with explicit permission and accurate availability.

## A. Help-brief demo — 60 seconds

0–2s: **“Why would this person be the right ask?”**

2–15s, enter a fictional project blocker. “Start with what you need to move forward.”

15–30s, inspect an explained fictional match. “This is a demo profile. The important part is the evidence behind relevance.”

30–45s, edit the first-message draft. “Make the request specific and easy to decline.”

45–55s, show no-send state. “The demo doesn't contact anyone; you choose the next step.”

55–60s: URL and **Five fictional profiles · no LinkedIn import**.

## B. Hook — 15 seconds, Short

0–2s: “Can you make the ask smaller?”

2–10s: vague request → focused question in the demo. “A bounded question is easier to answer.”

10–15s: fictional-profile label and URL.

## C. No-match hook — 20 seconds, LinkedIn

0–2s: “No match is better than a made-up expert.”

2–12s: show the actual empty/unsupported state after it works. “If the directory can't support the request, say so.”

12–20s: refine the brief. “Relevance needs evidence and permission.” Don't fake a real directory result.

## D. Consent clip — 20 seconds, Story

0–2s: “A profile isn't permission for everything.”

2–12s: show actual discoverability/help preferences using an owned test account. “The member chooses what they offer and who can find them.”

12–20s: toggle visibility off and show the actual result. If unavailable, fix the control before claiming it exists.
