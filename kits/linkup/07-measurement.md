# Linkup — Measurement

**B2C target: 1,000 signups in 30 days.** Count confirmed real member accounts once. Report **actionable help briefs**, **relevant opted-in matches** and **consensual real conversations** beside it. The five-fictional-profile public demo is a separate product-learning metric, not real membership.

Private records weren't accessed. Record unknown baseline values before promotion.

| Baseline | Source |
| --- | --- |
| Confirmed real members / last 7 days | Authentication records, no demos/tests |
| Discoverable members and bounded help preferences | Actual permission records |
| Useful briefs and supported matches | Aggregate status with quality sampled privately |
| Both-party voluntary conversation confirmation | Opt-in feedback, no message collection |
| Traffic/referrers | Existing consented analytics / [Clarity](https://clarity.microsoft.com/) |
| Course metric/rank/time | [Profile](https://shipped.money/p/linkup) |

Check existing Clarity before adding scripts. Exclude personal briefs, profile contact information, drafts and private messages from replay. Events: `member_confirmed`, `discoverability_enabled`, `brief_saved`, `supported_match_viewed`, `draft_copied`, `conversation_confirmed`. Copying a draft does not establish a message was sent or answered.

| Checkpoint | Evidence | Decision |
| --- | --- | --- |
| Day 7 | Ten willing members with clear help needs/offers | Recruit missing expertise before public claims. |
| Day 14 | Matches use real consented evidence, not samples | Unsupported matches: fix directory/criteria, don't invent supply. |
| Day 21 | People voluntarily confirm useful conversations | If drafts don't lead anywhere, inspect ask precision and availability. |
| Day 30 | Members against 1,000; real conversations/repeats beside it | Report honest gap and a useful next circle. |

At 20% visitor-to-member, 1,000 needs 5,000 distinct qualified visits. The initial tests may yield only dozens. More seekers won't repair missing willing helpers. Recalculate with actual rates by Day 14.

No public price was visible; count payments only if a real verified offer exists. Course 24-hour readings overlap and are not cumulative members. A fictional profile click, automatic draft or claimed future connection is never a completed introduction.
