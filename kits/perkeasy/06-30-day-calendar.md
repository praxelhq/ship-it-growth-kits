# PerkEasy — 30-day calendar

Start with a tested one-category account/data path and actual US employee relevance. Daily replies/aggregate logging take 25 minutes within these times. Twenty invitations maximum = five each on days 5,10,15,20. Six posts = days 5,10,15,20,25,29. If relevant contacts don't exist, lower the forecast and seek permissioned introductions; don't substitute unrelated classmates.
