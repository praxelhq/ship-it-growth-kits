# SquawkWire — Video scripts

Use an actual permitted public source or a clearly labelled synthetic headline. No portfolio, broker balance, private watchlist, account email, target price or trade. Record only after final policies and the real preview work.

## A · Source before score · 60 seconds · own feed / listing

| Time | Shot / text | Say |
| --- | --- | --- |
| 0–2s | Source/time fields. **“Which time is this?”** | “The headline reached me now. When was it published?” |
| 2–14s | Actual supported feed sample. | “This is the current feed and its stated delay, not a real-time promise.” |
| 14–29s | Open original publisher without copying its whole article. | “I check the original and its date.” |
| 29–43s | Actual automated label, scope visible. | “This label is an interpretation. It may be wrong and isn't a price prediction.” |
| 43–53s | Show missing coverage/uncertainty if present. | “What the dashboard hasn't checked should stay visible.” |
| 53–60s | Current entry/terms. | “Inspect the source first. Squawkwire dot app. No trade required.” |

If no actual source-linked feed is available, film a manual source-reading lesson, labelled as such; don't stage a private terminal result.

## B · Two clocks · 20 seconds · short post

Hook: **“Publication time isn't retrieval time.”** 0–8s, two labelled fictional times. 8–15s: “A dashboard can receive an old item now. That doesn't make the news new.” 15–20s: “Check both and the tier's actual delay.” No fabricated latency benchmark.

## C · Positive isn't profitable · 25 seconds · literacy clip

Hook: **“A tone label isn't a trade.”** 0–8s, clearly synthetic sentiment card. 8–18s: “Positive wording, company significance and future market outcome are different questions.” 18–25s: “Open the original and keep the interpretation limited.” No security recommendation or chart implying returns.

## D · A template isn't a finished policy · 20 seconds · candid release update

Hook: **“Don't ask for trust with an unfinished policy.”** 0–8s, show the current template notice without private operator details. 8–15s: “I'm resolving actual support, data and billing commitments before opening a wider account campaign.” 15–20s: “The final page must match the working product.” Use as a release update, not the main consumer marketing hook after the gate is fixed.
