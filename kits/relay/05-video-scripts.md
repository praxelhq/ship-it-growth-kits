# Relay — Video scripts

Use a toy repo and your own supported installed workflow. Never record private coding-session logs, tokens, customer code or recovery links. If installation is still an early-build gate, label it; don't manufacture a normal signed install in the edit.

## A. The next action survives —70 seconds

**Where:** landing page and experienced-builder invitation. **First two seconds:** “The summary missed the decision.”

|Time|Shot|Spoken line|
|---|---|---|
|0–2 s|Toy brief with the important decision missing|The summary missed the decision.|
|2–15 s|Your own small repo/session with a real decision|I want the next assistant to know why we chose this approach, not just a list of files.|
|15–30 s|Actual Relay source capture and preview|I review the exact context before anything is uploaded.|
|30–43 s|Inspect a genuinely reported gap or clearly labelled example|If something wasn't captured, it has to stay visible. A brief isn't the repo.|
|43–58 s|Generate and inspect the actual brief, then destination access check|Now Claude Code checks its access and the current project state before continuing.|
|58–70 s|Show limits and URL|Current Mac route only, two handoffs free. Other destinations are planned. Read the early-build status at relaycontext.app.|

Show actual output and failures. If generation is edited for length, label the shortened wait; don't imply instantaneous success.

## B. A path isn't access —25 seconds

**Where:** DEV article and owned feed. **Hook:** “This path doesn't give the next AI your files.” Show a synthetic path in a brief, then the destination checking its working directory and file availability. Say, “Carry context, then verify access. The next step changes if the files aren't there.” End with the manual checklist and founder disclosure. No claims about tools' permissions beyond what you actually observe.

## C. The preview is the product — 30 seconds

**Where:** privacy explanation beside the CTA. **Hook:** “Read this before you press Send.” Show a toy context item deselected and a synthetic secret marker removed, never a real key. Say, “Automatic redaction can miss things. I review the exact text that will be uploaded for generation.” Show consent and the supported-route limitation. End, “Local capture doesn't mean zero cloud processing.”

## D. One direction today —20 seconds

**Where:** launch gallery after the release gate. **Hook:** “These logos don't all mean the same thing.” Show a simple “reads now / opens now / planned” matrix from the actual current release. Say, “Today I can read these session sources and open Claude Code. The rest is still being built.” End with two free handoffs and URL. This clear limitation is more useful than a montage suggesting every tool works.

Capture source choice, exact preview, gap review, generated brief and destination checking access once. Keep text large for a phone and use hard cuts; no stock footage or fake successful terminal output.
