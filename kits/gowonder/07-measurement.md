# GoWonder — Measurement

**Target: 1,000 signups in 30 days.** For the observed no-account discovery flow, count unique genuine discovery sessions, beside **a detail path opened and a small activity tried/self-reported**. Label self-report honestly. A curated profile, card view, saved discovery or repeat session isn't an extra acquired person.

## Day 0

Read latest date/traffic/rank on the [course profile](https://shipped.money/p/gowonder). Establish actual sessions, detail paths, source exits, saves, activity self-reports and return days. The catalogue's 150 possibilities/110 people are content, not user totals. Private analytics figures are unknown to this kit; mark **not measured** until established.

Verify [Clarity](https://clarity.microsoft.com/) only where it cannot expose personal notes/interest answers. Use aggregate events and state limits on unique-person identification; don't add invasive fingerprinting to count anonymous learners.

## Funnel

`discovery_started → detail_path_opened → source_inspected → small_task_tried → later_day_returned`.

Separate an I tried this check from an observed task or private feedback report. No certificate, career-placement or mentor-connection outcome is being measured. Users who choose to read without doing are legitimate readers, but not activity activations.

## Projection and decisions

The actual calendar in `02` suggests roughly 13–84 activity trials before overlap under guessed rates. A confirmed session may overlap the same peers. If a hypothetical 40% of discovery starts reaches a tried task, 1,000 starts yields 400 trials; the current reach doesn't establish either. Report the board number and activation gap together.
