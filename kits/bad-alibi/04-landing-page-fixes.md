# Bad Alibi — Landing-page fixes

Checked 29 October 2026: homepage, `/play/new` and refund terms. No game, personal dossier or purchase was submitted. The old roster's price, duration and player range are stale.

1. **Put the whole-night decision by the real headline.** Current: “The game night where you’re the suspects.” Add **“3–10 people ·35-minute Quick or 75-minute Standard · one phone each.”** Preserve the personable headline; the organizer needs logistics before a story trailer. Primary CTA remains **“Host a game”** → `/play/new`.

2. **Make pay-at-start obvious.** Current pricing uses a $3.99 line, LAUNCH50 and $2 total; the bottom says the offer ends 30 November. Add **“Set up and invite free. The host pays when starting; friends join free.”** Show the final payable amount and promotion expiry beside Start, not only in the footer. Do not promise $2 after expiry or hide a required code.

3. **Show the minimum viable preparation.** The homepage says friends fill dossiers days before. Add a small preview **“Create a game → share the private link → friends answer harmless prompts → start when everyone is ready.”** Show actual readiness count, not a staged group as if it were live. Onboarding must explain what happens if a player is missing or drops out.

4. **Clarify tone without social pressure.** Current choices include Mild and Spicy; host setup says both are clean. Use **“Choose Mild for a first group. Inside jokes should be kind enough for everyone in the room.”** Make the optional inside-joke field visibly optional. Never ask for private contact details or real financial stories as personalization material.

5. **Prove the phone loop without spoiling it.** Show a consented or clearly staged 15-second clip of separate role screens, a timer and the final vote—not a solution. Caption **“Staged demonstration; no real players' private dossiers shown.”** A fake testimonial is worse than no testimonial.

6. **Keep refund/recovery next to the transaction.** The refund page says charged-but-not-started, duplicate charges and platform failures qualify for full refunds, with requests within 7 days. Add **“Paid but the game didn't start? Use the support route with your game code. Don't pay again.”** Link current refund terms. Test recovery in a controlled test flow before relying on it; this kit has not verified payment delivery.

7. **Use a useful link preview.** Title **“Bad Alibi — a mystery night for 3–10 friends”**; description **“Your group's harmless jokes become the case. 35 or 75 minutes; one host pays, friends join free.”** Exclude the temporary price from evergreen metadata. Test the actual room invite on a second phone and keep the code private; a homepage preview is not a tested game invitation.
