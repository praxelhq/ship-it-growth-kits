## Small-network arithmetic

One accepted circle,20 warm invitations, eight small-account posts and a directory listing might produce **10–35 completed rehearsals**, removing overlap. That is not an evidenced path to 1,000 accounts. If the rehearsal is useful, ask an organizer for one voluntary introduction to a different adult group; add its reach only when accepted. Keep the teaching post useful without any product link.
