# DeClutterMac — Measurement

**Target: 1,000 signups in 30 days**, defined as **valid new installs/first launches**, with **users completing a reviewed bounded folder sort** beside it. [Target policy](../../TARGET-POLICY.md).

Count download clicks, completed downloads, first launches, trial sorts and paid unlocks separately. Exclude tests, bots, reinstalls and repeated operations from the new-user headline. Activation is explicit preview/review plus an actual intended operation, not an app-open event. Retention is later independent use; freeing disk space is a separate actual measured outcome, not the size of files moved into folders.

## Day 0 baseline

[Public profile](https://shipped.money/p/decluttermac), checked 29 October, showed latest saved Clarity 8 sessions/24 h for 28 October, sync 03:13 UTC. One shipping-active day and $0 net revenue for 21–27 October; zero settled search clicks for 17–23 October. No rank was visible. These are period readings, not lifetime totals.

Private downloads, installs, sorts, undo outcomes and unlocks were not supplied. Record actual values before promotion. Verify existing landing Clarity once; never record private filenames/paths as analytics. Use aggregate native events only with an accurate data explanation.

Events: `download_completed`, `first_launch`, `preview_opened`, `operation_reviewed`, `sort_confirmed`, `operation_succeeded`, `operation_failed`, `undo_requested`, `undo_succeeded`, `undo_failed`, `later_day_use`, `license_unlocked`, `refund_recorded`. No “safe” or “zero-false-positive” event substitutes for test evidence. Log mismatches privately with the user's permission, not public file contents.

## Forecast and decisions

The actual plan schedules twenty invitations, three demos, eight clips and one listing.02 models **23–161 first launches before overlap**, not enough evidence for 1,000. At assumed 25% qualified-visitor-to-install, you need 4,000 qualified desktop visitors. Replace assumptions with actual rates; do not count download retries as people.

| Day | Install milestone | Paired decision |
| --- | --- | --- |
| 7 | 50 | Three real copied-folder tests pass; fix preview/move/undo mismatch first. |
| 14 | 150 | Reviewed operations and actual reversal tests, not tidy screenshots. |
| 21 | 500 | Real source-attributed installs/permissions; reforecast if wider route is absent. |
| 28 | 850 | Independent use, operation failures, undo mismatches and refunds. |
| 30 | 1,000 | Installs/launches, activated users, returns and net paid outcomes together. Report a miss plainly. |

Milestones are decisions, not predictions. Weekly rows: qualified desktop visits, downloads, first launches, reviewed successful sorts, undo success/failure, later users, paid unlocks, refunds and hours. Show denominators.

Installs without trial use point to trust/permissions/setup. Trial use without successful review points to scope confusion. Repeated undo or mismatch can indicate a product problem, not proof of engagement. Any unexpected loss or failed reversal on the tested scope requires repair before further promotion. Do not claim safety, accuracy or reclaimed capacity from a marketing badge alone.
