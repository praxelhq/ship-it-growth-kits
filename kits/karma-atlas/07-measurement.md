# Karma Atlas — Measurement

**Board target: 1,000 signups in 30 days.** For this no-account quiz, use unique genuine quiz sessions and report **completed questions plus a free personal teaser revealed** beside them. A sample card open, repeat purchase or new card download is not a new user.

## Day 0

Read the dated [course profile](https://shipped.money/p/karma-atlas). Record actual traffic/rank, quiz starts, completions, personal teasers, verified purchases/refunds, downloads and any retained sessions. The kit has no private totals; use **not measured**, not an assumed zero. Exclude `karma-atlas-2`, the duplicate roster submission, from a second kit/user count.

Verify public-page [Clarity](https://clarity.microsoft.com/) and masking/exclusion of birthday, name and answers. Use aggregate events without sending confessions to analytics. If unique humans can't be reliably counted, state the session-count limitation.

## Funnel

`quiz_started → quiz_completed → personal_teaser_revealed → purchase_verified → full_reading_revealed → card_downloaded`.

Separate sample/demo previews from real personalized teasers and test payments from real purchases. Inventory allocation follows verified payment/reveal according to the FAQ; don't estimate sales from a displayed card number. Count voluntary referral sessions separately from existing players recalculating.

## The target gap

The scheduled work in `02` suggests roughly 21–120 completions before overlap. These are assumptions, not proof. At a hypothetical 70% quiz completion, 1,000 completed teasers would require about 1,429 genuine quiz starts. The current calendar doesn't establish that reach. The board signup target is 1,000 starts; activation must accompany it so a thousand abandoned quizzes cannot look like success.
