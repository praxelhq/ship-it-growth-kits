# The Patterns — 30-day calendar

Two hours daily plus replies. Three owned clips at 18:30 IST. All testing uses fictional or specifically consented non-sensitive examples.

| Day | Main action |
| --- | --- |
| 1 | Record `07` baseline and actual account/price/result state. |
| 2 | Build `04` reflection consistency and visible action label. |
| 3 | Explain required inputs/processing/retention before submission. |
| 4 | Test missing-time/result-error/back behaviour with your own examples. |
| 5 | Record `05` A/B on the actual current flow. |
| 6 | Invite 15 consenting adult peers using `03` #1. |
| 7 | W1 review: did any wording sound like a prediction? |
| 8 | Fix the most repeated expectation or private-input surprise. |
| 9 | Ask first adult-circle admin for one invitation. |
| 10 | Send accepted `03` #2 reflection prompt. |
| 11 | Publish first clip B with #3 feeling caption. |
| 12 | Collect private process feedback, not copies of personal readings. |
| 13 | Publish one LinkedIn builder update #4. |
| 14 | W2 review: entry→real result→user-chosen next step. |
| 15 | Improve source/explanation clarity using actual objections. |
| 16 | Record clips C/D with no private chart data. |
| 17 | Publish second clip C about user choice. |
| 18 | Ask a different adult-circle admin for second invitation. |
| 19 | Send accepted second prompt #2 with a different non-sensitive example. |
| 20 | Test result consistency across feeling, yes/no and compatibility paths. |
| 21 | W3 review: return use and perceived prediction/authority. |
| 22 | Fix one repeated result or access-price confusion. |
| 23 | Optional factual Peerlist build note after usability; no paid placement. |
| 24 | Send one consented follow-up #6. |
| 25 | Publish third clip D about inspectable sources. |
| 26 | Review actual privacy masking and deletion/help process. |
| 27 | Support existing users instead of adding another broad spiritual pitch. |
| 28 | W4 review: real sessions, completed reflections and return use. |
| 29 | Exclude tests, sample views and repeat sessions from new-user totals. |
| 30 | Full `07` report with target gap and the next observed product improvement. |

Coordinate circle/week choices with the other reflection kits. If a result or data explanation is not ready, keep acquisition small and report the limitation; don't manufacture a successful reading.
