# Kaira — Video scripts

Use fictional deadlines on an actual tested account. Hide email/timezone identity if it identifies a person. No real grades, health tracker entries or task words in public footage. Re-record the actual UI after changes; don't animate proposed features as live.

## A. Main demo — 50 seconds, landing/session

**0–6s:** Three fictional tasks on paper. “Three deadlines. Which one do I start?” Label sample tasks.

**6–18s:** Enter a natural-language task using the actual interface. “I type a date, then check the exact saved date and timezone.” Show confirmation only if implemented and verified; otherwise show manual date verification honestly.

**18–29s:** Add two more sample tasks and open Focus Now. “This order is urgency first, with a reason. It doesn't decide what's important in my life.” Zoom to actual reason.

**29–39s:** Choose one task and show actual completion control. “One useful first step before I set up an entire system.” Don't fake task completion as a real productivity outcome.

**39–50s:** Show calendar/reminder setting. “Reminders work while Kaira is open. Free plan, account required, no card.” End URL. Never show an invented background phone notification.

## B. Hook — 22 seconds, Day 10

**0–5s:** A feature-heavy mock list is crossed out, three tasks remain. “I wanted to do one task, not configure twenty habits.”

**5–15s:** Actual three-task Focus Now with reason. “Enter the date, read the reason, choose where to start.”

**15–22s:** “Kaira's free plan needs an account, no card.” URL, fictional example label. Don't imply the recommended task is objectively correct.

## C. Hook — 24 seconds, Day 16

**0–6s:** Close crop of “Friday 5 PM.” “Which Friday, in which timezone?”

**6–17s:** Show the actual saved date/time on a test task. “Check what the app understood before trusting the deadline.” Compare input with stored display, not a proposed design rendering.

**17–24s:** “A calm planner should make the date clear.” URL, open-app reminder note. Use to invite precise usability feedback.

## D. Hook — 25 seconds, Day 24

**0–6s:** Focus Now reason. “Urgent doesn't always mean important.”

**6–17s:** Show one nearby due task and a personally meaningful undated sample. “Kaira shows the urgency reason. The final choice stays yours.” Don't demonstrate manual reordering unless it exists.

**17–25s:** Finish on one actual next action, not a perfect streak. “Try three tasks and tell me where the reason helps—or doesn't.” URL. Keep no invented before/after performance percentages.

Repurpose the same clean recording into captions/stills. Six owned posts in the calendar don't require six new video shoots.
