# Kaira — Distribution map

Sell the first useful day, not a generic productivity transformation. Coordinate with TaskBaddie: Kaira's wedge is date parsing plus urgency reasons in a personal timezone; TaskBaddie is choosing one task and a focus session. Use different actual classmates/organizers; one organization gets one primary invitation per week.

## Ranked routes

**Twenty individual invitations**, five each on Days 5,12,19,26. Qualify students who already have several real deadlines and want a dated list. Use 03 #1, one follow-up maximum. Don't collect their task text, grades or private timetable. Signup requires an account; explain that before the click.

**Six owned posts**, Days 6,10,16,20,24,29. Demonstrate three fictional tasks and the exact ranking reason. Post manually to existing personal accounts, using 03 #2/#3 and 05 videos. [LinkedIn's policy](https://www.linkedin.com/help/linkedin/answer/a1341387) forbids unauthorized scraping/automation and inauthentic behavior; no bulk DMs or comment bait. No audience size is known here.

**One conditional fifteen-person planning session**, Day 15. Ask one real known study organizer on Day 8 using 03 #4. Proposed 20-minute exercise: three tasks, check timezone, read reason, choose first action. It is not an approved session until accepted; use 03 #5 only then. Participants needn't show their real tasks. If declined, individual tests replace it and event forecast is zero.

**Peerlist**, https://peerlist.io/launchpad. Inspect current eligibility, existing listing and launch timing Day 18, submit Day 23 if appropriate. A checked destination is not a booked slot or promised audience. Use 03 #6 and don't ask for votes.

**Product Hunt**, https://www.producthunt.com/launch. Day 25 inspect existing listing and real maker-led launch readiness. Publish only a working product or substantive iteration with accurate current free-plan limits. No paid hunter, upvote requests or duplicate unchanged launch. Zero secured traffic in the base.

**One introduced student-learning editor**, Day 22. Use 03 #7 with an original fictional three-task example. Ask for editorial review, don't invent publication names, rates or email addresses. No traffic credited until accepted/published.

**AlternativeTo**, https://alternativeto.net/faq/, optional factual listing after category/eligibility verification. Verified email required; free backlog can be indefinite. Paid priority outside budget, zero month-one traffic until accepted.

## Forecast matched to calendar

All rates below are planning assumptions, not benchmarks. Twenty invitations × 40–60% visit = 8–12 visits; × 40–60% create account/first dated task = 3–7 activations. Six posts × 100–500 impressions = 600–3,000 impressions; × 1% visits = 6–30; × 20–40% account/first task = 1–12. An accepted fifteen-person session × 60–80% attendance = 9–12; × 40–60% activation = 4–7. Remove overlap and existing accounts.

Rough base: 4–19 activations without a session, 8–26 with it before deduplication; accounts may be more but count separately. None of these inputs supports promising 1,000. Keep the target, report the gap and seek a larger **accepted** partner only after first-day/repeat value exists. Don't put hypothetical newsletter/launch-site reach into guaranteed arithmetic.
