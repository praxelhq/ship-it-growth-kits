## Target and milestones

Keep the **1,000 B2C account target**. Public directory visit, 84 listings, saved tools and a paid kit purchase aren't interchangeable accounts. Activation after trust/access gates: a verified account saves one non-sensitive public link, puts it in meaningful categories and can find it again. Deeper value is voluntary later retrieval for a real job. Directory usability can be measured separately without requiring signup.

Potential coarse aggregate events only under actual policy/consent: public category/card opened, register completed, harmless link saved, category assigned, later retrieval, export/delete completed. No URL containing secrets, private notes, tool stacks tied to client identity, email, full library export or account identifiers in marketing events/replays. Existing Clarity's content visibility is the problem to correct, not a convenient research source. Don't add duplicate analytics scripts or promise masking that hasn't shipped.

Private aggregate ledger: date, source visits, public-directory exercise completed, legitimate accounts, first harmless save/retrieval, voluntary return, fetch/category errors, privacy objections, opt-outs, hours/spend. Tags `warm-tool-finding`, `owned-use-case`, `organizer-tools`, `peerlist`. Remove known workshop/warm overlap without fingerprinting. Keep paid kit/advertising figures separate and only if legitimately supplied.

## Weekly decisions

**Day 7:** Can five voluntary evaluators find a relevant public tool and explain the recording exception? Five is a learning gate. If “private” is understood as no operator/recording access, change copy and controls. Don't push signup by hiding the exception.

**Day 14:** Split directory finding, metadata fetch/correction, category assignment and retrieval. If saves rise but nothing is found later, improve use-case naming/organization instead of adding hundreds of listings. Don't scrape private libraries to learn what people saved.

**Day 21:** Compare voluntary later retrieval and trust decisions. Someone staying on the public directory is not a failed private-note conversion to overcome by pressure. If recording controls changed, verify actual behavior/policy before revising acquisition claims.

**Day 28:** Check export/delete consequences, actual directory curation/sponsorship labels and paid-kit delivery separately. An account deleted from the product doesn't mean prior Clarity footage vanished under the current policy. No “zero data retained” claim or independent security endorsement.

**Day 30:** Report public evaluations, verified accounts/first harmless saves/retrieval separately, eligible return, actual trust-gate state, sources after deduplication, errors, hours/spend and gap to 1,000 accounts. 02 assumes only 3–14 activations without a session or 4–18 with it before overlap **if gates pass**, otherwise zero private-library adoption forecast. No unaccepted editor/launch/directory reach in the base; no fabricated role-kit outcomes or tool/vendor endorsements.
