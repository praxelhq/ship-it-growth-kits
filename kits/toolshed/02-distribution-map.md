## Assumed arithmetic

All rates are planning guesses: 20 invitations × 40–60% visit = 8–12; × 25–50% account/first harmless save = 2–6 activations. Six small-account posts × 100–500 impressions = 600–3,000; × 1% visit = 6–30; × 10–25% account/first save = about 1–8. Accepted twelve-person exercise × 60–80% attendance = 7–10; × 20–40% later account/first save = about 1–4. Remove overlap.

If trust/access gates pass, rough base 3–14 activations without event, 4–18 with it before deduplication. If not, forecast **zero private-library account adoption from this campaign**, and report public-directory evaluations separately. No unaccepted launch/editor/directory traffic is credited. The 1,000-account target remains far above this base; seek a larger accepted partner only after useful retrieval/trust, not by treating every tool's audience as automatically available.
