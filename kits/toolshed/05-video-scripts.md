# Toolshed — Video scripts

Use public product URLs and harmless notes only. No client stacks, private dashboards, invitation tokens, names/emails or secret links. Real authenticated save/retrieval needs owner testing first; don't animate proposed features as live.

## A. Main demo — 55 seconds, landing/session

**0–7s:** A public tool link with a generic “why did I save this?” note. “A bookmark is less useful when I forget the job.”

**7–19s:** Actual URL metadata fetch with a harmless canonical product. “The fetch fills details; I check them.” Show a correction if needed, no false price-verification claim.

**19–30s:** Assign actual use-case categories. “One tool can serve more than one job.” Use real implemented controls only.

**30–42s:** Find the saved harmless tool through a category on return. “Can I find it when the job comes back?” No private library or account identity visible.

**42–49s:** Actual public privacy exception excerpt. “Don't put sensitive notes here while recordings can show them.” If controls were corrected, show actual verified status instead of stale warning.

**49–55s:** Public-directory-first CTA, free library/no card/current beta status. URL. No invented paid-kit offer or endorsement.

## B. Hook — 22 seconds, Day 10

**0–5s:** Generic bookmark pile. “I remember the job. I don't remember the tool.”

**5–15s:** Actual category→public tool result. “Find by what you wanted to do.”

**15–22s:** “Browse the directory before making an account.” URL. Eighty-four tools is a listing count, not users.

## C. Hook — 25 seconds, Day 16

**0–6s:** Metadata fields beside a public URL. “Automatic details still need a human check.”

**6–17s:** Actual title/description correction and category. “Check the fetched summary and current vendor terms; don't save a secret dashboard link.”

**17–25s:** “The fetch handles typing, not judgment.” URL and public-example label. Don't show a nonexistent tool price as real.

## D. Hook — 25 seconds, Day 24

**0–6s:** “Private from other users” versus “visible in recordings.” “Those aren't the same promise.”

**6–17s:** Actual policy excerpt showing current note/email recording exception and deletion distinction, no real account footage. “Know the boundary before writing sensitive notes.”

**17–25s:** “Public tools, harmless test notes first.” Public directory/privacy URL. If owner fixes controls, make a new verified update rather than pretend a recommendation shipped.

Use these four assets plus two honest process/trust text posts. Don't collect private notes to produce a more compelling testimonial or improve attribution.
