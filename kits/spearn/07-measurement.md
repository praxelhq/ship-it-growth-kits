# Spearn — Measurement

**B2C target: 1,000 signups in 30 days.** The current app is a no-account demo, so use the policy's session definition: **unique first app sessions**, with **completed and correctly understood sample comparisons** alongside. Actual account creation, if introduced, must be separate and deduplicated. A simulated redemption is not a real purchase or earned reward.

Activation means the person completes one sample comparison and can identify the assumptions/source limitation. A stronger signal is returning to compare another fictional spending scenario or inspect another assumption. Don't treat a large estimated rupee total as user value by itself.

Check existing [Clarity](https://clarity.microsoft.com/) before adding another script. Mask amount inputs and personal fields. Don't collect card numbers, statements, issuer credentials or actual transaction text. Minimal events can include `demo_started`, `sample_card_viewed`, `comparison_completed`, `assumptions_opened`, `simulation_opened`, `return_demo` only where actually measurable. A demo balance of zero isn't a customer's real financial state.

## Arithmetic

At an assumed 30% visitor-to-demo-start rate, 1,000 first sessions needs about 3,334 qualified visits. If 60% complete and understand the sample, that is 600 activations. These are hypotheses, not benchmarks. Twenty warm invitations, eight posts, one conditional session and uncertain directory discovery form a **10–30 understood-comparison experiment**, not evidence of thousands of visitors.

## Weekly decisions

| Day | Decision |
| --- | --- |
| 7 | Three fresh reviewers must identify the catalogue as illustrative and redemption as simulated. Any live-data confusion: correct labels before expanding. |
| 14 | Fewer than five of ten willing testers finish a comparison: observe the input/result step. If the total can't be explained, show the assumptions before more charts. |
| 21 | What assumption did return users inspect? No voluntary repeat value: narrow the learning job rather than advertise more cards. |
| 30 | Report first sessions, activations, repeat use, actual source-data status, hours and target gap. No card approvals, avoided fees or real redemptions claimed without evidence. |

These thresholds are experiment decisions, not financial standards. Keep potentially useful education separate from advice for a person's real borrowing or spending. A user deciding not to trust a sample ranking as a real recommendation is a correct outcome, not failed activation.
