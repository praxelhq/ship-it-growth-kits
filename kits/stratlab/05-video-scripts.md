# StratLab — Video scripts

Public product examples or synthetic calculations only. No real portfolio, broker statement, account identifier, trade recommendation or return testimonial. Record actual supported states and label sample/past-data periods.

## A · Read the losing test · 60 seconds · own feed / listing

| Time | Shot / text | Say |
| --- | --- | --- |
| 0–2s | Actual public losing verdict. **“A passed check isn't an edge.”** | “This test lost money after costs.” |
| 2–14s | Open actual rules/period. | “It's StratLab's own past-data example, not a customer result.” |
| 14–29s | Cost/baseline explanation on the real report. | “I want to know what was tested and what costs were assumed.” |
| 29–43s | Checks run/missing and their limits. | “These describe the sample. They don't predict the next period.” |
| 43–53s | Paper-only and free scope. | “The next experiment stays on paper. No real orders.” |
| 53–60s | Public route/URL. | “Read a report before signup at StratLab dot studio.” |

Don't cut to an unrelated rising curve or imply the public result was independently reproduced here.

## B · Gross isn't net · 20 seconds · short lesson

Hook: **“What did the costs change?”** 0–8s, clearly fictional gross/cost/net amounts. 8–15s: “A nice curve can shrink when fees and slippage enter.” 15–20s: “Check the assumptions before the conclusion.” No current tax/broker fee instruction from made-up numbers.

## C · A missing check stays missing · 25 seconds · report help

Hook: **“Three checks aren't four.”** 0–8s, show an actual report with only supported coverage, or a labelled illustrative card. 8–18s: “A missing test doesn't silently pass. Read what the verdict covers.” 18–25s: “Keep the conclusion smaller than the evidence.” No universal sample-size or scoring claim.

## D · Paper stays paper · 20 seconds · product introduction

Hook: **“There is no real-money order in this demo.”** 0–8s, actual paper-only disclosure. 8–15s: “This is a learning experiment, not an instruction to trade. Data and AI can be wrong.” 15–20s: “Start with the public example and keep private files out.” No brokerage connection or simulated profit passed off as earned money.
