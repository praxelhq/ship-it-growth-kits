# Soulloop — Measurement

**B2C target: 1,000 signups in 30 days.** The no-account product uses **distinct people's first meaningful practice sessions** as the signup equivalent. Report **completed 50-count sessions** and **stories opened** beside it. Fifty button taps are not fifty people or proof of spiritual benefit.

Private baseline records were not accessed. Record the actual starting point before promotion.

| Baseline | Source |
| --- | --- |
| First practice starts / last 7 days | Aggregate status events, deduplication limits stated |
| Completed counts and story opens | Product events, excluding tests |
| Source/context opens | Aggregate event |
| Repeat use in 7 days | Privacy-consistent aggregate records |
| Traffic/referrers | Existing consented analytics / [Clarity](https://clarity.microsoft.com/) |
| Course metric/rank/time | [Profile](https://shipped.money/p/soulloop) |

Check existing Clarity before adding scripts. Avoid recording private prayer/chant input, personal identity or religious-profile details in replay. Track `practice_started`, `count_threshold_reached`, `story_opened`, `source_opened`, `repeat_practice_session` as status only. A counter reset or browser-data clear does not create a new person.

| Checkpoint | What to check | Decision |
| --- | --- | --- |
| Day 7 | Five willing testers can count, correct a tap and open a story | Fix the first blocked step before group promotion. |
| Day 14 | Current content and coming-soon routes are understood | If not, narrow the hero and onboarding claims. |
| Day 21 | Readers return voluntarily and understand source/context | Improve reading quality, not guilt-based reminders. |
| Day 30 | Actual first sessions against 1,000; counts/stories/returns beside it | Keep the useful route and report the target gap honestly. |

At 50% visitor-to-start, the target needs 2,000 distinct relevant visits. The scheduled small tests don't guarantee that volume. Replace assumptions after three clips. Never label a large count as devotion, religious knowledge or a health outcome.

Course 24-hour readings overlap and cannot be added as cumulative users. Unsupported tradition selections are not activations. Your best evidence is a respectful, understandable supported experience that people choose to return to.
