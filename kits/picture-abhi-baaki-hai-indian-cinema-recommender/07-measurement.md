# Picture Abhi Baaki Hai — Measurement

**Assigned target: 1,000 consumer signups in 30 days.** This free product needs no account. Under the existing target policy, count one meaningful first discovery session: a new person starts onboarding and makes a real OTT/mood preference selection. A homepage visit, bot, reload or your own test does not count. Deduplicate repeat sessions using an existing consented identifier where possible; disclose the limits of anonymous/browser-based measurement rather than claiming perfect unique-person counts. No forced login is needed. Optional project-support payments are separate.

**Activation:** a person completes the preference flow, opens a recommendation and uses its provider link or saves their choice using an actual supported action. Report the precise supported action. A film shown is not a film watched. Return use: another recommendation visit on a later day, measured only with consent and an appropriate method.
