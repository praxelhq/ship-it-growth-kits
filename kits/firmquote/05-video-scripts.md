# FirmQuote — Phone-demo scripts

Use a fictional five-page website and your own voice/screen recorder. Never show real clients, proposals, editor tokens or confidential rates. A final acceptance/change must be a real internal test, not a simulated customer outcome.

## A. Agree the exact version — 65 seconds

0–3 s: sample scope beside “one more page”. **“Was the booking page included?”**

3–17 s: real quote builder with deliverables, exclusion and revision count. “Write the scope before choosing how persuasive the price sounds.”

17–32 s: separate client view with the exact version visible. “This is what the client is reviewing.” Leave a key navigation uncut; mask any access-bearing editor URL.

32–47 s: actual internal acceptance and locked version, if verified. “Record the yes to this revision. This is not identity verification or payment.”

47–57 s: real priced change and pending/accepted distinction. “Only an accepted addition changes the agreed total.” If not verified, show the public description and label the missing test.

57–65 s: URL and first-quote boundary. “Start one quote without an account. Keep the editor link private. firmquote.tech.”

## B. Scope hook — 20 seconds, Short

0–3 s: sample phrase “basic website”. **“Basic means what, exactly?”**

3–12 s: specific pages, form, revisions and one exclusion. “Name what is included before somebody assumes the rest.”

12–20 s: real client-view route and URL. “A clearer yes starts with a clearer scope.” No invented client conflict or money saved.

## C. Approval hook — 25 seconds, LinkedIn

0–3 s: version number beside an approval. **“A yes needs a version.”**

3–15 s: actual version record and a separate pending change. “A new request is not automatically part of the old agreement.”

15–25 s: public no-signature/no-payment disclosure and URL. “Keep the record useful. Keep its limits clear.”

Capture real builder/client separation, explicit exclusions, revision allowance, version state, acceptance lock, pending/accepted change total and legal/payment boundary. Label shortened waits. Do not fake signatures, endorsements or client purchases.
