# Magnetos — Video scripts

Use fictional goal amounts and an owned account. No private savings, banking data or travel document is needed.

## A. One-goal demo — 50 seconds

0–2s: **“A travel goal you can see when you return.”**

2–15s, show actual account/goal setup after verification. “One destination and a goal I chose.”

15–28s, record fictional progress through the actual supported control. “This is the recorded number—not proof the app holds money.”

28–40s, reopen the fridge and goal. “The test is whether it helps me revisit the plan.”

40–50s: actual storage/offer note and URL. No booking or financial return claim.

## B. Visual hook — 15 seconds, Reel

0–2s: “Not another forgotten travel note.”

2–10s: actual fridge/magnet interaction and fictional goal. “One place you care about, kept visible.”

10–15s: URL and **Illustrative amount · no booking implied**.

## C. Number clarity — 20 seconds, LinkedIn

0–2s: “What does 'Funded' mean here?”

2–12s: show the actual explanatory label and input source. “A progress state needs context, not just a glow.”

12–20s: sample/real-data distinction. Don't invent a connected bank feed for the shot.

## D. Return hook — 20 seconds

0–2s: “Would you open the fridge next week?”

2–12s: reopen a real test goal and show actual persistence. “That's more useful than a one-time screenshot.”

12–20s: URL and voluntary feedback question. No manufactured savings result.
