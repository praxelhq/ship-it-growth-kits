# shotgun — Video scripts

Use two owned phones, fictional names and a clearly fake bill. Real friends appear only with permission; private crew links stay hidden.

## A. One-plan demo — 60 seconds

0–2s: **“Your group's organizer didn't sign up for every job.”**

2–15s, create demo crew and join on second phone. “Start with people you already know.”

15–28s, vote on actual demo options. “Let the group choose instead of burying replies in chat.”

28–40s, show real role assignment/rotation. “Make the jobs visible.”

40–52s, add a fictional expense and inspect split. “This is a calculation, not a payment.”

52–60s: URL and **Fictional crew/bill · keep real links private**.

## B. Role hook — 15 seconds, Reel

0–2s: “Why is it always the same person?”

2–10s: show the actual role rotation. “Make the work explicit and take turns.”

10–15s: URL, no invented fairness statistic.

## C. Split hook — 20 seconds

0–2s: “Who owes whom isn't a memory test.”

2–12s: enter fictional payer/participants and show the actual split. “Check the people and amount before saving.”

12–20s: correct an input and show recalculation. “A clear split, not automatic money movement.”

## D. Repeat-plan hook — 20 seconds

0–2s: “Did the plan actually leave the chat?”

2–12s: show a real willing group's anonymized flow or a labelled demo, not a staged attendance claim. “The test is a decision people can follow.”

12–20s: next-plan action only if implemented and verified. Otherwise end on the useful vote/role flow.
