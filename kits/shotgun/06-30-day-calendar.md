# shotgun — 30-day calendar

Daily: 15 minutes for replies and aggregate issues. No private bill or crew-link collection for marketing.

| Day | Main job | Time |
| --- | --- | --- |
| 1 | Two-phone create/join/vote/role/split test; baseline. | 3h |
| 2 | Explain private access, no-login identity and split-not-payment. | 2h |
| 3 | Fix the biggest shared-state or rounding problem. | 3h |
| 4 | Record demo A and role hook B. | 2h |
| 5 | Invite five willing existing-group organizers (#1). | 1h |
| 6 | Observe one organizer-to-friend handoff without coaching clicks. | 2h |
| 7 | Checkpoint: first people, activated crews, blocked steps. | 1h |
| 8 | First Reel B / #3 at 19:30 IST. | 1h |
| 9 | Ask three existing alumni/friend-group admins for permission. | 30m |
| 10 | Share #2 in first approved group. | 1h |
| 11 | First LinkedIn #4 at 12:30 IST. | 2h |
| 12 | Fix a real poll/role confusion from feedback. | 2h |
| 13 | Second Reel C / #3. | 1h |
| 14 | Checkpoint: real decisions/roles, not just crew creation. | 1h |
| 15 | Test changed payer/participants and private-link behaviour. | 3h |
| 16 | Share #2 in second approved group. | 1h |
| 17 | Invite five more organizers, different contacts from Crewup/Adda. | 1h |
| 18 | Ask #6 after real plans, no pressure to share private details. | 1h |
| 19 | Record repeat-plan hook D with honest demo status. | 1h |
| 20 | Third Reel D / #3. | 1h |
| 21 | Checkpoint: repeat crews and actual bill clarity. | 1h |
| 22 | Optional current Peerlist maker feedback #5. | 1h |
| 23 | Share #2 in third approved group only if support capacity exists. | 1h |
| 24 | Second LinkedIn #4 about actual organizer friction. | 2h |
| 25 | Record a different fictional plan/role lesson. | 1h |
| 26 | Fourth Reel / #3. | 1h |
| 27 | One follow-up only to willing organizers who asked for help. | 1h |
| 28 | Checkpoint: unique people versus repeat plans and crews. | 1h |
| 29 | Improve the route producing real shared decisions. | 2h |
| 30 | Report first sessions, activated/repeat crews, split use and target gap. | 2h |

Don't invent an outing date to fill this calendar. Use plans the group was already making, and treat a cancelled plan as actual product feedback rather than a hidden failure.
