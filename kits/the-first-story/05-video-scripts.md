# The First Story — Video scripts

Use an actual reviewed entry and inspect its source before recording. No fictional etymology, private family shortlist or historical-image claim.

## A. Name-to-source demo — 50 seconds

0–2s: **“What does the source actually say about this name?”**

2–12s, select language and a real archive entry. “Start with a name you're curious about, not a random long list.”

12–25s, show native script, meaning and review label. “These are different kinds of information.”

25–38s, open actual source/context. “The reference supports this claim; it may not establish every association.”

38–50s, save a name if that flow works. “Keep your own shortlist. Free discovery; the Pass is preview-only. thefirststory.live.”

## B. Hook — 15 seconds, Reel

0–2s: “A pretty meaning isn't enough.”

2–10s: actual entry → source. “Open the reference before repeating the story.”

10–15s: URL and **Free discovery · source/review labels**. No unsupported name fact in the hook.

## C. Illustration hook — 20 seconds, Story

0–2s: “This picture isn't a historical portrait.”

2–12s: show art label and the separate textual reference. “Illustration helps the page feel alive. The source has a different job.”

12–20s: review label and URL. “Know which part you're looking at.”

## D. Family-shortlist clip — 25 seconds, Reel

0–2s: “Twenty names in the chat. Which ones have a reason?”

2–15s: fictional shortlist, then two real entries with sources. “Choose language, context and what matters to your family.”

15–25s: save/compare only if verified. “The final choice stays yours.” Price/availability disclosure: **Pass preview-only today**.
