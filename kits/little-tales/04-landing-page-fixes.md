# Little Tales — Landing-page fixes

## 1. Verify and expose the first action

Current rendered page: **“Turn little moments into memories.”** and **“Private by default. No feed, no followers.”** No actionable link was exposed in the rendered extraction. This is an evidence limit, not proof that every browser lacks controls. Test a clean mobile browser first. If the entry is missing, ship the real destination before paid traffic or public launches.

Replacement button: **“Start a private scrapbook”**. Supporting line: **“Keep one little moment. You choose what to add.”** Link to the actual implemented editor/account route; do not invent `/signup` because it sounds plausible.

## 2. Bring trial terms out of metadata

Current preview says **“Free for 7 days.”** No paid amount or trial-end action was visible. Show the actual commercial terms beside the button. Until those are confirmed, use **“Read the current trial terms before starting”** linked to the real explanation. Do not promise no card, automatic cancellation, lifetime access or a free forever plan.

## 3. Define private in plain language

Replace the unsupported implication of “private” with an accurate storage explanation. A useful section heading is **“Where your memories go”**. Answer who can access entries, what leaves the device, which providers process it and how deletion works. Write the answers from the actual implementation. No blanket end-to-end encryption claim without proof.

## 4. Show one harmless completed example

Add a staged stamp about tea or a walk, clearly marked **“Example memory”**. Show what the first save and later return look like after testing them. Do not use someone else's diary or a fictitious testimonial.

## 5. Match previews and mobile

The existing title/preview describes the scrapbook well. Keep it consistent with the actual entry and trial. Test Android and iPhone tap targets, keyboard, back navigation and reopening. If a save requires an account, explain that before typing. Never erase someone's drafted memory while asking them to sign in.
