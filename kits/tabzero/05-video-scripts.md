# TabZero — Video scripts

Use a dedicated public-tab window and an actual installed release. Hide private URLs/accounts. Screen recording, voice and captions suffice. No fake instant grouping, performance benchmark or privacy claim.

## A. One task, fifteen tabs—60 seconds

**Where:**owned technical clips/project sessions.** Hook:**“Chrome can group these. Which ones need action?”

| Time | Shot/text | Voice |
| --- | --- | --- |
| 0–8 s | Dedicated public research window. | “Chrome can group these. Which ones need action?” |
| 8–22 s | Actual extension suggestion run; show data/permission boundary. | “I use a non-sensitive window and the release's stated processing mode.” |
| 22–35 s | Inspect and correct an actual category. | “This belongs in Reference, not Action. The suggestion needs review.” |
| 35–48 s | Apply actual native groups. | “Now the tab bar reflects the task. These groups are not a backup of unsaved work.” |
| 48–60 s | URL/current price/desktop requirement. | “TabZero. Check the actual install and data terms before buying.” |

If the installed run cannot complete, fix it rather than use an animated mockup as proof.

## B. Native versus suggested—20 seconds, vertical

**Hook:**“The colors are not the new part.”

| Time | Shot/text | Voice |

| 14–20 s | Actual grouped task/URL. | “Judge the workflow, not the AI label.” |

## C. A group is not a backup—25 seconds, vertical

**Hook:**“Don't close unsaved work for a tidy screenshot.”

| Time | Shot/text | Voice |
| --- | --- | --- |
| 0–7 s | Public demo tab, clear boundary text. | “Don't close unsaved work for a tidy screenshot.” |
| 7–18 s | Actual group/reopen behaviour. | “I check what this release keeps and what the page itself still needs me to save.” |
| 18–25 s | URL/data/install note. | “Organization and persistence are different promises.” |

## D. Correct the AI—20 seconds, vertical

**Hook:**“This tab was in the wrong bucket.”

| Time | Shot/text | Voice |
| --- | --- | --- |
| 0–6 s | Actual incorrect suggestion. | “This tab was in the wrong bucket.” |
| 6–14 s | Actual review/correction control. | “A useful tool makes the correction easy before changing the task.” |
| 14–20 s | Corrected groups/URL. | “That is the TabZero test.” |

Eight clips are scheduled. Use real errors and task context, not staged private browsing. Ask permission before recording another person's screen.
