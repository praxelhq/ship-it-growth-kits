# TabZero — Landing page fixes

Public rendered page/controls checked 29 October 2026. Checkout, installation, permissions and AI flow were not tested. A button without ordinary href is not proof it is broken; verify the interactive route before promotion.

## 1. Explain the AI/local-processing claim precisely

Current page says Gemini-assisted triage and the footer says “100% Private, Local In-Browser Processing.” Those words alone do not establish whether titles/URLs stay local or go to a provider.

Inspect the actual release and publish the true data contract before asking for browser access:

> What the extension reads; which fields are processed locally; whether anything is sent to an AI provider; how keys/data are stored; how to clear or remove it.

Do not invent a leak or replace uncertainty with an unsupported offline badge. If remote processing exists, explain it before the action. If genuinely local, show the exact supported mode/requirements.

## 2. Show the usable install/purchase path

The CTA says “Get TabZero Pro—$2.99.” A live store/package route, billing period and entitlement were not verified here. Show the exact current release route before payment, with browser compatibility, permissions, final total and refund/support information.

Copy:

> **Review the install and data requirements first.** The current Pro offer is $2.99; check what it includes and the final payable total before purchase.

Do not call it lifetime, monthly or free without evidence. Test a clean Chrome profile through the stated route before sending traffic.

## 3. Match the headline to the actual job

Current headline: “Close the tabs. Keep the context.” The feature copy describes categorization and native grouping, which are not automatically closing, archiving or backup.

Replacement:

> **Sort this task's tabs before deciding what to close.**
>
> Review suggested Action, Read Later, Reference and Done groups. Correct them, and keep the right context in Chrome.
>
> **See a real task triage**

Keep a product-specific public-tab demonstration as the focal evidence, not generic AI icons.

## 4. Compare native Chrome honestly

Google already documents named/color tab groups. Add a simple explanation:

> Chrome can group tabs without this extension. TabZero's proposed value is the suggested triage and review workflow. Try that difference, not just the colors.

Use a real category error and correction in the demo. Do not claim measured time/RAM savings you have not tested.

## 5. Show review before change and state what persists

The page promises one-click groups. Test whether users can inspect/correct categories before applying, what happens to pinned/private pages, and what survives restart/uninstall. Never imply grouping saves an unsaved form or backs up a page.

Suggested boundary:

> A group organizes tabs. It does not guarantee the page's unsaved work is stored. Save important work separately before closing anything.

If the actual extension automatically closes tabs, make that action explicit and reversible where supported before asking for confirmation.

## 6. Test strangers with non-sensitive tabs

Observe three adults install/launch in a clean profile, triage a dedicated public window, correct a mistake, apply groups, close/reopen and uninstall. Test network failure, AI failure, empty windows and permissions denial. Pause promotion if required steps fail.

Mask URLs/titles in analytics; do not collect private browsing as a growth funnel metric. Use aggregate install/first-group events with a clear consent/data explanation.

## 7. Mobile/share reality

This is a Chrome extension workflow, not a demonstrated phone app. A mobile visitor needs a clear desktop requirement and a safe way to return later, not a non-working install promise. No visual audit was performed; check keyboard/reduced-motion/readability in the actual popup.

Suggested title: “TabZero—review your current tabs by next action.” Description: “Suggested triage and native Chrome groups. Current price, install and AI data boundaries shown upfront.” Preview privately without real private tab titles.
