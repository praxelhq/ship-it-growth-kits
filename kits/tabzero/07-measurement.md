# TabZero — Measurement

**Target: 1,000 signups in 30 days**, defined for the extension as **valid new installs/first launches**, with **people completing a reviewed real grouping** beside it. [Target policy](../../TARGET-POLICY.md).

Exclude tests, bots, reinstalls, landing clicks, checkout starts and public-video views. A paid receipt is a billing result, not proof the extension launched. Activation is a real suggested-category review and applied grouping. Retention is an independently initiated task session on a later day. Do not fingerprint private browsing to deduplicate; state install/device limitations honestly.

## Day 0 baseline

[Public profile](https://shipped.money/p/tabzero), checked 29 October, showed zero shipping-active days for 21–27 October, sync 20:34 UTC. Clarity, search and revenue had no eligible readings. Missing is not zero. No rank was visible.

Private purchases, installs, first launches and groups were not supplied. Record actual values before promotion. Verify existing landing analytics once and keep extension data collection minimal/explicit. Do not send real URLs, titles or browsing contents as analytics events merely to measure a funnel.

Events: `checkout_started`, `purchase_succeeded`, `install_completed` only if verifiable, `first_launch`, `triage_started`, `triage_failed`, `suggestions_reviewed`, `category_corrected`, `groups_applied`, `later_day_task_session`, `refund_recorded`. Keep install and first-launch counts separate when sources differ. Use coarse campaign labels, no private tab data.

## Forecast and decisions

The actual plan schedules twenty invitations, two sessions, eight clips and one listing.02 models **8–69 valid first launches before overlap**, assuming the paid/install path works. That is not sufficient evidence for 1,000. At assumed 10% qualified-visitor-to-install, the target needs 10,000 qualified visitors. Replace the rate with actual data; do not count a purchase CTAclick as an install.

| Day | Install milestone toward target | Paired decision |
| --- | --- | --- |
| 7 | 50 | Three real clean-profile tests pass; fix install/data/review gaps first. |
| 14 | 150 | Actual first launches and reviewed groups, not only purchases. |
| 21 | 500 | Real source-attributed installs and voluntary introductions; reforecast if wider distribution is absent. |
| 28 | 850 | Independent later tasks, correction rate and support/refunds. |
| 30 | 1,000 | Valid installs/first launches, activated groupers, returns and paid outcomes together. Report a miss plainly. |

Milestones are decisions, not predictions. Weekly rows: qualified desktop visits, purchases, valid installs, first launches, reviewed groups, later task sessions, errors, refunds and hours. Show numerators/denominators.

Visits without install may mean an unclear offer or unsupported device. Purchases without first launch are an installer/entitlement failure. First launches without grouping suggest permissions, AI reliability or poor suggestions. Grouping without later use challenges the value beyond native Chrome. Any unexpected closing/data exposure requires repair before promotion. A tidy screenshot does not prove preserved work, privacy or performance gains.
