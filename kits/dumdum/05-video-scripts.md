# dumdum — Video scripts

Record on an actual supported Windows machine with a real published version. Don't substitute the website's draggable pet for a native install. Use fictional tasks and files. Never film credentials, license keys, calendar identity or private Desktop files.

## A. Demonstration — 55 seconds, landing page/session

**0–6s:** Pet enters a clean desktop. “A little Windows companion, with one useful job.” Overlay Windows 10/11 64-bit, about 300 MB, free account.

**6–15s:** Click the real mouth-menu and create “Refill water” or another invented task. “One click for a note.” Don't film account login; explain it is required.

**15–25s:** Set a reminder a few minutes ahead. “Let's check whether the reminder actually arrives.” Show actual permissions/settings required; no false instant outcome.

**25–35s:** Label *Time compressed*. Show real Windows notification arriving, hiding unrelated notification contents. “This is the actual reminder from this test.” If it fails, don't publish a fabricated success; fix/re-record.

**35–44s:** Feed a synthetic file and pat out its copy. “The original stays where it was.” Show both clean paths/names and collision numbering only if verified.

**44–55s:** Show persona/reaction toggles and exit. “Keep it if it's useful. Startup and calendar export are optional.” CTA official download page; no invented Pro amount or Mac availability.

## B. Hook — 20 seconds, Day 10

**0–4s:** Close crop of a pet with a fictional note in its menu. “My desktop pet learned one practical trick.”

**4–13s:** Actual note/reminder action. “A note here, a Windows reminder later.” Cut away from account identity.

**13–20s:** “Windows 10/11 64-bit, free account, about 300 MB. See what it needs before downloading.” URL. Don't hide the download/account tradeoff for a better click rate.

## C. Hook — 25 seconds, Day 16

**0–5s:** Two synthetic file icons. “This one stays put.”

**5–17s:** Feed-copy/pat sequence with a pre-existing Desktop filename. “dumdum takes a copy. A collision gets a number rather than overwriting.” Only show passed real behavior.

**17–25s:** “The pet trick is free. Document conversion is separate Pro functionality; check the actual offer.” URL and *sample files*. No claim that notes/AI never use a network.

## D. Hook — 22 seconds, Day 24

**0–6s:** Pet reaction toggles. “A companion shouldn't become another interruption.”

**6–15s:** Turn off one reaction, show optional startup and quit. “Pick what stays, and make it easy to stop.”

**15–22s:** Show one simple useful note. “Does the note earn its place after the novelty?” URL. Use to invite real usability feedback rather than invented affection testimonials.

One clean screen recording supports all four edits. Include captions and a readable final Windows/platform/account card; don't produce a new video every day instead of supporting installs.
