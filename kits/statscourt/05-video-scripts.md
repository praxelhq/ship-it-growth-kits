# StatsCourt — Video scripts

First reproduce a working comparison. Use actual result values, filters, denominators and snapshot labels; no invented score or staged successful share link. Do not post AI-written scripts or generated images into r/Cricket.

## A. The same question — 50 seconds

**Use:** homepage, adult cricket/data session, Peerlist.

| Time | Picture / on-screen text | Spoken words |
| --- | --- | --- |
| 0–3s | Real comparison workspace. Text: “Same situation?” | “Same situation?” |
| 3–16s | Select the actual shared filters. | “In StatsCourt, start with the same selected situation for both players.” |
| 16–32s | Hold a real result and its denominator. | “Now look at the sample. A number without its opportunities can be easy to misread.” |
| 32–45s | Show snapshot and methodology route. | “This is a descriptive comparison, not an overall player ranking. The calculation and data version should be inspectable.” |
| 45–50s | URL. | “Try one clear question at statscourt.online.” |
