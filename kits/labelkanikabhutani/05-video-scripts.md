# Label Kanika Bhutani — Video scripts

Use only real pieces/images the atelier owns or has permission to show. No generated outfit portrayed as stock, body ratings, private measurements or customer faces without specific consent. Phone close-ups and your voice are enough.

## A · Before the order · 60 seconds · own feed / consultation page

| Time | Shot / text | Say |
| --- | --- | --- |
| 0–2s | Actual garment detail. **“Agree the details first.”** | “An occasion outfit starts with a clear conversation.” |
| 2–14s | Real permitted piece, describe only observed work. | “This is an actual piece from our atelier preview.” |
| 14–28s | Simple brief: function, preferences, budget, required date. | “We discuss what you want and the time available.” |
| 28–43s | Consultation page, no personal fields submitted. | “The new public edit is launching soon. You can request a free 30-minute preview conversation.” |
| 43–53s | Checklist: quote, fit, alterations, delivery. | “Confirm these for the specific piece before ordering.” |
| 53–60s | Current route and request limit. | “A requested slot needs confirmation. Details at labelkanikabhutani dot shop.” |

If there is no real piece available to show, don't manufacture one; film the honest collection-preparation state and explain the current limit.

## B · Budget isn't a quote · 20 seconds · stylist help

Hook: **“Choosing ₹25,000 doesn't make this a ₹25,000 garment.”** 0–8s, show the stylist's actual budget input. 8–15s: “This is a preference for the brief. The actual design and quote need confirmation.” 15–20s: “Check before ordering.” No invented item price.

## C · Optional means optional · 20 seconds · own-feed short

Hook: **“You can choose Prefer not to say.”** 0–8s, show actual body-type option without submitting. 8–15s: “Start with the function and colours you enjoy. A body label isn't required for the first brief.” 15–20s: “A fitting discussion should be respectful.” Don't promise body transformation or guaranteed flattering results.

## D · Request isn't the appointment · 25 seconds · booking help

Hook: **“Wait for the accepted slot.”** 0–8s, show public consultation choices. 8–18s: “A form request and an operator-confirmed appointment can be different. Check the actual confirmation before travelling.” 18–25s: “Then agree the real piece, quote and timeline.” Use the actual booking model after testing; no fabricated receipt or availability.
