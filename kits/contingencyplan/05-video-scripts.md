# ContingencyPlan — Video scripts

Record a phone screen and voice; no paid tools. Use only fictional ordinary arrangements. The demo waits for the actual workspace test; do not animate invented product screens.

**A. Demo, 40 seconds; owned profile.** 0–2s hook: “Where is your Plan B when the first plan changes?” Show a fictional original arrangement. 2–12s show the real public example and say, “You should see what this does before creating an account.” 12–30s record the actual verified create/save/reopen flow with test data; narrate only the visible actions. 30–40s show the reopened outcome: “That's the test: can I find the next step again?” End card: “ContingencyGenius · everyday planning · current limits on the site.” If save/reopen fails, publish a build update about the failure instead.

**B. Login gap, 20 seconds; LinkedIn.** Hook: “A login screen isn't an explanation.” Shot 1: existing “Welcome back” heading. Spoken: “New visitors don't know what they're coming back to.” Shot 2: the fictional example you actually publish. Spoken: “I'm putting the outcome before the form.” End: “Would your notes app do this better?” On-screen: “Builder feedback, not a testimonial.”

**C. Note comparison, 25 seconds; permissioned circle.** Hook: “Your current note is the competition.” Shot 1: fictional note with an original arrangement and fallback. Shot 2: same information in the verified workspace. Spoken: “I need to make creating or finding this easier, not add another password.” End shot: ask the tester which step was clearer. Do not script a favourable answer.

**D. Scope, 15 seconds; owned post.** Hook: “A backup note is not an emergency service.” Show the actual scope text. Spoken: “I'm testing everyday arrangements. Don't rely on this for urgent help or professional decisions.” End: actual product URL. This boundary matters because “safety net” otherwise implies more than the public evidence supports.
