## Milestones and integrity

First activation: harmless text fixed, reviewed and deliberately accepted, with exact-undo behavior verified in a test. Don't require every user to perform an unnecessary AI rewrite. Deeper value: voluntary later useful fix/rewrite with meaning preserved. Count edit failures/text-loss incidents and undo failures explicitly; don't hide them behind successful tap totals.

Possible coarse milestones: download click, known first launch, consented/legitimate aggregate fix/rewrite count, optional account signup, quota reached, voluntary return, reported undo failure. Actual app policy already describes device/usage/credits; keep operational telemetry separate from marketing. No writing, clipboard, screen contents, source-app window title, private instructions, email, device hash or payment reference in growth reports/replays. Hashes aren't permission to publish device-level data.

The website promises GA/Clarity only after consent, strict masking and exclusion from sensitive pages. Verify current implementation; don't add duplicate scripts or count declined-consent users as zero interest. Sources `warm-writing`, `owned-undo`, `organizer-bilingual`, `macapps` can use coarse link tags. Remove known event/warm overlap without fingerprinting or adding Clarity sessions to PostHog views.

**Day 7:** Can five voluntary supported-Mac tests fix/review and restore the exact harmless original? Five is a learning gate. If text is lost or meaning shifts, prioritize integrity/recovery before another invitation. If users think every mode is local, correct copy and actual settings explanation.

**Day 14:** Split download/launch, permission, invoked selection, edit, undo and AI-account/allowance errors. Optional Screen Recording refusal isn't a failed basic user. Quota confusion means reconcile units/reset, not invent extra free writes. Report denied/closed paid access as product state, not churn.

**Day 21:** Compare sources on useful repeat fixes/voluntary return and reported meaning preservation, not characters processed. A large document creates many characters but one user. Don't claim a writing-quality percentage or reliable Hindi translation from a few fictional samples.

**Day 28:** Recheck current paid-plan openness, sponsored/sample-line status, real release signing and privacy consent. No actual paid delivery means zero revenue forecast. Confirm support burden and unsafe-app cases before seeking a larger partner.
