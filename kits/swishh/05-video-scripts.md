# Swish — Video scripts

Use a clean owned Mac and fictional message. Never film private chat, workplace documents, email identity or password fields. Native edit/undo must be actual, not a website animation. Captions state exact tested app/version and distinguish local from AI.

## A. Main demo — 55 seconds, landing/session

**0–7s:** Fictional short message with a typo. “A small fix, where I'm already writing.” Show sample label.

**7–19s:** Actual two-tap local Fix with Smart grammar state visible. “Here is the change; I still read it.” Highlight real changed text, don't invent a perfect result.

**19–30s:** Actual four-tap undo, continuous shot. “My exact original comes back.” Compare punctuation/line breaks. If it fails, fix/re-record instead of hiding text loss in a cut.

**30–41s:** Separate opt-in three-tap tone/Hindi–English example. “This AI mode sends the selected sample text to the service.” Don't imply local translation or guaranteed meaning preservation.

**41–48s:** Actual permission/settings view. “Accessibility is required for in-place changes; glow precision's Screen Recording is optional.” Hide unrelated system information.

**48–55s:** Free/local versus 10,000 AI-character daily allowance after sign-in, paid plans closed, macOS 13+, URL. No bought-plan CTA.

## B. Hook — 23 seconds, Day 10

**0–5s:** Original fictional sentence. “Before a fix is clever, it should be reversible.”

**5–16s:** Actual fix then exact undo in one continuous view. “Read it. Keep it or bring your words back.”

**16–23s:** “Free local fixes, macOS 13+. Test with harmless text.” URL. No universal any-app or perfect-grammar claim.

## C. Hook — 25 seconds, Day 16

**0–6s:** Local/AI mode cards. “One app, different processing boundaries.”

**6–17s:** Actual Smart grammar setting and AI rewrite control. “Local Fix can stay on-device. AI rewrite sends selected text to providers.” Don't show a fake network audit.

**17–25s:** “Choose the mode before using private text.” Privacy/product URL. No “never anything collected” claim; usage/device records are disclosed.

## D. Hook — 25 seconds, Day 24

**0–6s:** Fictional Hindi/English sentence. “A different tone shouldn't quietly change the meaning.”

**6–17s:** Actual chosen rewrite result, compare with original and identify whether meaning was preserved. If imperfect, explain the correction rather than inventing flawless translation.

**17–25s:** Actual undo/review step. “The last word stays with you.” URL, free AI allowance/signup and network note. Don't claim a measured improvement in writing quality from one clip.

Use these four assets plus two actual text/testing lessons for six owned posts. Keep readable original/result crops; whimsical effects should not hide a failed undo or quota boundary.
