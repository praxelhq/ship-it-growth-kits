# SnipText — Video scripts

Use a made-up error or permitted sample image, no keys, emails, serials from real devices or private screen content. Actual native capture must be recorded on a supported test Mac; website practice isn't install/permission proof. No security-warning bypass footage.

## A. Main demonstration — 55 seconds, landing/session

**0–7s:** Harmless fake error image. “I need this text, not another screenshot.” Label synthetic image/test model/build.

**7–19s:** Actual native shortcut Ctrl–Option–C and selection. “Select the small area. Keyboard controls can refine the box.” Show only controls genuinely implemented/tested.

**19–31s:** Real OCR result with engine label. “Check what it read.” Deliberately inspect a digit/symbol; correct an actual error if present, don't claim perfect accuracy.

**31–40s:** Copy/paste into a clean scratch document. “Paste only the checked text.” Don't put OCR output into a command shell as an execution demonstration.

**40–47s:** Cancel a second sample capture and verify previous clipboard stays. “Cancel should leave the clipboard alone.” If failure, fix rather than edit away.

**47–55s:** Free/no account/key and actual Apple Silicon/macOS14+/beta/not-notarized card; recognition local, model/license network separate. URL. Public installation CTA only after release/privacy gates.

## B. Hook — 22 seconds, Day10

**0–5s:** Fake screenshot error. “Retyping one symbol wrong can send you down the wrong path.”

**5–15s:** Actual select→editable result→correction. “OCR first, review before paste.”

**15–22s:** “Free Vision snips, no account/key. Check actual beta release status.” URL. No “100% accurate” overlay.

## C. Hook — 25 seconds, Day16

**0–6s:** Memory versus optional history/export labels. “Memory-only by default isn't never saved under any setting.”

**6–17s:** Actual history toggle/export choice with synthetic text. “Keep results only when you explicitly choose persistence.” Don't show an invented delete control.

**17–25s:** “Know where your text goes.” Privacy/product URL after own policy corrected. Recognition local; don't imply Pro validation is offline.

## D. Hook — 25 seconds, Day24

**0–6s:** Vision/MLX actual engine menu. “A larger local model isn't the first step for every snip.”

**6–17s:** Same harmless sample, actual measured outputs if both genuinely tested. “Vision for this test; MLX needs explicit setup and warm-up.” No manufactured timing comparison.

**17–25s:** “Start with the smallest useful workflow.” Free/Pro price/model-download card and URL. Keep roughly1.25GB setup visible, don't hide it behind “instant local AI.”
