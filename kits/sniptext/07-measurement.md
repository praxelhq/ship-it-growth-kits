## Target and milestones

Keep the **1,000 B2C install/license target**. Free requires no account, so count known legitimate first installs/launches separately from paid Pro licenses and don't invent signups. A license covering all buyer's Macs doesn't create multiple buyers. Activation: first harmless OCR result reviewed/corrected and copied successfully. Later useful snip/voluntary return is deeper value; total captures aren't users.

Potential website milestones are download-click and actualPro checkout/delivery only where current policy/consent supports. Don't infer native capture from webpage practice. The local/no-content-logs promise rules out sending images/recognized words for growth analytics. If native aggregate telemetry isn't disclosed/available, use voluntary test counts and say global totals unknown.

No image, OCR text, clipboard content, private filename/path, screen title, serial, license key or hardware identity in events/replays/public reports. Track coarse source/error/success only with legitimate consent. Fix own privacy destination before adding analytics; don't assume Microsoft's policy covers app processing. Don't add duplicate Clarity scripts. Source tags can separate `warm-ocr`, `owned-error`, `organizer-ocr`, `macapps`; remove known overlap without fingerprinting.

## Weekly decisions

**Day 7:** Can five voluntary supported-machine/sample tests select, read, edit/copy and cancel safely? Five is a learning gate. If download→launch fails, inspect compatibility/signing/normal installation, not “run anyway” messaging. If OCR has errors, show review/correction rather than promise perfection.

**Day 14:** Separate screen permission denial, image-import success, engine setup, recognition and clipboard failures. Screen Recording isn't needed for imported images; Accessibility isn't promised for copy-only. If cancel changes clipboard or data logs contain recognized text, fix before expansion.

**Day 21:** Review voluntary second useful snips, actual local processing and optional history behavior. High capture count from one tester isn't 1,000 installs. If users expect no disk/network, fix persistence/model/licence copy before another promotion. Don't call a failed project link proof the app is down.

**Day 28:** Review supported-release readiness, own privacy links, paid Pro delivery and support cost. Compare actual sample/engine/model specs only when measured; don't imply framework Intel support means an Intel build exists. Community main-feed eligibility isn't established by a DMG 200 or a “local” label.

**Day 30:** Report actual invitations, sample evaluators separately, known first installs, reviewed/copied OCR activation, eligible voluntary return, Pro licenses/buyers separately, errors, hours/spend and target gap.02 assumptions give only roughly 3–13 activated installs without an event or 4–16 with it before overlap, and zero until release/privacy gates pass. No unaccepted launch/community/directory reach in the base. No perfect-accuracy, independent-security or guaranteed privacy claim.
