# DilliScenes — Distribution map

**One reliable host and a reachable circle lead.** Broad reach before a real event creates unanswered expectations, not a community.

All figures below are assumptions for the scheduled work, not local-event benchmarks.

| Route | Action / rule | Expected result | Copy |
| --- | --- | --- | --- |
| 1. Three known adult hosts | Individually ask about one real small no-spend activity. Confirm venue/public-space arrangements and what the host can support before publishing. | Three × assumed 30–60% host acceptance = 1–2 events, not guaranteed. | #1 |
| 2. Twenty relevant adult invitees | Only after actual host/time/place confirmation; private consented invitations, no group additions. | 20 × assumed 50–70% account/RSVP = 10–14 accounts, attendance separate. | #2 |
| 3. Two permissioned existing local circles | Admin approval for one event invitation each. No city-group blast or invented venue partnership. | Two × assumed 40 readers × 10–25% visit × 20–40% signup = 2–8 accounts. | #3 |
| 4. Two owned clips | Clear plan and RSVP-versus-attendance at 18:30 IST. No guest identities, live private location or fake crowd. | Two × assumed 200–1,000 views × 1–2% relevant visit × 20–40% signup = 1–16 accounts. | #4 |

The base plan supports roughly 13–38 accounts before overlap. Event capacity and actual attendance can be smaller. A thousand signups requires a host/distribution supply the current plan hasn't established.

## Communities, directories and accounts

Use the actual host's approved group/profile, not a review page of a venue you don't control. No current Delhi-city-community commercial permission, newsletter slot or influencer partnership was verified. If an organizer declines, count zero reach. [Peerlist](https://peerlist.io/) is a later software build note, not the place to recruit a local event's attendees; skip broad launch directories this month.

Coordinate dates with Café Xtroverts, Crewup, Kahi Chalo, ORBIT, Adda and Shotgun. Your job is a hosted local gathering; theirs are café presence, existing circles, building intros or planning logistics. Don't send the same circle several competing invitations in a week.
