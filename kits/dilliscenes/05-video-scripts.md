# DilliScenes — Video scripts

Use fictional/test event details unless a host explicitly permits a public recording. No guests or live private locations without permission.

## A. A plan that answers questions — 40 seconds, vertical

0–2: **“Who's actually hosting this?”**

2–15: Show a labelled test page with host, activity, time/place and cost expectations. “A clear plan answers the basics before an RSVP.”

15–27: Show the actual supported RSVP/change flow after testing. “Plans change. The page should say so before someone travels.”

27–40: “A real host, one small activity, no invented crowd. dilliscenes.me.” Use in host demos.

## B. The five questions — 20 seconds

0–2: **“A venue name isn't a plan.”**

2–14: On-screen list: host, what, when, where/how, cost. “If one is missing, ask before joining.”

14–20: “DilliScenes: clearer local plans.” URL. First owned clip.

## C. Going versus there — 20 seconds

0–2: **“Twelve going isn't twelve attending.”**

2–12: Use labelled illustrative stage cards: RSVP, update, actual event. “Count each honestly.”

12–20: “The useful result is a gathering that happens.” URL. Second clip; don't show fake app counts as live.

## D. Host walkthrough — 30 seconds, horizontal

0–2: **“Start with a plan you can actually run.”**

2–15: Explain one no-spend activity and the actual host/account path. Don't publish the test event for a video unless clearly labelled and authorized.

15–25: “Confirm arrangements, explain expectations, keep changes current.” Show the real supported edit/cancel flow only after verification.

25–30: “One host first, citywide reach later.” URL. Send to a known host who agreed to see it.
