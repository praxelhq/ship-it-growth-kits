# RoastMaster — Distribution map

**Original before/after examples first.** Avoid publicly roasting strangers' profiles. Estimates are unmeasured assumptions for 20 personal invitations, two permissioned bulletins and three owned clips/posts.

| Route | Permission and action | Expected result / copy |
| --- | --- | --- |
| 20 known adult project builders | Ten invitations on Days 6/9. Offer a fictional paragraph first; no resume collection by DM. | 6–12 starts, 3–8 useful reports; #1. |
| Two existing adult career/build circles | Admin permission, different circles/weeks from Kriya and other CV products. One example per accepted bulletin. | Combined 60–140 views, 3–9 starts; #2. |
| Your [LinkedIn](https://www.linkedin.com/) profile | Three original clips; disclose you built it. [Basic is free](https://www.linkedin.com/help/linkedin/answer/a545596). No tagging a candidate as an example. | Combined 90–300 impressions, 1–6 starts; #3. |
| [Peerlist](https://peerlist.io/launchpad) | Optional free usable-product entry; current slot/prior listing checked. State one-pager-only and test payment status. No votes requested. | 0–5 starts, upside excluded from base; #4. |

Base is 10–27 starts before overlap, perhaps 5–17 complete actionable reports. It does not substantiate 1,000. A real source of career readers is useful only when its admin allows a pitch; no unverified subreddit, newsletter placement or recruiter partnership supplies forecast traffic. The optional free [Product Hunt](https://www.producthunt.com/launch) guide requires personal maker participation and no direct upvote requests; do not add it as a second guaranteed launch.

People can send a private real document only after your product accurately explains processing/retention. For a group exercise use fictional text, not forced public critique. Same organizer gets one cohort product invitation that week.
