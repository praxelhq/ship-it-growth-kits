# RoastMaster — Landing page fixes

Observed 29 October 2026: **“Everything you made is mid. Let's prove it.”**, “Roast me” → the actual one-pager form, **“We roast the document, not you.”** Sample: ₹99 fix and **“Payments are in test mode during launch.”** No submitted text/report or live payment was tested.

1. **Bring test-payment status into the offer.** Homepage “Fix ₹99” looks purchasable while the sample says test mode. Replacement **“Free one-pager critique. Paid fixes are not available as a verified live purchase during this launch test.”** Disable live-looking payment promises until actual mode, terms and delivery pass. Do not edit a test hostname into a production hostname as a shortcut.
2. **Make the usable category explicit.** Hero replacement **“Your one pager can be clearer. Let's find the weak lines.”** Support **“Sharp feedback on the document, not a judgment of you.”** CTA **“Critique my one pager”** → existing form. Keep coming-soon cards visibly unavailable; do not send dating-profile traffic to a resume form.
3. **Preview tone and data choices before paste.** Put **“Read a sample first”** beside the form, linking to the labelled sample. State actual processing providers, retention, deletion and support before private input. Add **“Use a fictional paragraph to test. Remove personal contact details before pasting.”** This is risk reduction, not a guarantee that redacted text is anonymous.
4. **Make feedback fact-preserving.** Report instruction **“Use only facts you can support. If no outcome metric exists, clarify the action and scope instead of inventing one.”** Mark sample 4/10 as **“Illustrative sample, not a verified customer result.”** A score needs a plain rubric and uncertainty; no hiring probability.
5. **Handle form failure honestly.** Current length range is 200–8,000 characters. Show counts and recoverable errors: **“The report didn't complete. Your submission has not produced a result; try again or return later.”** Test minimum/maximum lengths and whether content is preserved safely. Don't count an endless loading state as a roast.
6. **Mobile and link preview.** Title **“RoastMaster — useful feedback on your one pager”**. Description **“Critique the document, keep the facts. Preview the tone before pasting.”** Test keyboard, paste length, visible error focus and report readability. Never use a real CV or named applicant in metadata.
