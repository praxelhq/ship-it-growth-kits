# TidyRow — Landing-page fixes

Read 29 October 2026. Actual headline **“Clean messy spreadsheets without doing the cleanup yourself.”** Public **“See an example”** / **“Download this sample CSV”** and Google/email sign-in entry. Free $0, Pro $5 USD/month plus applicable tax; no authenticated cleanup/billing test completed.

1. **Replace hands-off certainty with review.** Replacement headline **“Clean recurring spreadsheets with changes you can review.”** Support **“Keep the original, inspect changed cells and resolve flagged issues before exporting.”** Current illustrative unresolved-email example should stay prominent.
2. **Put processing choice before data.** Replacement **“Basic cleanup runs in this browser. AI planning can send instructions/column names; AI cleanup can send selected cell values through our server to Gemini. Choose knowingly.”** Link actual privacy; do not imply every feature is local.
3. **Explain recovery honestly.** Replacement **“Browser recovery is not cloud backup. Download your files and workflows you need before clearing site data. Clearing local data does not delete your account or previously sent AI-provider data.”** Test actual recovery/export; don't promise unsupported workflow portability.
4. **Make allowances readable.** Replacement **“Free: 10,000 rows per file, 15 files and 100 operations per month. Pro: 100,000 rows per file, 500 files, 5,000 operations and 100 local workflows.”** Add actual operation definition, failed/cancelled consumption, AI 100-row batches and UTC monthly reset. The 100 MB advertising is separate from row/usage limits.
5. **Keep import preparation separate.** Replacement **“Checks selected destination rules. You download and import yourself; unresolved issues may remain.”** No automatic HubSpot/Salesforce/Shopify import or certification. Show the actual rule/version checked.
6. **Treat likely duplicates carefully.** Replacement **“Review suggested matches before merging or removing. Similar details can belong to different records.”** Test identical versus fuzzy, ambiguous dates, leading-zero IDs and currency. Don't infer missing contact facts or change sensitive values just to improve a score.
7. **Clarify real versus simulated payment.** Pro renews monthly, no annual plan; checkout final total/current access-end/cancel route. Preserve Test mode labels wherever simulated. Test actual phone sign-in, preview, undo/recovery, limits and export using synthetic data. No raw cells or account/payment screens in replay.
