# Orbit — Video scripts

Use fictional profile data and owned drafts. Show real prototype limits; don't fabricate a connected community behind the screen.

## A. Prototype demo — 50 seconds

0–2s: **“This is a demo, not a live brand-deal network.”**

2–12s, show setup and local-storage notice. “A profile stays in this browser today.”

12–25s, use fictional data and show actual local save after verified. “These preferences test the workflow; they don't connect Instagram.”

25–38s, show sample crew/brief labels. “Samples explain the idea, not available people or paid work.”

38–50s, show a separate real owned draft/revision. “The pilot question is whether specific feedback improves a draft. orbitcrew.me.”

## B. Hook — 15 seconds, Short

0–2s: “'Nice post' didn't help this draft.”

2–10s: an owned draft, specific critique, revised hook. “One clear reason. One useful revision.”

10–15s: URL and **Disclosed prototype · voluntary feedback**.

## C. Integration honesty — 20 seconds, LinkedIn

0–2s: “Entering a handle isn't connecting Instagram.”

2–12s: actual inactive connection notice. “The demo should make that clear before asking for trust.”

12–20s: local-profile label and URL. No fake analytics import animation.

## D. Real review lesson — 20 seconds

0–2s: “What changed after the feedback?”

2–12s: a real owned draft before/after, with critique permission if another person provided it. “Not more engagement—a clearer point.”

12–20s: product prototype boundary. If no real review happened yet, record an owned self-edit and label it honestly.
