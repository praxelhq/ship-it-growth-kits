# Patterlane — Video scripts

Public footage uses fictional sample mail only. No real addresses/names, provider credentials, invitation/session tokens or activity exports. Web sample doesn't send email or run AI; native claims require separate actual release tests.

## A. Sample demonstration — 55 seconds, landing/session

**0–7s:** Sample workspace with obvious *Fictional messages; browser sample* label. “Can a conversation feel calmer than an inbox?”

**7–19s:** Open an actual sample thread. “Follow the person and the conversation.” Don't call cleaned quoted replies proof every real MIME/thread case works.

**19–30s:** Add an actual sample to-do/private note using the real control. “Keep a next step beside the conversation.” No claim this syncs to Google/Outlook calendar.

**30–40s:** Switch actual English/Hindi interface, show sample message unchanged. “Interface language changes; the original words stay theirs.” No generated translation claim.

**40–48s:** Draft a sample reply. “This is a browser draft, not a real email send. No AI model runs here.” Avoid a fake success toast implying delivery.

**48–55s:** Sample CTA plus native release status: signing/notarization/provider/model/support checks open; no install/credentials required. URL.

## B. Hook — 23 seconds, Day 10

**0–5s:** Fictional conversation beside a task. “The useful bit might be the next step, not another inbox skin.”

**5–15s:** Actual sample message→to-do flow. “What would you do after reading this?”

**15–23s:** “Try the sample. No real mail, no install.” URL and fictional-data label. No invented customer praise.

## C. Hook — 25 seconds, Day 16

**0–6s:** Sample versus desktop columns. “A browser demo doesn't prove live email works.”

**6–17s:** Real release-status text, then sample action. “This sample is for workflow critique. Native startup/provider/local-model checks remain separate.”

**17–25s:** “Don't enter real mail credentials for my public demo.” URL/sample. Never turn unverified app footage into a supported-release promise.

## D. Hook — 25 seconds, Day 24

**0–6s:** Actual join card. “First 100 invited isn't the same as open free access.”

**6–17s:** Show price/access text without any token/address. “Accepted personal invitations get ongoing free access. Later price $5/person/month; payments aren't open.”

**17–25s:** “Sample first, with the limits clear.” URL. Update actual access status before export; don't repeat a stale configuration blocker if fixed.

A later native demonstration needs real compatible Mac startup, test-provider mail send/review and model/network checks, all on owner-controlled accounts. Don't substitute a fake inbox animation for that evidence.
