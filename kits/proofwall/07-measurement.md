# Proofwall —Measurement

**Target:10 real business customers**, under [policy](../../TARGET-POLICY.md). Four tests: genuine business; own authorized business/customer material onboarded; independent use in the last seven days; privately known owner name/phone. Keep identity records outside this public repo. Testimonials, client contributors, embeds and wall views are separate counts.

Signup is an owner account. Activation is an owner's own permitted submission reviewed and correctly displayed on a site it controls, with removal verified. A fictional demo is not activation. Count selected testimonials honestly; owner approval doesn't independently authenticate a statement or prove representativeness.

Private baselines unknown: real businesses, own collection links, permissioned submissions, approval/display success, removal requests/completion, independent recent use and actual subscriptions. Save current rank/reading/period/sync from [profile](https://shipped.money/p/proofwall); unknown isn't zero and rolling readings aren't cumulative.

Check existing [Clarity](https://clarity.microsoft.com/) before adding a tag. Exclude contributor identities, raw testimonial text/media, unpublished content, consent details and account screens. Aggregate events: owner_created, own_collection_ready, submission_received, publication_permission_confirmed, approved_embed_visible, removal_confirmed, independent_owner_return. A copied code or clicked approval isn't proof the public page is correct.
