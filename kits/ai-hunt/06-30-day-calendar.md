# AI Hunt — 30-day calendar

Start once source labels, public browsing and signup work on a fresh phone. Every day: 15 minutes answering genuine replies and 10 minutes logging visits, accounts and source opens. Build days and posting days are separate. Times are IST.

| Day | Main action | Time |
| --- | --- | --- |
| 1 | Record `07` baseline; test browse→official source and account→vote. Reconcile starter/editorial labels (`04` Fix 1). | 3h |
| 2 | Check ten entries against official sources; remove unverified try links. | 3h |
| 3 | Ship hero and reader CTA (`04` Fixes 2–3); ask a classmate to find a tool unaided. | 2h |
| 4 | Ask one existing campus group admin for a briefing slot (`03` #1). | 1h |
| 5 | Record videos A/B with three genuinely checked releases. | 2h |
| 6 | After permission, invite up to 40 classmates through the existing group and run the accepted briefing at 18:00; #4 only for interested classmates. | 2h |
| 7 | First checkpoint; inspect source-open and account rates, not votes alone. | 1h |
| 8 | Publish LinkedIn teaching post #3 at 09:00. Answer questions for an hour. | 2h |
| 9 | Fix the most common missing entry field from reader feedback. | 2h |
| 10 | Send five maker fact-check notes #7 using public contact routes. | 1h |
| 11 | Write one task-specific three-release briefing; verify every link again. | 2h |
| 12 | Publish the briefing to opted-in readers and your LinkedIn feed at 09:00; no unsolicited newsletter additions. | 1h |
| 13 | Read current Peerlist eligibility and prepare #2; do not promise a slot. | 1h |
| 14 | Checkpoint: ask five readers what they used after leaving AI Hunt. | 2h |
| 15 | Launch on the next eligible Peerlist slot, or publish the working project to Scroll. | 2h |
| 16 | Fix source/access errors reported in launch replies. | 2h |
| 17 | Send the next five maker fact-check notes; no votes requested. | 1h |
| 18 | Publish video C to LinkedIn at 09:00 showing the actual credibility fix. | 1h |
| 19 | Ask one new organizer for permission to repeat the briefing; check cohort calendar first. | 1h |
| 20 | Build a second shortlist around the task readers requested most. | 2h |
| 21 | Checkpoint; compare week-two returning readers with one-time makers. | 1h |
| 22 | Inspect Product Hunt listing status and prepare #5 only if eligible. | 1h |
| 23 | Optional Product Hunt launch, otherwise repeat the best owned-feed format. | 3h |
| 24 | Spend the day on replies and broken-source corrections. | 2h |
| 25 | Send the third set of five maker fact-check notes. | 1h |
| 26 | Publish second briefing to opt-ins and LinkedIn at 09:00; invite a factual correction. | 2h |
| 27 | Read Reddit rules and ask moderators if still unclear; #6 only after permission. | 1h |
| 28 | Recheck the ten most-opened entries and their access status. | 2h |
| 29 | Interview five returning readers; stop the format that attracted only self-voting makers. | 2h |
| 30 | Complete `07`; report real accounts, activated readers, return rate and remaining gap to target. | 2h |

If a briefing produces no source opens, do not increase posting volume. Watch five people attempt the task and repair the index. If a channel produces real readers, trade the optional Product Hunt/Reddit slots for a second relevant briefing with permission.
