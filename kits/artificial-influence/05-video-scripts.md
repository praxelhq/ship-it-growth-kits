# Artificial Influence — Video scripts

Use your own brand or written permission. Never expose API keys, client-sensitive questions or fabricated dashboard results.

## A.65-second evidence demo — homepage / LinkedIn
0–2: mention number beside question; **“Mentioned in which answer?”**
2–15: show one actual buyer question, provider and date.
15–32: open the real raw answer and source. “The number needs this context.”
32–48: show run count and quality label. “A provisional result stays provisional.”
48–58: identify one supported information gap, not a ranking promise.
58–65: “Free starts with one brand/five questions on one engine. artificialinfluence.space.”

If no real permissioned output is ready, label the entire walkthrough sample and keep the public live-example status unchanged.

## B.20-second hook
0–2: **“Five mentions isn't five customers.”**
2–13: show a clearly labelled sample answer set and explain that visibility is not revenue.
13–20: “Measure the answer first. Track business outcomes separately.”

## C.25-second hook
0–2: quality badge, **“Insufficient is useful.”**
2–14: show an actual or labelled example with too little evidence.
14–22: “The honest result is not enough data, not a confident zero.”
22–25: full URL.

Phone mic, large captions, hard cuts. Never claim a provider endorsed the tool or that one changed source caused future AI answers.
