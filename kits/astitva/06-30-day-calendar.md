# Astitva — 30-day calendar

**Day 1 starts when a fresh founder can reach the real output.** If signup or generation fails, use the first days to repair it and shift the outreach calendar. Keep the 30-day record honest. All times below are IST; use your prospect's local working hours when outside India.

Daily: 20 minutes answering existing conversations, 10 minutes updating the private prospect log. New outreach is capped at five carefully researched approaches on an outreach day; the cap is a workload choice, not a platform guarantee. One follow-up after seven days, then stop. Build days and publishing days are separate so you can see what changed.

| Day | Main task and output | Time |
| --- | --- | --- |
| 1 | Test signup → brief → two slides with a fresh account; record the real restrictions and `07` baseline. | 3h |
| 2 | Implement `04` fixes 1–2: free scope, actual CTA and credit boundary. Ask one unfamiliar person to try. | 3h |
| 3 | Record `05` A and C; prepare the real sample export. Build the first 20 qualified-founder list entries. | 3h |
| 4 | Ask 10 warm contacts for a relevant introduction using `03` #1. Reserve one permitted clinic within days 4–7. | 2h |
| 5 | Send five individualized founder messages, `03` #2. Log the specific deck problem; don't offer generic logo feedback. | 2h |
| 6 | Host the accepted clinic, or do three private demonstrations if no organizer accepts. Use #4 only with permission. | 3h |
| 7 | Review week 1 in `07`: where did founders stop, and did anyone return without prompting? | 2h |
| 8 | Build day: fix the single largest observed brief-to-output blocker; don't add new channels. | 3h |
| 9 | Publish #5 with demo A on your own LinkedIn at 09:00; answer for one hour. Five relevant approaches. | 3h |
| 10 | Onboard up to three interested founders using their own non-confidential briefs. Observe without doing the work for them. | 3h |
| 11 | Follow up once with day-4 contacts who showed interest. Ask a current local Headstart organizer about a free clinic, #1. | 2h |
| 12 | Publish video B and the three-part X sequence, #6, at 18:00. Record actual visits and trials. | 2h |
| 13 | Send five new founder messages; ask two existing users what they changed in their deck after first export. | 2h |
| 14 | Week-2 checkpoint. Separate assisted trials, independent activations and qualifying active businesses. | 2h |
| 15 | Build day: ship `04` fix 6 only if return-use evidence supports it; improve the next-revision path. | 3h |
| 16 | Inspect existing Product Hunt listing and Peerlist eligibility. Prepare #7; choose the next eligible Monday, not an invented slot. | 2h |
| 17 | Support existing founder users while Postifyy's student window runs. Five private, non-overlapping founder approaches. | 2h |
| 18 | Give the clinic organizer #8 only if they requested an email blurb. No mailing-list access assumed. | 1h |
| 19 | Publish video D. Explain one real factual correction in your own example, without implying funding outcomes. | 2h |
| 20 | Run another accepted private demo; check whether the founder can make the next edit alone. | 2h |
| 21 | Week-3 checkpoint. If fewer than five active businesses, identify whether qualification, trial or return use is failing. | 2h |
| 22 | Build day: repair the worst observed export or editing friction. Retest with one fresh account. | 3h |
| 23 | Use the eligible Peerlist slot if available; otherwise publish one output walkthrough on your own feed. Copy #7. | 3h |
| 24 | Adya has the shared founder-group invitation window. Work your own follow-ups; don't pitch into the same group. | 2h |
| 25 | Ask two independently active founders for a permissioned example; don't ask them to manufacture engagement. | 2h |
| 26 | Publish a new example of a real edit with #5 rewritten around what changed. Five qualified approaches. | 3h |
| 27 | Close unanswered outreach after the allowed follow-up. Spend the saved time observing an existing customer's workflow. | 2h |
| 28 | Week-4 checkpoint: audit the four business-customer tests, especially unprompted use in the last seven days. | 2h |
| 29 | Send the final five new qualified approaches through your best measured source, making 30 explicit new approaches this month. No new directory hunt. | 3h |
| 30 | Final review: active businesses, exports, returning businesses, credit revenue, refunds, hours and next-month decision. | 2h |

If three real prospects are blocked by the same product failure, pause acquisition and fix it. If a public post brings relevant questions, use tomorrow's outreach time to answer them. An accepted partner session replaces that day's new outreach; it is not an extra six-hour obligation.
