# Think More — Landing-page fixes

Checked 29 October 2026: public home and browser navigation through Practice→Logic→first exercise. No answer, voice, sign-in or feedback submission was made. The observed initial answer gate was disabled until 20 characters.

1. **Connect the real headline to one next action.** Current “Think More” / “Less scrolling. More thinking” and “AI can do the thinking. You should still do some” lead to subject selection. Add **“Try one short question. Write your first reason before opening help.”** Make **“Try one everyday-logic exercise”** the simple default, while keeping subject choice available.

2. **Reduce the menu before the first attempt.** Practice offers six subjects, activities, four feedback modes and difficulty. Start with a clearly labelled default, then **“Change the question or style”** as secondary. Preserve the distinction **“Difficulty changes the exercise. Mode changes the feedback.”** Don't imply Intense mode is a validated higher-intelligence test.

3. **State the anonymous coaching model honestly.** The session says without an account it uses written coaching notes and local answers. Repeat **“Anonymous practice: written coaching notes, answers stored in this browser. Sign in only if you want the actual synced features.”** Verify signed-in AI/data behavior before promising it. AI appearing in the brand story does not prove every response is live generation.

4. **Make the answer gate useful, not punitive.** Current field allows 600 characters and requires 20 for feedback. Say **“Give a reason and one example. At least 20 characters so there's an attempt to work with.”** A minimum length is not learning evidence; review whether feedback recognizes an actual argument rather than only word count.

5. **Keep hints optional and input choice clear.** Current Ellie offers three hints and voice becomes editable text. Show **“Type if you prefer. Read what voice capture sends before enabling it.”** No automatic microphone request on page load. Do not ask testers for a recording when written feedback suffices.

6. **Explain local progress and sync before loss.** Current practice says notes/progress stay in this browser and sign-in syncs across devices. Add **“Changing browser or clearing storage may lose local practice. Read the sync/storage details before signing in.”** Test actual behavior rather than treating the statement as audited fact. No paid plan was observed; don't invent a premium tier.

7. **Phone and preview checks.** Title **“Think More — one attempt before the explanation”**; description **“Short reasoning practice with hints and clear feedback choices. Try typing without an account.”** Test keyboard, visible character count, disabled/enabled Submit, back navigation and feedback failure recovery on a phone. The read-only route check didn't complete a submitted response or sync test.
