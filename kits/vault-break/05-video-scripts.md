# Vault Break — Video scripts

Use original screen recordings. Hide answers and real player names unless they consent. No fake speed run or fabricated rank.

## A. One safe, one friend — 60 seconds

**Hook:** “Your friend gets exactly the same locks.”

| Time | Shot/text | Spoken line |
| --- | --- | --- |
| 0–10s | Open the first vault, no account form | “Crack the Vault starts with a free safe.” |
| 10–25s | One original lock, answer blurred in recording | “Solve locks to earn digits before the clock runs out.” |
| 25–38s | Genuine result, no invented time | “This is my actual result, not a leaderboard example.” |
| 38–50s | Tap Share, open challenge on second device | “The link gives a friend these same questions and one shot.” |
| 50–60s | Hold URL and price terms | “Try the first two free. The rest of the full set is optional $1 once.” |

Post to your itch page and permitted campus invitation. If Share or the guest run fails, fix it before recording a success claim.

## B. Same clock — 20 seconds

**Hook:** “Different questions aren't a fair race.” Show two pretend scorecards labelled illustrative, cross them out, then open a real same-question challenge. Say: “A fast time means little if the questions changed. This link keeps the locks the same.” Do not show solutions. Use an original Short.

## C. No spoilers — 15 seconds

**Hook:** “Send the result. Keep the answer.” Show a finished-run grid, the Share action and the friend's unopened challenge. Say: “The grid says how it went without giving away the locks. One friend, one fair attempt.” End with the domain; no gameplay claims beyond the tested flow.

## D. Clean beats quick — 25 seconds

**Hook:** “A messy fast run doesn't win everything.” Show your own result, then the public explanation of rank before time. Say: “The board prioritizes a clean first crack. Replays are practice; challenges are separate. Read the rules before you compare.” Use as a response to fairness questions, not as an independently verified anti-cheat claim.
