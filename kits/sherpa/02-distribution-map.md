# Sherpa — Distribution map, listing recovery first

**Zero public acquisition reach is forecast until the package, availability and use case are known.** A 404 Play link and course profile are not working app destinations.

| Route | Purpose and permission | Expected result / copy |
| --- | --- | --- |
| Owner's [Play Console](https://play.google.com/console/about/) and existing release records | Verify package identity, intended audience, device/region/testing availability and actual release state. Authorized owner access only. | One factual availability diagnosis, not an install; #1. |
| Existing legitimate app collaborator | Reconcile current build, package and demonstrated first action if such a collaborator exists. Never send signing keys/credentials. | One source confirmation, not an assumed team; #2. |
| [Shipped sign-in](https://shipped.money/signin) / [submission](https://shipped.money/app/submit) | Owner corrects the app record after the real public/test access route is verified. No record was changed during research. | Accurate identity/link, not a signup; #3. |
| Three consenting adult Android testers after recovery | Use intended supported devices and official authorized access. Ask for an uncoached first action; no private data/payment for navigation feedback. | Three attempts, actual install/launch/use counted separately; #4. |
| Five genuine prospective users after job confirmation | Ask about current alternative and where they discovered it. No guessed hiking/student group. | Five conversations if accepted, no acquisition forecast; #6. |

[Product Hunt](https://www.producthunt.com/launch) and [Peerlist](https://peerlist.io/launchpad) may later carry a truthful maker submission after the app is usable and eligibility/current slots are checked. Personal participation, no direct upvote requests or vote swaps. Neither is scheduled as a current launch or counted as guaranteed traffic.

Specialist communities, newsletters, creator accounts and offline groups must follow the recovered actual user job. Verify two destinations named by real users, read the rules and get organizer permission before pitching. Do not distribute an unverified APK as a shortcut around an unexplained listing. No paid listing, editorial placement or app-install campaign is budgeted.
