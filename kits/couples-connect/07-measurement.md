# Couples Connect — Measurement

**B2C target: 1,000 signups in 30 days.** The free no-account entry uses the policy's session equivalent: one person's first meaningful session, defined as a Radio memory played intentionally or a table joined. Report **completed two-person reveals** alongside it. Also report member accounts and paid memberships separately; do not add these overlapping counts.

No private analytics were accessed. Record unknown baseline values before posting, not zero.

| Day 0 measure | Source |
| --- | --- |
| First listeners and table participants / last 7 days | Aggregate product events, with deduplication limits documented |
| Completed reveals and repeat pairs | Product records without answer text |
| Existing members, renewals/refunds | Account/payment records |
| Seven-day traffic and sources | Existing consented analytics / [Clarity](https://clarity.microsoft.com/) |
| Latest course metric, rank and timestamp | [Course profile](https://shipped.money/p/couples-connect) |

Check existing Clarity before adding it. Mask all answer fields, memory content, table tokens, names and payment data. Track `radio_play_started`, `table_joined`, `both_answers_submitted`, `reveal_completed`, `second_table_completed` and `membership_verified`, without the actual words spoken or written.

| Checkpoint | What matters | Response |
| --- | --- | --- |
| Day 7 | Can ten willing pairs understand joining/reveal? | Fix the first blocked step before broader invitations. |
| Day 14 | First listeners versus completed pairs | Many listens and no pairs: clarify which experience is being offered and the price boundary. |
| Day 21 | Voluntary second conversation | No return: improve the prompt/occasion; don't infer that more advertising fixes it. |
| Day 30 | Actual count against 1,000; reveals and repeat pairs beside it | State the shortfall and best route honestly. |

At 50% visit-to-meaningful-start, 1,000 requires 2,000 distinct relevant visits. The initial scheduled tests may yield only tens or low hundreds. Do not count a person listening to three free memories as three signups, or two people completing one table as two completed pairs.

Keep a channel log of visits, first sessions, table joins, reveals, repeats and hours. A public notebook snippet is not a user review. A course traffic reading is not private-table participation. You can learn whether the product's interaction works without learning what anyone confessed.
