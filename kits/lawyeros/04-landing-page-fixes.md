# Lawyer OS — Landing-page fixes

Read [lawyeros.online](https://lawyeros.online/) on 29 October 2026. Actual headline: **“Your cases, hearings and documents in one place.”** CTAs: **“Start free”** / **“See demo.”** Free $0/five cases; Individual $4.99/month/one lawyer; Firm $20/month/ten lawyers total. The sample demo saves nothing. Authentication, storage, firm permissions, export/deletion and checkout were not exercised.

## 1. Keep the sample route before real-data commitment

Current page already labels sample views and a no-save demo.

Replacement supporting line: **“Inspect a fictional case first. Decide about actual practice records only after reviewing access, storage and recovery.”**

Keep See demo as a clear route. Do not imply reading a sample means the lawyer has onboarded or proven the real workflow.

## 2. Bring coming-soon boundaries near the first decision

Current list marks WhatsApp/SMS reminders, CNR import and client-update links coming soon.

Replacement scope strip: **“Current: manual case records, dates and documents. Planned: messaging reminders, CNR import and client-update links.”**

Verify the current actual feature set before publishing that strip. Never use a CNR import demonstration if only a future feature exists.

## 3. Explain the date's source and review responsibility

Current promise can sound like the notebook and all hearing checks become unnecessary.

Replacement date help: **“Enter and verify this date against your authoritative record. Keep your established deadline checks during evaluation.”**

Test timezone, edit, duplicate matter and stale-date presentation. Do not invent automatic court sync or legal reliability guarantees.

## 4. Make firm permissions inspectable

Current claim: share selected cases with up to ten lawyers; private cases stay hidden even from firm owner.

Replacement permission summary: **“Review who can view and edit each case before sharing. Test private and firm cases with sample accounts.”**

Verify owner/member access, direct file links, revoked members and sign-out behavior using synthetic records. Publish the actual tested roles, not a security badge or unverified vulnerability accusation.

## 5. Keep plan/case/seat limits separate

Current pricing is USD monthly with distinct case and lawyer limits.

Replacement strip: **“Free: five cases. Individual: unlimited cases for one lawyer, $4.99/month. Firm: up to ten lawyers total, $20/month. Review final tax/billing terms before payment.”**

State which actions count toward case/seat limits and what happens after downgrade or cancellation only after verifying it. Ten seats are not ten businesses for traction.

## 6. Explain files, recovery and deletion before upload

Current documents include private attachments up to 20 MB each; storage/recovery was not exercised.

Replacement upload note: **“Use only files you are authorized to process. Review permissions and retention first. Keep originals and verify a saved file can be reopened.”**

Test synthetic attachment limits, wrong file type, interrupted upload, owner/member access and deletion/export. Show support and privacy information before requesting sensitive records. Pause real-data onboarding for unexplained access or loss; a public feature card is not proof of safe case storage.
