# Roamio — Positioning

**Live:** https://roamiio.me/ · **Category:** Trip organization · **Profile:** https://shipped.money/p/roamio

**Your site is live now; the roster's earlier down label is stale.** The actual browser headline checked 29 October is **“Hey, Explorer!”** The CTA is **“Plan a trip.”** It opens a form for destination, trip name, dates, travel mode and companions, ending with **“Create trip folder.”** No trip was saved during research.

Your first user already has a real weekend trip in mind and scattered details in notes/chat. They need one place to resume planning. They are not buying a booking, live fare comparison or guaranteed travel advice.

**Pitch:** Give each trip its own folder so you can organize it and find your place again.

**Short version:** One trip. One folder. Pick it up where you left it.

## The wedge

Create a folder for one known trip, add a useful detail through the actual supported flow, leave and reopen it. That return is more valuable than an attractive empty dashboard. The public copy says deleting a folder removes details from this browser; explain actual storage/recovery before someone trusts it with plans.

[Google Maps](https://www.google.com/maps/about/) provides public place discovery and saved lists with group collaboration. An existing notes document is another no-extra-purchase alternative. Roamio earns attention by organizing the trip's context, not claiming a generic AI can plan everything better. No public paid plan was visible in the inspected entry/setup; don't invent a subscription or permanent-free promise.

## The uncomfortable bit

There is a Google sign-in button and a GLOBI helper, but their behaviour wasn't tested. Don't claim cloud sync, private AI, booking access or companion invitations work merely because a control exists. The trip form says companions can be invited later; verify the real handoff before promotion.

Keep the B2C target at 1,000 first meaningful trip-folder sessions, with folders reopened and a useful detail retained beside it. If accounts are used, report them separately. Never count fictional demo destinations or repeated clicks as real trips taken.
