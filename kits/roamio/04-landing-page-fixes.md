# Roamio — Landing page fixes

Based on the homepage and actual Plan-a-trip modal viewed 29 October. No trip/profile/sign-in was submitted.

## 1. Prove persistence before asking for real plans

Test a fictional folder: create, add one supported detail, leave, reopen, refresh, try a second browser and delete. The public deletion text refers to this browser, while Google sign-in is also visible. Explain which data is local and whether sign-in changes sync/recovery. Don't imply cloud backup until verified.

## 2. Make the headline do more work

Current headline: **“Hey, Explorer!”** CTA: **“Plan a trip.”**

Suggested heading: **“Keep one trip's plan in one folder.”** Support: **“Start with a destination and dates, add details through the supported tools, and return when you're ready.”** Button: **“Create my first trip folder.”** Keep the friendly explorer greeting inside the dashboard.

## 3. Tell users what is required

The modal asks destination, name, dates, travel mode and companions. Mark actual required fields and allow “not decided” where supported. Copy: **“You can fill in the rest later.”** Don't force a fictional date or travel mode merely to create a useful draft.

## 4. Separate helper/invite controls from verified capabilities

GLOBI and Google sign-in are visible, but their functioning wasn't established here. Label a helper's actual scope and limits; don't advertise live fares, bookings or up-to-date travel rules without a real source. Only promise companion sharing after a second-person invitation test passes.

## 5. Make deletion and recovery understandable

Current copy says removing a trip deletes saved details from this browser. Show the actual consequence before deletion and provide a reversible option if implemented. Explain how to keep a copy using existing export/copy features; don't invent an export button that doesn't exist.

## 6. Test phone planning

At 390px, check date input, long destinations, keyboard overlap, modal close and returning after interruption. Mask trip dates, companion identities, documents and exact locations from replay. Preview: **“Roamio — one trip, one place to continue the plan.”** No private itinerary or travel-document image.
