# Roamio — Video scripts

Use fictional destination/dates and owned sample details. No passport, ticket, hotel code or real companion contact in a public recording.

## A. Return-path demo — 50 seconds

0–2s: **“Will the plan still be useful when I come back?”**

2–15s, create fictional folder through the real modal. “One destination, dates and a name I can recognize.”

15–28s, add one actual supported detail. “This is the piece I want to find again.”

28–40s, leave/reopen the page and folder. “The return path is the product test.” Don't fake persistence with an edited screenshot.

40–50s: actual storage/sign-in explanation and URL. “Not a booking service. roamiio.me.”

## B. Hook — 15 seconds

0–2s: “Where did we put that plan?”

2–10s: scattered fictional notes → actual trip folder. “Give this trip one place to live.”

10–15s: URL and **Fictional travel details**.

## C. Storage honesty — 20 seconds, LinkedIn

0–2s: “Saved where?”

2–12s: show the actual local/sync explanation after verification. “A traveler should know before closing the browser.”

12–20s: reopen the fictional detail. “Persistence beats a pretty empty dashboard.”

## D. Setup hook — 20 seconds

0–2s: “You don't know every detail yet.”

2–12s: show actual optional/not-decided setup choices. “Start with what you know, keep the rest open.”

12–20s: save only through the real supported flow. No invented booking/AI output.
