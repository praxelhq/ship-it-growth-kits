# The Docket Dispatch — Measurement

**B2C target: 1,000 signups in 30 days.** Count real confirmed newsletter recipients once, only after a working list exists. Put **first issue delivered** and **official source/eligible-call inspection** beside signup. Paid subscribers, free-interest readers, local prototype form completions and visitors are separate. A local browser entry isn't received by the publication and cannot count as a reader subscription.

No private metrics were accessed. Privacy's local-only form statement means live signup readiness is unresolved, not that every metric is zero. Establish actual state with the operator.

| Baseline | Source |
| --- | --- |
| Real list confirmation and delivery capability | Authorized end-to-end test, no private addresses published |
| Distinct confirmed recipients / last seven days | Actual provider records, exclude tests |
| Issue sends/deliveries/failures/unsubscribes | Provider status, not page success labels |
| Source clicks and voluntary relevance feedback | Aggregate events, no application content |
| Real paid plans, renewals/cancellations/errors | Verified payment records only if connected |
| Traffic/course metric/rank/time | Existing consented analytics and [profile](https://shipped.money/p/the-docket-dispatch) |

Check existing [Clarity](https://clarity.microsoft.com/) and actual consent/masking before adding scripts. Exclude emails, plan form details, confirmation tokens and payment fields from replay. Track status `subscription_confirmed`, `issue_delivered`, `source_opened`, `correction_published`, `unsubscribed`. Email opens are imperfect; don't claim every tracked open equals reading.

| Checkpoint | Evidence | Decision |
| --- | --- | --- |
| Day 7 | Real issue, working list and exact offer established | If unresolved, continue recovery and no subscriber/sales claim. |
| Day 14 | Willing readers receive the issue and understand sample/source limits | Repair delivery and confusing evidence boundaries first. |
| Day 21 | Sources support stage/eligibility/date fields | Correct errors and do not infer grants won from clicks. |
| Day 30 | Confirmed readers versus 1,000; delivery/source use beside it | Report target gap and unresolved readiness explicitly. |

`02` suggests about 15–110 gross signups before overlap only if readiness passes. At 30% visit→confirmed signup, 1,000 needs roughly 3,334 distinct qualified visits. A paid-only conversion funnel may be lower; measure it rather than using free-interest assumptions. Four posts/three clips don't guarantee reach.

No current grant amounts/deadlines, founder production history or “38 days” discovery advantage were independently verified. Don't report grant wins, prevented losses or saved hours from a signup. Overlapping course traffic readings aren't cumulative subscribers. Final delivery must flag the browser-only form contradiction as unresolved until evidence proves it fixed.
