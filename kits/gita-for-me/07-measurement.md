# Gita For Me — Measurement

**B2C target: 1,000 signups in 30 days.** The no-account preview uses **one person's first meaningful reflection session** as its signup equivalent. Report **completed reflections** and **source-context opens** beside it. A browser reset or second example is not a new person.

Private baseline values were not accessed. Record the real starting point before promotion.

| Day 0 measure | Source |
| --- | --- |
| First reflection starts/results / last 7 days | Aggregate status events, with deduplication limits stated |
| Source-context opens | Aggregate event, no personal concern text |
| Launch-update registrations | Confirmed form records, not CTA clicks |
| Known content/source errors | Private review log |
| Traffic/referrers | Existing consented analytics / [Clarity](https://clarity.microsoft.com/) |
| Course metric, rank and timestamp | [Profile](https://shipped.money/p/gita-for-me) |

Check whether Clarity already exists before adding scripts. Mask or exclude the input/result area if it contains private thoughts. Do not upload a concern into analytics to measure a product that says it stays local. Events: `reflection_started`, `curated_match_shown`, `context_opened`, `example_read`, `launch_updates_confirmed` using status only.

| Checkpoint | What you learn | Response |
| --- | --- | --- |
| Day 7 | Can five willing readers complete a reflection and identify the labels? | Fix the first confusing step before widening reach. |
| Day 14 | Do users understand it is curated, not live AI? | If not, change first-screen copy and demo. |
| Day 21 | Do readers open context or return to examples voluntarily? | Improve source accessibility; do not add false authority. |
| Day 30 | Actual first sessions against 1,000; reading/context use beside it | Report honest gap and the route worth repeating. |

At 50% visitor-to-start, 1,000 requires 2,000 distinct relevant visits. The scheduled experiments may yield only tens or low hundreds; replace rates after three clips. Don't describe 1,000 visits as 1,000 people helped.

₹99/month is a proposed offer, not revenue. An external waitlist click isn't a confirmed signup. A course 24-hour traffic reading isn't cumulative users. Success here means a clear, accurately labelled reading experience; don't measure or promise treatment, spiritual certainty or a solved personal crisis.
