# Supercharged — Video scripts

Use actual authorized gameplay capture. No install/play was performed for this research; the owner must record the real current demo. No fabricated frame rate, review, award, streamer or first-try success.

## A. Route demo — 50 seconds

0–2s: **“What if the gun built the next step?”**

2–12s: show the gap and an actual platform shot, enough context to understand the placement.

12–27s: chain the real wall-run/jump sequence through the route. “Create the path, then commit to the movement.” Keep one readable continuous section; label any cuts.

27–38s: show an actual failed attempt and recovery if one occurred. “The route has to be learnable, not just look fast.” Don't invent a bug/failure for drama.

38–50s: demo store CTA and Windows requirement. “Free demo, about 15–30 minutes per store description. Full game Coming Soon.”

## B. Platform hook — 15 seconds

0–2s: **“That platform wasn't there a moment ago.”**

2–10s: actual aim→shot→landing in one readable sequence. No fake UI or impossible edit.

10–15s: **Free Windows Steam demo** and main-game URL/Steam search title. Don't hide installation behind “play now in browser.”

## C. Recovery hook — 20 seconds

0–2s: **“I missed the route. Here's what I changed.”**

2–12s: actual own failed attempt then deliberate change, cuts labelled. “Different timing/placement,” only if true of the footage.

12–20s: successful actual attempt or honest still-testing limit. Demo CTA. No invented player quote.

## D. Scope hook — 20 seconds

0–2s: **“This is the demo, not the full game.”**

2–12s: show real available sections without implying every trailer environment is in the demo. “Try the core platform-gun and movement loop.”

12–20s: Windows/minimum-requirement reminder, separate wishlist invitation **“Follow the full game only if you want to.”** No reward/entry requirement for wishlisting.

Six scheduled clips reuse the best structure with different real routes or lessons. Don't produce six near-identical montages that never show why a player would understand the mechanic.
