# Supercharged — Measurement

**B2C target: 1,000 signups in 30 days.** As a game without a separate signup, use **distinct real people's first meaningful demo-player sessions** under the policy equivalent, subject to available Steam/game telemetry. Put **first platform-gun traversal completed** and voluntary continued play/demo completion beside it. Wishlist additions, follows, demo licences/downloads and main-game sales are different metrics. Never replace the assigned target with wishlists.

Private Steamworks records and gameplay weren't accessed. Record actual baseline; store “Coming soon” means full-game availability, not zero demo players.

| Baseline | Source |
| --- | --- |
| Demo unique players / seven days | Actual authorized Steamworks/game status, definition recorded |
| Downloads/licences versus launched/meaningful sessions | Separate available records, no invented visibility |
| First traversal and demo completion | Minimal game events if already available, or optional playtest observation |
| Failures/performance by volunteered device class | Aggregate issue log, no private logs/credentials |
| Main-game wishlists/follows | Separate authorized Steamworks interest records |
| Store traffic/course metric/rank/time | Actual source records and [profile](https://shipped.money/p/supercharged) |

Steam page traffic isn't meaningful play. Don't add web replay to a game to pretend you observed movement; inspect existing analytics first. If telemetry lacks a reliable player count, state that and use bounded observed playtests, not made-up installs. Events if supported: `demo_first_session`, `platform_traversal_completed`, `demo_completed`, `repeat_session`, aggregated without public Steam identity.

| Checkpoint | Evidence | Decision |
| --- | --- | --- |

| Day 30 | First meaningful players versus 1,000; traversal/continuation beside it | Report gap, compatibility limits and useful channel honestly. |

`02` implies about 18–131 gross players before overlap. At 30% store visit→demo start, 1,000 needs about 3,334 qualified visitors; about 333,400 clip views if only 1% visit, before overlap. Six clips don't guarantee this. Replace assumptions after three clips and observed installation rates.

Full-game release/price unannounced here; no sales or wishlist-to-purchase guarantee. Demo listed performance/support are publisher claims, not independently tested. Don't sum overlapping course snapshots, repeated launches, downloads and wishlists as new users or invent review/award proof.
