# Supercharged — Steam-page fixes

Main Steam page inspected in browser and separate demo listing read, 29 October. No install, gameplay, account action or purchase. Store copy is evidence of the offer, not tested performance.

1. **Lead every external invitation to the right product.** Actual title/H1 “Supercharged.” Action “Download” under “Download Supercharged Demo”; separate demo page says “Install Demo.” Full game “Coming soon.” Use **“Play the free Windows demo; full game coming later.”** Don't say buy/play the full release today or invent a price/date. Keep main-game wishlist and demo download distinct.

2. **Reconcile the story.** Short description begins “Play as a developer trapped inside his own game,” while About describes a young boy transported into an energy world. Pick the actual current premise and align copy/trailer/capsule. Suggested short copy **“Shoot temporary platforms, chain wall-runs and find a route through corrupted digital spaces.”** Mechanics should be visible even before story context.

3. **Show one readable route before the montage.** First trailer beat: gap→platform shot→wall run→landing, recorded from the real demo. Show input or brief camera context; don't cut away before the mechanic makes sense. Label sped-up/time-compressed footage and never present an edited perfect run as first-player evidence.

4. **Make demo scope/platform explicit.** Demo page says around 15–30 minutes, Windows minimum requirements and keyboard/mouse/controller publisher support. Put scope near the external CTA. Don't imply Mac/browser/Steam Deck compatibility from screenshots or handheld mention. Hardware/performance must be tested on the actual build before frame-rate claims.

5. **Clean incomplete requirements and mismatched specs.** Some system fields remain unspecified and recommended GPU differs between full-game/demo pages. Resolve using actual testing; don't copy unfinished labels into marketing or invent certification. Keep build/version and tested device conditions with a performance statement.

6. **Replace unsupported proof with real play.** Awards image/curator entry must name only verified, permissioned awards/reviews. “No user reviews” on main page isn't a quality verdict, and a curator count isn't a testimonial. Show a real first traversal/bug fix and actual player permission rather than fabricate a review wall.

7. **Test discovery-to-play friction.** On mobile, make Windows/install requirement obvious before click; on compatible PC, verify Steam installation, controls, pause/restart and error reporting. No website redesign required to fix owned copy/trailer. Preview **“Supercharged — shoot platforms, chain movement; free Windows demo.”** No private Steam IDs, credentials or unreleased-content claim.
