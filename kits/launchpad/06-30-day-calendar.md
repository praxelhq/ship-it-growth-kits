# LaunchPad — 30-day calendar, recovery gated

Budget 1–3 hours daily. The acquisition clock begins only after the actual public identity and useful first action work. If a gate fails, continue recovery instead of labelling later promotion executed.

| Day | Action |
| --- | --- |
| 1 | Record `07` baseline; inspect authorized domain/deployment records, #1. |
| 2 | Confirm intended build/hostname and actual owner authority. |
| 3 | Repair DNS/hosting or establish a verified replacement URL. |
| 4 | Test HTTPS/public route from fresh browser and second network. |
| 5 | Record actual headline, CTA, price, user job and access restrictions. |
| 6 | Test the complete first action and ordinary failure with synthetic data. |
| 7 | W1 gate: public identity and usable action; otherwise keep recovering. |
| 8 | Correct owner-controlled course URL/description through #3. |
| 9 | Invite three consenting usability testers with #4 after recovery. |
| 10 | Observe their actual attempts without coaching. |
| 11 | Fix the most repeated explanation or first-action obstacle. |
| 12 | Record private evidence walkthrough A if the path works. |
| 13 | Establish actual buyer and record the low-confidence classification. |
| 14 | W2 gate: real signup/activation definitions and three test outcomes. |
| 15 | Request five real prospective-user interviews using #6. |
| 16 | Verify their actual alternative and official price/access. |
| 17 | Verify two channels named by those users, not generic guessed groups. |
| 18 | Request current posting/organizer permission where needed. |
| 19 | Write the actual product pitch from demonstrated facts. |
| 20 | Record a real first-action demo and accurate public preview. |
| 21 | W3 gate: audience, access, useful action and checked channels. |
| 22 | Run one permitted five-person invitation test, actual volume logged. |
| 23 | Answer replies and fix the first conversion failure. |
| 24 | Check whether anyone completed the real action unaided. |
| 25 | Ask consenting testers #7 about voluntary return. |
| 26 | Repeat one five-person test only if permission and activation justify it. |
| 27 | Audit actual analytics and remove internal/test traffic. |
| 28 | W4 review: recovery status, real funnel and target gap. |
| 29 | Document current public limits, price and remaining blockers. |
| 30 | Deliver honest recovery/growth report with exact acquisition start date. |
