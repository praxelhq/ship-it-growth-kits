# Shotlist — Video scripts

Use a screenshot you create containing fictional ordinary tasks. No real chat, assignment recipient, name, medical/financial document, login email or confirmation token. Record only supported behaviour; phone voice and screen capture are enough.

## A · From picture to checked action · 60 seconds · own feed / listing

| Time | Shot / text | Say |
| --- | --- | --- |
| 0–2s | Synthetic reminder image. **“Where is the action?”** | “This picture isn't a finished task list.” |
| 2–14s | Actual verified input in current build. | “I'm using a made-up reminder, not a private message.” |
| 14–28s | Real extracted/entered task and source. | “This is what the current flow produced.” |
| 28–42s | Check wording/date and correct if necessary. | “I review it. If a date wasn't stated, I don't invent one.” |
| 42–53s | Real save and later retrieval, cut labelled. | “The useful result is finding the action again later.” |
| 53–60s | Actual access/data helper and URL. | “Read the current limits and data terms at Shotlist dot me.” |

If screenshot conversion isn't implemented, don't film a fake result. Narrow the recording/pitch to the actual task-list flow and flag the old description for correction.

## B · Screenshot isn't the task · 20 seconds · short post

Hook: **“I saved the reminder and lost the action.”** 0–8s, show a fictional screenshot stack. 8–15s, write one concrete task manually or through the tested tool: “Name the next action, not just the image.” 15–20s: “Then find it when you need it.” No claim of personal productivity improvement beyond your actual observed result.

## C · Missing date stays missing · 25 seconds · review help

Hook: **“Where did that deadline come from?”** 0–8s, synthetic reminder without date. 8–18s, inspect actual output: “If the source doesn't state one, this needs your decision, not a confident guess.” 18–25s: “Check before saving.” Don't stage an app failure if it didn't happen; label an explanatory example.

## D · Confirmed isn't submitted · 20 seconds · access help

Hook: **“The form isn't the finished account.”** 0–8s, show public Create account explanation, no email token. 8–15s: “The page says confirm your email before sign-in.” 15–20s: “Test the return path before inviting a group.” Use a controlled already-authorized test state if available; no new registration solely for footage.
