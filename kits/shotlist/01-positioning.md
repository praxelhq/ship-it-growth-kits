## Alternatives and actual costs

[Microsoft To Do](https://www.microsoft.com/en-us/microsoft-365/microsoft-to-do-list-app) is free and supports tasks, dates, reminders and synced lists. [Todoist's Beginner plan](https://www.todoist.com/pricing) is $0 with five personal projects; Pro is $7/month billed monthly or $60/year at a $5 monthly equivalent. You don't need the paid plan just to manually type two tasks.

Shotlist must earn the account/confirmation friction by turning a screenshot into a useful reviewable action more easily than manual entry. Don't claim competitors can't handle tasks or that a local demo automatically has stronger privacy. Authentication, image processing and saved task storage can have different data paths.

## The first gate

Make one synthetic screenshot → reviewed task → saved task → later retrieval test, then publish the actual data boundary and price/access. A “Local Demo” document title isn't a privacy policy. A screenshot can contain other people's information even if the user owns the phone.

Keep **1,000 verified individual accounts** as the target, with **one reviewed supported task saved and retrieved later** alongside. If screenshot conversion isn't supported, revise activation to the real task input before Day 1 and correct the captured description. Never count an unconfirmed email, seeded demo task or screenshot upload as completed adoption.
