# Media Chronicle — Video scripts

Use owned/consenting sample images with no children's faces, private EXIF, names or paths. Real app footage requires a real released build; until then record only a labelled website/release-repair update. Don't animate a proposed catalogue as a shipped product.

## A. Main demonstration — 60 seconds, after release repair

**0–7s:** Two clean sample external drives. “Which drive has that photo?” State actual Windows/build/sample count on screen.

**7–20s:** Actual in-place sample-folder index. “The original stays on this drive; the local catalogue stores metadata and previews.” Time-compress long indexing with a clear elapsed-time label, not a fake instant scan.

**20–32s:** Real search with a query the released build supports. “Here is the result and source drive.” If natural-language or face search doesn't work, don't splice in a hand-picked result as successful recognition.

**32–44s:** Disconnect the sample drive. Show actual preview/catalogue. “I can still find which drive. This isn't a full-resolution backup.”

**44–53s:** Reconnect for original access/export. “The original still needs its source.” Show actual path without private details; don't delete anything.

**53–60s:** Windows x64, actual trial terms, $79 one-time/three-PC/update/refund scope card after terms clarified. URL. No cloud-backup cancellation CTA.

## B. Hook — 24 seconds, Day 10

**0–6s:** Actual empty releases destination. “A trial button should lead to a trial.”

**6–16s:** If fixed, show actual published release/version and normal download destination. If not, say delivery isn't ready and show no install invitation.

**16–24s:** “I'll verify the release before asking anyone to trust it with a photo library.” URL. This is a development update, not a false product demo.

## C. Hook — 25 seconds, Day 16

**0–6s:** Catalogue thumbnail versus an external drive. “A preview isn't your backup.”

**6–17s:** Actual disconnected search and source-needed state. “Find which drive holds it. Reconnect for the original.” Label sample images.

**17–25s:** “Keep your backups. This solves finding, not storage redundancy.” URL. Use only after real test; otherwise a plain explanatory diagram clearly labelled concept.

## D. Hook — 25 seconds, Day 24

**0–6s:** A huge unverified performance claim crossed out. “I'd rather show one measured scan.”

**6–18s:** Actual small-library test card with file count, formats, specs and elapsed index time. “This is this build, this sample and this PC—not every archive.”

**18–25s:** Real retrieved result and URL. No invented timing, cloud-plan price or universal accuracy claim. Make the measured card readable long enough to inspect.

The calendar has six posts but only four video assets; use stills and actual release/testing notes for the other two. Reliability testing is more important than daily editing.
