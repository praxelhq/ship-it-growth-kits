# Media Chronicle — Landing-page fixes

No H1 was present in the rendered selector audit; actual visible leading heading **“Find any moment in a heartbeat.”** Actual CTA **Download Free Windows Trial** → GitHub releases, currently **no releases**. Purchase **$79 once**, three personal PCs in FAQ. Native install/search, payment and licensing untested. This is a live marketing site with a concrete missing trial destination, not a dead-domain diagnosis.

## 1. Repair the promised trial before purchase promotion

Publish the actual Windows x64 installer/release notes and test the button from a fresh browser. Verify signing/publisher, version, minimum OS, installer size, trial length/limits and clean uninstall; none should be invented from the marketing text. Until then replace the download CTA with:

> **Windows trial not available at this link yet.** We're repairing release delivery. View the clearly labelled product demonstration; don't purchase expecting an immediate trial download.

If checkout is taking payments without deliverable access, owner must resolve that fulfillment path before traffic. Don't generate fake release links or tell people to disable system protection. A live empty repository page isn't a working trial.

## 2. Stop equating catalogue with cloud storage

Replace “Break Free From the Cloud Storage Trap” and unconditional savings language with:

> **Find the photos on your own drives.** Media Chronicle is a local catalogue, not cloud storage or a backup service. Keep your existing originals and backup plan.

Beside calculator:

> Illustrative subscription-cost comparison only. Local drives, backup copies and replacement costs aren't included. Cloud synchronization/backup and a local index provide different functions; don't cancel a backup because of this number.

Remove unverified current provider prices or date/source their exact plan/country/tax. The claimed $521/$1,000 savings isn't a user outcome. Success means correct understanding, even if fewer people click a dramatic savings claim.

## 3. Resolve the lifetime-update contradiction

“Lifetime Updates” versus “free minor version updates forever”/v1 license has different buyer implications. Owner chooses actual terms; proposed narrow copy if accurate:

> $79 one-time for a permanent v1 license on up to three personal Windows PCs. Minor v1 updates included; major-version policy shown here before purchase.

Don't publish the suggested major-version policy until real. Keep actual 30-day refund link next to purchase; the policy requests transaction proof and deactivates refunded licenses. Do not guarantee bank settlement times beyond the posted processing estimate.

## 4. Demonstrate a small real archive before scale claims

Replace “100,000+ effortlessly”/“instant” as an established result with an actual test card:

> Tested sample: [actual file count, formats, drive type, PC specs, build]. First-index time and search latency shown separately. Your library and hardware can differ.

Populate only measured owner results. Don't leave fabricated numbers in a published card. Include supported RAW/video formats and corrupt-file handling only after tests. A search-box animation isn't a benchmark or evidence of semantic recall.

## 5. Make disconnected behavior explicit

Suggested copy near results:

> This preview comes from your local catalogue. The original stays on the named source drive. Reconnect that drive for full-resolution access/export; the catalogue doesn't contain a new backup copy.

Use a synthetic drive label; no family names, location EXIF or private file paths in recordings. Test source disconnect, renamed/missing drive and cache deletion on disposable sample data.

## 6. Scope offline privacy and safe indexing

The page claims zero network dependencies for desktop operations. Verify a real released build offline; distinguish website/payment network use. Proposed truthful framing pending verification:

> Indexing/search are designed to run locally; review the released build's actual network/privacy behavior. The website and payment process have separate terms.

Don't claim an independent audit or promise original safety without a read-only test. Confirm originals' hashes/metadata unchanged on sample files, permission denial, cancel/resume and uninstall/catalogue cleanup. Keep backups even when the tool behaves correctly.
