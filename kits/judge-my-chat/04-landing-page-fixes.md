# Judge My Chat — Landing page fixes

Based on homepage and `/court`, checked 29 October. No real/synthetic chat was uploaded during research and no verdict/purchase was completed.

## 1. Explain processing before file selection

The court says the chat is read once and never stored. State the actual server/AI-provider processing, retention, deletion and sharing behaviour before upload. **“Not stored” is not “never transmitted.”** Don't imply local/offline processing without verifying it. Provide a synthetic sample so a visitor need not start with private messages.

## 2. Keep the toy court unmistakable

Current title: **“Judge My Chat.”** CTA: **“Put a Chat on Trial.”** The page describes a verdict based on chosen-country laws.

Suggested support: **“A fictional courtroom joke from a chat you are allowed to use. Not a legal finding or advice.”** Button: **“Try a made-up case.”** Country choice should be framed as comic flavour, not accurate legal analysis unless a separate validated legal product actually exists.

## 3. Show the full free/paid boundary

The court page offers one free case with no upfront signup. Put the exact included result, later limits and any price before processing. Don't claim unlimited free cases or let a user upload first and discover a hidden charge. If paid plans aren't live, say so clearly.

## 4. Test the complete synthetic path

Synthetic screenshot/text export → format validation → verdict → card preview → download/share → delete/close. Test malformed/long files and a failed AI response. Don't publish a success video before these steps work. A return URL or spinner isn't a completed report.

## 5. Put consent and preview before sharing

Suggested note: **“Use your own or mutually agreed conversation. Check names and quoted lines before sharing; ask everyone represented.”** Show exactly what the card/link contains. Do not expose raw messages by default or imply a verdict grants permission to publish them.

## 6. Check phone export and preview

Link [WhatsApp's export help](https://faq.whatsapp.com/1180414079177245), label phone-specific steps and test file selection at 390px. Mask uploads, message text, names and tokens from replay. Preview: **“Judge My Chat — a fictional court for a chat joke.”** No real person's accusation/result in the image.
