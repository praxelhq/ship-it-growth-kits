# Labby — Landing-page fixes

Public page/app destination read 29 October 2026. No account, research record, calculation or checkout was tested. The personal-versus-institutional boundary is material.

## 1. State who can buy/use the actual current product

**Current headline:** “Your experiment. One intelligent workspace.” Researcher pricing explicitly addresses postgraduate/PhD researchers.

**Write:** **“A personal research-record workspace. Check your institution's data policies before use.”** Only add institutional/team claims after those actual features and terms exist. Don't imply a personal subscription buys lab-wide ownership, permissions or approved storage.

## 2. Make the first record/source test concrete

**Current CTA:** “Start Researching Free” links to the app/home route.

**Write:** **“Try a synthetic notebook example free.”** Supporting line: **“Inspect the source before trusting an AI answer.”** Test fresh signup → harmless controlled entry → source retrieval → edit/export before asking for real records. If the current app cannot preserve source context, fix it before promoting that promise.

## 3. Keep generated text separate from observations

**Current:** Ask Labby and research memory display confident answers from notebook/protocol context.

**Write on every answer:** **“Source record · model interpretation · uncertainty.”** A model must not silently create or overwrite observations. Show the actual original note and date; no fabricated citation or “experiment succeeded” claim. A draft report remains a draft.

## 4. Explain pricing without inventing institutional scope

**Current:** Free three active experiments, $12/month Researcher, $29/month Pro.

**Write:** **“These are individual plan limits. Confirm full charge, renewal and current features before purchase.”** Check actual checkout and storage limits before making a paid promise. A report/poster generator isn't evidence of research validity or institutional approval.

## 5. Explain IP, access and record recovery

**Current:** a connected research memory is promoted; institutional controls aren't established publicly.

**Write:** **“Use only records you're authorized to process. Read storage/provider/access/export/deletion terms before uploading.”** Verify actual handling with controlled data. Don't infer team isolation or compliant retention from a personal login. Never ask for confidential protocols in a public demo.

## 6. Make source checking readable on phones

**Current:** many tools and a long linked-workflow story compete for attention.

**Write the first demonstration around:** **“Find the original entry, then review the answer.”** Test 360 px, large text, keyboard, long-source display and error recovery. Preview title: **“Labby — research records with source context.”** No clipping/load failure was measured, and no scientific/safety outcome is established by a readable demo.
