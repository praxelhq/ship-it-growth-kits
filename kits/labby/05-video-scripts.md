# Labby — Video scripts

Use a harmless synthetic observation table, not private protocols or unpublished research. No technical biological/chemical troubleshooting, invented data or scientific-outcome claim. Phone voice plus screen recording is enough.

## A · Find the original note · 60 seconds · authorized lead walkthrough

0–2 s hook: **“Did the notebook say that, or did the model infer it?”** Show a synthetic answer. 2–15 s: open the original harmless observation/date: “The record is the evidence.”15–30 s: ask an actual supported retrieval question: “Now inspect the source rather than trusting the wording.”30–45 s: mark a difference between note and interpretation: “An inference should stay an inference.”45–55 s: show actual supported export/review or state the current gap: “A report needs the researcher's review.”55–60 s: “Start with permitted data and current terms. Labby.”

## B · A poster isn't a result · 20 seconds · own feed

Hook: **“A polished poster doesn't create evidence.”**0–8 s: show a synthetic draft with a clear draft label. 8–15 s: “Every number and citation must trace to the actual reviewed record.”15–20 s: “Use the tool to organize work, not invent it.”

## C · Personal account, institutional permission · 25 seconds · onboarding

Hook 0–2 s: **“Can you put that record in a personal tool?”**2–12 s: show the current individual-plan label, no real account details. 12–20 s: “Check your institution's IP/data policy and actual product access terms before uploading.”20–25 s: “A free signup isn't institutional approval.”

Keep sources readable and samples labelled. If a feature isn't released, don't stage it or turn a failed lookup into a confident scientific answer.
