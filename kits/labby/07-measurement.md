# Labby — Measurement

**Assigned target:10 real businesses/institutions.** The current public individual-researcher offer does not by itself support that target. Report **authorized entities independently maintaining permitted real research records** beside it; personal user counts remain separate.

## Day 0

Query actual institutional permissions, supported ownership/access scope, real entity workflows, source errors and independent returns. Personal plan/account totals aren't an institutional baseline. Check existing [Clarity](https://clarity.microsoft.com/) collection or configure it if absent, excluding research contents and credentials. Capture actual [course profile](https://shipped.money/p/labby) rank, saved metric and timestamp; unknown isn't zero. No private billing was independently tested.

Proposed events only where features exist: `permitted_record_added`, `original_source_opened`, `interpretation_reviewed`, `record_exported` and `entity_returned`. Keep synthetic examples separate. A generated answer, report or poster isn't a research result, and a model citation isn't verified merely because it appears.

## Four tests and the mismatch

The [policy](../../TARGET-POLICY.md) requires a real organization, its own permitted actual workflow onboarded, independent use in the last seven days without your prompt, and a responsible authorized person's name/callable contact held privately. Payment isn't required. Ten researchers at one institution aren't ten entities. A PI lead is a buyer hypothesis until actual authority/capabilities are confirmed. If only personal use is possible, say the 10-entity target isn't supported rather than relabelling students.
