# Audit extractor — Landing-page fixes

Public page/tool/pricing read 29 October 2026. No confidential file, extraction result or checkout was independently tested. Local-processing and team-readiness remain operator claims.

## 1. Make reviewed extraction the promise

**Current headline:** “Turn PDF paperwork into clean, reviewable data.” Nearby wording says “Audit-ready document data.”

**Write:** **“Text-PDF invoices and orders into a table you review.”** Supporting line: **“Check important fields against the original before using the Excel export.”** Keep the review-first strength; don't imply audit assurance, completeness or regulatory acceptance from extraction alone.

## 2. Put the text-only boundary at upload

**Current:** text-based PDFs are described in the workflow and tool helper.

**Write beside the first action:** **“Text-based invoices, purchase orders and sales orders. Scans/image-only PDFs aren't supported in this first workflow.”** Test a synthetic supported file and an unsupported scan. The latter needs a clear state, not a misleading empty result. If the actual supported path fails, pause outreach and repair it.

## 3. Keep test pricing unmistakable

**Current:** $10/month, $60/year and $99/month Firm cards sit below “Test mode: no real payment is taken.”

**Write on every paid action:** **“Test checkout—not a live purchase.”** Keep the ten-day/five-documents-per-day trial scope visible. Before going live, reconcile all limits, tax, renewal and cancellation terms with the actual provider setup. A test receipt isn't a paying customer.

## 4. Show original context beside the editable field

**Current:** a broad results table includes confidence and edit actions.

**Write:** **“Original value → extracted value → reviewed correction.”** Keep document identity, currency and total easy to compare; unknown or missing fields must remain visible. Don't let a high overall confidence hide one dangerous total/date error. A professional approves the final result.

## 5. Explain privacy and team scope accurately

**Current:** “Your documents stay in your browser” and a Firm “team-ready” bullet.

**Write:** **“Use only authorized files. Read the verified processing and access scope before client-data use.”** Have the owner check actual network/storage behaviour and current team permissions. Don't imply an independently audited local-only or multi-tenant control from marketing copy. Start with synthetic/redacted documents.

## 6. Make the review table usable on a phone

**Current:** many columns can make the review action hard to find on narrow screens.

**Write a compact review step:** **“Check document number, date, parties, currency, tax and total before export.”** Test 360px, large text, keyboard, horizontal table navigation and export error states. Preview title: **“Audit extractor — reviewable text-PDF data for Excel.”** No actual clipping/load defect was measured; verify, don't allege.
