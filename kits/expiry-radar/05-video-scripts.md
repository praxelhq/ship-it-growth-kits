# Expiry Radar — Video scripts

Use fictional items and no credentials. Don't claim actual saved money from a demo.

## A. One dated item — 40 seconds, vertical

0–2: **“You paid for it. Will you remember to use it?”**

2–12: Show a fictional pass and checked expiry rule. “Start with the actual date and what remains.”

12–25: Record the real supported add/save/view flow after testing it. “Expiry Radar keeps the next action in view.” If private flow is not ready, label this a proposed workflow, not a live success.

25–33: Show expiry versus reset wording. “A one-time expiry isn't the same as a recurring allowance.”

33–40: “No account credentials needed for the example. exptrack.site.” Use on homepage/listing.

## B. The forgotten pass — 15 seconds

0–2: **“I meant to use that.”**

2–10: Show a fictional date moving from distant to near. “The point is seeing the next date before it becomes yesterday.”

10–15: “One item first. Expiry Radar.” URL. First clip.

## C. Not a savings counter — 20 seconds

0–2: **“Unused value isn't saved money.”**

2–13: Compare a fictional unused amount with the actual action needed. “Track it, check the terms, use it if it genuinely fits.”

13–20: “No invented savings total.” URL. Second clip.

## D. Account handoff — 20 seconds

0–2: **“A login screen shouldn't look unrelated.”**

2–13: Open the branded page and actual app auth destination. “This is the current Expiry Radar path; the identity and next step should stay clear.”

13–20: “Track one thing after signing up. No private details in this demo.” URL. Third clip; don't submit someone else's account.
