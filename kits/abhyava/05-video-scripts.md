# Abhyava — Video scripts

Use a synthetic adult class or explicit permission. No identifiable student recordings, private portal links or medical/fitness outcome promises. Phone voice and screen recording are enough.

## A · From class note to next-class brief · 60 seconds · teacher demo

0–2s hook: **“What should your next class remember?”** Show a synthetic teacher brief. 2–15s: dictate a non-sensitive sample class note: “The teacher supplies what actually happened.” 15–28s: review and approve one modest task: “The AI drafts. I check what's appropriate before sharing.” 28–42s: open a controlled adult-student portal, label “Demo”: “A browser link lets the student respond without installing an app.” 42–55s: show the actual before-class view: “Now the teacher sees what needs attention next time.” 55–60s: “Free up to ten students. Abhyava dot space.”

Don't stage an unsupported brief function or hide a failed private-link permission check; repair it first.

## B · What happened between classes? · 20 seconds · teacher demonstration

Hook 0–2s: **“Before tonight's class, what should you remember?”** Show a synthetic adult group's next-class brief. 2–8s: point to the teacher-approved practice and one demo response: “The last class left this small task.” 8–15s: show the actual response/review view: “Now the teacher can see the question to address next.” 15–20s: “Carry the learning into the next session instead of starting from memory.” No real student names or outcome claims.

## C · Approve before practice · 25 seconds · teacher onboarding

Hook 0–2s: **“An AI plan isn't ready to teach.”** 2–12s: show a synthetic draft and teacher correction. 12–20s: “You know the students and class context. Check the task and decide what to share.” 20–25s: show an actual approval boundary: “Draft first. Teacher decision before students see it.”

If approval is not enforced in the current flow, label it as a required fix instead of pretending it exists. Record readable text and the smallest complete workflow; no polished montage needed.
